# App Store 소재 리프레시

- 요청: 현재 화면으로 다운로드 욕구를 높이는 스크린샷과 Remotion 영상 제작. 심사 제출은 보류.
- 프레임워크: 명시적으로 선택한 Remotion 4.0.499, 현재 설치 의존성 사용.
- 언어: 한국어, 영어, 일본어. 번역투보다 각 시장의 짧고 읽기 쉬운 문장 우선.
- 산출물: 언어별 8장, 1320×2868 및 1284×2778 PNG. 언어별 886×1920, 30fps, 28초 H.264/AAC 앱 미리보기, 포스터 프레임, 검토 페이지.
- 타깃: 한 명의 선수를 직접 키우며 플레이하는 야구 팬. 첫 방문자가 시뮬레이션/육성과 직접 투구를 함께 이해하도록 구성.
- 설득 순서: 손맛 → 성장 보상 → 선택의 결과 → 프로 진출 → 내 기록 → 한 구의 기억 → 계승 → 재도전.
- 첫 세 장: 기능 목록 대신 플레이 감각과 얻는 보상. 첫 영상 3초에는 수동 릴리스를 실제로 보여 준다.
- 시각: 짙은 야구장 초록, 따뜻한 아이보리, 라임 포인트. 스크린샷은 제목/실제 화면에 위계. 실제 UI의 텍스트·결과는 조작하지 않는다.
- 영상: 실제 앱 녹화 중심, 짧은 의미 단위 편집과 자막. 가격, 가짜 리뷰/평점, 다운로드 보장 문구, 다른 플랫폼 배지 없음. 세로 전체 화면, 기기 프레임 없음.
- 원본: 최신 로컬 소스의 iPhone 17 시뮬레이터. 테스트용 격리 앱에서 엔진 생성 픽스처와 수동 투구를 촬영. 강제 퍼펙트 인자 사용 안 함.
- 앱스토어 등록·업로드·심사 제출은 이 소재 제작 완료만으로 실행하지 않는다.

참고: [Apple 앱 미리보기](https://developer.apple.com/app-store/app-previews/), [영상 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications), [스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications).
