## 1. 이름과 부제 (2026-08-12 검색 유입 개편)

| 필드 | 값 | 길이 |
|---|---|---|
| 앱 이름 | `야구 못하면 또 환생함: 투수 키우기` | 20자 (제한 30) |
| 부제 | `한 구씩 직접 던져 프로 지명을 노리는 육성 시뮬레이션` | 30자 (제한 30) |

브랜드("야구 못하면 또 환생함")는 그대로 두고 **검색 태그를 붙였다** — 이름이 최고
가중치 검색 필드인데 11자만 쓰는 것은 예산 낭비였다. "키우기"는 한국 육성 장르의
핵심 검색어다. 부제는 이름에 이미 있는 야구·투수·환생을 반복하지 않고 실제 조작
(한 구씩 직접 던짐), 목표(프로 지명), 장르(육성 시뮬레이션)를 한 문장에 넣는다.
한국 App Store 실측에서 `야구 RPG`는 결과가 잡음에 가깝고 앱도 미노출이었지만,
`야구 육성`은 9위, `야구 시뮬레이션`은 4위였다. 따라서 검증된 검색 의도 두 개를
부제의 높은 가중치로 끌어올린다. Apple 공식 가이드에 따라 너무 넓은 "게임"은 키워드
필드에도 넣지 않는다.

## 1-1. 키워드 100자 (버전 필드)

```
로그라이트,회귀,드래프트,고교,에이스,삼진,오프라인,싱글,광고없음,커리어,성장,선수,타이밍,마운드,제구,구속,구종,선발,신인,피칭,전략,트레이닝,변화구,불펜,포수,회차,각성,사인
```

99자. 이름·부제·카테고리와 중복되는 야구·투수·키우기·환생·프로·육성·시뮬레이션·
게임·스포츠는 넣지 않았다. `스토리,인디,유료,베이스볼,루키`는 검색 의도가 약하거나
신인과 겹쳐 빼 두고 `변화구,불펜,포수,회차,각성,사인`을 넣었다. Apple은 필드 간
단어를 조합하므로 `야구+로그라이트`, `야구+드래프트`, `투수+제구`, `투수+변화구`
같은 고의도 조합을 만든다.

## 1-2. 스크린샷 7장 (2026-08-11 환생 서사판)

현재 제출 기준은 `asc-2026-08-rebirth/`의 7장 세트다. 6.7형은 1320×2868,
6.5형은 1284×2778이며 `apps/promo/src/asc/StoreCreative.tsx`에서 결정적으로 렌더한다.

대표 유산과 다음 선수, 지명 성공으로 실제 시스템임을 증명한다.

|---|---|---|
| 1 | 마지막 한 구를 / 직접 던진다 | 투구 결과와 스트라이크 존 |
| 2 | 못하면 / 이름은 불리지 않는다 | 드래프트 미지명 |
| 3 | 그래도 끝이 아니다 / 또, 환생함 | 환생 스탬프 |
| 4 | 전 생의 한 가지를 / 이번 생에 남긴다 | 대표 유산 선택 |
| 5 | 타자도 / 당신의 공을 읽는다 | 구종·코스·포수 사인 선택 |
| 6 | 전 생의 실패가 / 이번 생의 시작이 된다 | 다음 선수 시작 능력 |
| 7 | 이번 생엔 / 이름이 불릴까 | 드래프트 지명 |

## 2. 프로모션 텍스트 (170자 제한)

> 마지막 한 구를 직접 던집니다. 구종·코스를 고르고 손 떼는 타이밍으로 제구가 갈립니다.
> 지명받지 못하면 다시 태어나 전 생의 한 가지를 남깁니다. 광고·뽑기·인앱 결제 없이,
> 한 번 사면 고교부터 은퇴까지 전부입니다.

2026-08-25에 라이브 1.2.2 한국어 필드에 반영. 차트에서 들어온 사람에게 직접 투구·환생·한 번
구매를 먼저 알린다. 프로모션 텍스트는 심사 없이 갱신된다.

```
이번 생이 끝나도, 다음 공이 이어집니다.

마지막 한 구는 여전히 당신이 직접 던집니다.
```

## 3. 설명 (4,000자 제한)

첫 3줄이 접히기 전에 보이는 전부다. 거기에 "한 구씩 직접 던진다"가 들어가야 한다.

```
공 하나하나를 직접 던지고, 한 투수의 인생을 선택하는 야구 게임입니다.

구종과 코스를 고르고, 화면을 길게 눌러 와인드업한 뒤 손을 떼는 타이밍으로 제구가 갈립니다. 자동으로 굴러가는 경기를 구경하는 게임이 아닙니다. 중요한 공은 투구 슬라이더로 직접 던집니다.

■ 한 구의 무게
구종과 코스, 노림과 힘 배분을 고릅니다. 포수는 이유와 함께 사인을 내고, 따를지 고칠지는 당신이 정합니다. 같은 공을 반복하면 타자가 읽고 적응합니다. 던진 공은 궤적과 타구로 다시 확인할 수 있습니다.

■ 3년의 선택
고교 3년 동안 훈련·관계·중요 경기·각성이 이어집니다. 팔 상태와 피로를 무시하면 부상을 입을 수 있습니다. 부상이 생기면 원인, 회복 기간, 다음 행동을 결과 화면에서 바로 알려 줍니다. 쉴지, 훈련할지, 다시 승부할지 당신이 결정합니다.

■ 더 읽기 쉬워진 커리어
스토리와 반복 설명은 처음 볼 때 맥락을 충분히 보여 줍니다. 한 번 읽은 뒤에는 간결한 요약으로 접어 한눈에 읽을 수 있고, 원하면 언제든 다시 펼칠 수 있습니다.

■ 누구나 이해하는 성장
능력 수치는 익숙한 1–100으로 보여 줍니다. 기본 능력치가 100에 닿은 뒤에는 숫자가 끝없이 커지지 않습니다. 대신 별도의 숙련 레벨과 효과를 쌓아 다음 성장을 이어 갑니다.

■ 다시 태어나기
지명받지 못하면 기억과 대표 유산을 남기고 새 선수로 다시 시작합니다. 전 생의 실패가 다음 회차의 출발점이 됩니다. 학교·감독·포수·라이벌·일정도 회차마다 새로 짜입니다.

■ 프로, 그리고 기록
지명되면 프로에 진출해 역할·계약·콜업·시즌·기록·은퇴를 이어 갑니다. 관계와 지역의 분위기, 당신이 내린 선택이 한 투수의 연대기가 됩니다.

■ 약속
· 광고 없음 · 인앱 결제 없음 · 확률형 뽑기 없음
· 한 번 구매하면 고교부터 은퇴까지 전부
· 오프라인 플레이 가능
· 한국어·영어·일본어 지원

실존 리그·구단·학교·선수와 관련이 없는 독자적인 가상 야구 세계입니다.
```

마지막 두 문단이 중요하다. **한국어·영어·일본어 지원을 정확히 명시**해 구매자가 실제
바이너리 지원 언어를 알 수 있게 한다. 실존 IP 무관 문구는 야구 게임에서 관례이자 안전장치다.

## 4. 키워드 (ASC 버전 필드와 동일)

실제 제출 값은 **§1-1의 98자 목록**을 사용한다. 아래의 예전 14개 초안은 삭제하여
App Store Connect에 등록된 키워드와 문서가 어긋나지 않게 했다. 실존 구단명·선수명·로고는
사용하지 않는다(AGENTS.md의 IP 위생).

## 6. 구형 제출안 (보관용)

현재 제출본은 §1-2의 7장 환생 서사판이다. 2026-08-02의 9장안과 아래 5장안은 초기 기획
순서를 보존하기 위한 참고 자료이며, App Store Connect에 다시 올릴 때의 기준이 아니다.

순서 자체가 주장이다: **"이건 텍스트 관리 게임이 아니라 한 구씩 던지는 야구 게임이다."**

| 순번 | 화면 | 캡션(선택) |
|---|---|---|
| 1 | 승부 — 존 그리드·포수 사인·카운트 | 한 구씩 직접 던집니다 |
| 2 | 투구 결과 — 궤적과 판정 | 손 떼는 타이밍이 제구를 정합니다 |
| 3 | 드래프트 호명 | 3년이 여기서 판가름 납니다 |
| 4 | 환생 — 회차 스탬프 | 못 하면 다시 태어납니다 |
| 5 | 기록 — 시즌 등판 목록 | 던지지 않은 경기도 기록에 남습니다 |

3번과 4번은 이번에 만든 정점 연출 화면이다(`ClimaxViews.swift`). 스크린샷에서 다른 앱과
구별되는 장면이 여기에 있다.

생성 절차는 `README.md` §1. UI 스모크 테스트가 `07-draft-reveal`·`09-rebirth`를 포함해
찍는다.
