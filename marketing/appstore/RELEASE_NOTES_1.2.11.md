# 1.2.11 릴리스 노트

대상: 1.2.11 (70). 현재 판매 중인 1.2.10 (69) 이후의 환생 문안을 포함한다.
실제 배포 상태와 제출 조건은 `docs/IOS_1_2_11_RELEASE_EVIDENCE_2026-09-18.md`에서 관리한다.

## whatsNew (ko)

환생을 이번 선수와 다음 선수로 더 분명하게 밝혔습니다.

• 이번 회차·다음 선수라는 말로 커리어가 이어지는 방식을 정리했습니다.
• 능력 화면의 변화구 이름을 다른 기록과 같게 맞췄습니다.

직접 투구의 기본 조작은 타이밍 슬라이더 그대로이며 기존 자동 릴리스 선택도 유지됩니다.

## whatsNew (en)

Reincarnation now talks about this pitcher and the next career.

• Copy now says this run and the next pitcher, so the career you pass on is easier to follow.
• The breaking-ball ability uses the same name as the rest of the records.

Manual pitching still uses the timing slider by default, and your saved auto-release preference is preserved.

## whatsNew (ja)

転生の言葉を、今回の投手と次の選手にそろえました。

• 今回の回次・次の選手という言い方で、キャリアの引き継ぎが分かりやすくなりました。
• 能力画面の変化球の名前を、ほかの記録と同じにしました。

直接投球の基本操作は、引き続きタイミングスライダーです。保存済みの自動リリース設定も維持されます。
