# Steam 그래픽 자산

기준일: 2026-07-22

이 폴더에는 `야구 못하면 또 환생함` Steam 상점과 라이브러리에 올릴 1차 출시 후보 자산이 들어 있다. 모든 캡슐은 게임 아트와 공식 게임명만 사용하고, 리뷰 점수·수상·할인·출시일 문구를 넣지 않았다. `library-hero.png`에는 Steam 규칙에 맞춰 글자를 넣지 않았다.

## 제출 파일

| 파일 | 규격 | 용도 |
|---|---:|---|
| `store/header-capsule.png` | 920×430 | 상점 헤더 |
| `store/small-capsule.png` | 462×174 | 검색·목록 |
| `store/main-capsule.png` | 1232×706 | 메인 캡슐 |
| `store/vertical-capsule.png` | 748×896 | 세로 캡슐 |
| `store/page-background.png` | 1438×810 | 상점 배경 |
| `icons/shortcut-icon.png` | 256×256 | 바로가기 아이콘 |
| `icons/app-icon.jpg` | 184×184 | 앱 아이콘 |
| `library/library-capsule.png` | 600×900 | 라이브러리 캡슐 |
| `library/library-hero.png` | 3840×1240 | 글자 없는 라이브러리 히어로 |
| `library/library-logo-1280x720.png` | 1280×720 | 투명 배경 로고 |
| `library/library-header-capsule.png` | 920×430 | 라이브러리 헤더 |

`source/`에는 재크롭과 보정에 사용할 생성 원본을 보관한다. 최종 파일은 원본의 글자를 별도 합성하지 않고, 생성 이미지에 포함된 공식 게임명을 그대로 사용했다. 투명 로고만 단색 크로마 배경을 제거했다.

## 생성 브리프

- `key-art-wide-v1.png`: 야간 고교 야구장, 결승구를 던지는 한국인 투수, 이전 삶의 실루엣, 짙은 초록과 형광 궤적, 왼쪽에 정확한 한글 게임명 `야구 못하면 또 환생함`, 고급 스포츠 드라마 키아트.
- `key-art-vertical-v1.png`: 같은 세계관의 세로형 포스터, 위쪽에 정확한 한글 게임명, 중앙에 여러 삶의 투수 실루엣, 아래쪽에 현재 삶의 투구 동작.
- `small-capsule-v1.png`: 작은 크기에서도 읽히는 단순한 구도, 왼쪽의 큰 한글 게임명과 오른쪽 투수 얼굴, 강한 명암과 초록 궤적.
- `library-hero-v1.png`: 글자·로고가 전혀 없는 초광각 야간 야구장, 오른쪽에 현재 투수와 이전 삶의 잔상, 왼쪽은 Steam UI가 올라갈 수 있는 어두운 여백.
- `logo-chroma-v1.png`: 정확한 한글 게임명만 들어간 붓글씨 로고, 아이보리와 짙은 초록, 제거 가능한 균일한 마젠타 배경.

## 공개 전 사람 검수

- 축소 미리보기에서 제목이 `야구 못하면 또 환생함`으로 정확히 읽히는지 확인한다.
- 실제 구단·리그·선수의 로고, 유니폼, 상표를 연상시키는 요소가 없는지 법무 관점에서 확인한다.
- 게임의 실제 그래픽과 분위기를 오해하게 만들지 않는지 외부 플레이테스터에게 확인한다.
- 데모 캡슐은 Steamworks App ID 발급 후 실제 데모 자산 규칙에 맞는 별도 버전으로 제작한다.
- 생성 원본과 최종 자산의 사용 권리 기록을 출시 보관 문서에 남긴다.

규격 자동 검사는 저장소 루트에서 `npm run steam:submission:check`로 실행한다.
