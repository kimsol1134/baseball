# Google Play 스토어 이미지

이 폴더에는 한국어 스마트폰 배포용 스토어 이미지만 둔다. 실제 게임 스크린샷은 서명된
프로덕션 후보 AAB를 실기기에서 검증한 뒤 별도 증거 폴더에서 캡처해야 하며, 이 폴더의 키아트를
게임 플레이 화면으로 표시하면 안 된다.

## 포함 파일

- `FeatureGraphic-1024x500.png`: Google Play 피처 그래픽. 가상 야구 세계관의 새벽 구장, 공의
  궤적, 기존 한국어 로고 **야구 못하면 또 환생함**을 하나의 장면으로 구성했다. 실존 구단명,
  선수명, 로고, 유니폼 문양은 포함하지 않았다.
- `StoreIcon-512x512.png`: 승인된 RGB 앱 아이콘의 512×512 스토어 사본이다. Android 런처의
  adaptive/monochrome 레이어와는 용도가 다르다.
- `manifest.json`: 크기, PNG 색상 형식, SHA-256, 원본 참조와 출시 스크린샷 상태를 고정한다.

## 피처 그래픽 제작 기록

OpenAI imagegen을 사용해 `KeyArtReincarnation.png`를 배경 정서와 구도 기준으로, 투명 배경의
`LaunchLogo.png`를 정확한 한국어 타이틀 기준으로 참조했다. 제작 브리프는 다음과 같다.

> 1024×500 비율의 프리미엄 모바일 야구 게임 피처 그래픽. 새벽빛의 독자적인 가상 한국 야구장,
> 포수 뒤에서 홈플레이트를 향해 휘어 들어오는 공의 발광 궤적, 희망적이면서 긴장감 있는 색감.
> 화면에 보이는 문자는 기존 로고의 “야구 못하면 또 환생함”만 정확히 사용한다. 실존 구단,
> 리그, 선수, 로고, 스폰서, 유니폼 문양, 추가 문구는 넣지 않는다.

생성 결과는 목표 비율과 사실상 같은 원본 캔버스에서 1024×500 RGB PNG로 결정론적으로
리사이즈했다. 생성 모델은 비결정적이므로 최종 파일과 `manifest.json`의 SHA-256이 승인된
마스터다. 새로운 생성 결과로 교체할 때는 사람이 한국어 글자와 콘텐츠 불변 규칙을 검수한 뒤
매니페스트 해시도 함께 갱신한다.

## 출시 전 확인

- Play Console의 현재 이미지 규격과 콘텐츠 등급 정책을 다시 확인한다.
- 프로덕션 서명 AAB로 세로형 스마트폰 스크린샷을 캡처한다.
- 스크린샷에 디버그 UI, 개인정보, 실존 야구 IP, 테스트 분석 식별자가 없는지 확인한다.
- `npm run check:android:unity`가 이미지 크기·RGB 형식·해시·원본 해시를 통과해야 한다.
