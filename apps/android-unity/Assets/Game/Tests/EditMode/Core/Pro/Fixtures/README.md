# Pro cross-language fixtures

`pro_seed_7.json` was emitted by the Swift `SimulationCore` implementation on 2026-08-11.
The NUnit suite checks the exact start, rookie-contract, and first `earn_trust` weekly transition:
next seed, signed commitment, Korean tension titles, season line, game line, and event IDs.

The first weekly line is not a statistical stub. Swift and C# both submit each pitch to their
`PitchKernelEngine`; matching the 17-out/12-strikeout/99-pitch line verifies the shared seed
consumption and authoritative kernel path.

Standalone NUnit must be run from a project outside Unity `Assets` (the verification runner uses
`/tmp/baseball-pro-standalone`) so package restore and test-platform DLLs never create Unity plug-ins.
