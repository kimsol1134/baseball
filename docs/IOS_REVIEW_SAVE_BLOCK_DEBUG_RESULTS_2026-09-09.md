## 이번에 수정한 것

1. **다음 회차 저장 실패**: `beginNextLife()`가 저장 실패를 무시하고 현재 선수를 메모리에서 비운 채 새 선수 화면으로 넘어가는 것을 재현했다. 저장 성공 후에만 전환하며, 실패 시 현재 선수·유산·보상·회차를 되돌리고 재시도할 수 있게 수정했다. 정산 전 선수를 이 경로로 건너뛰는 것도 차단했다. 빠른 환생 호출부도 저장 성공 여부를 확인한다.
2. **프로 기록 없는 고교 교착**: 고교에는 프로 진출 영수증이 남고 프로 저장은 없는 상태에서 ‘은퇴 대기’만 표시되는 경로를 확인했다. 프로 복원이 끝나 비어 있음이 확인된 경우에만 **남은 기록으로 이어가기**를 제공한다. 버튼을 누를 때 저장을 다시 읽고, 남은 고교 기록으로 유산 선택을 연다. 이미 모은 자산과 진출 영수증을 보존하며, 없는 프로 기록·보상은 만들어 내지 않는다. 복구 버튼은 긴 기록 카드들보다 위에 배치했다.
3. **연구 완료 후 실전 적응 잔여 표시**: `(훈련, 실전) = (9,0), (9,1)`에서 연구가 완료됐는데도 미완료 수치가 계속 표시되는 것을 재현했다. 고교·프로 화면 모두 완료 상태를 표시하도록 수정했다. 실제 횟수나 능력치를 조작하지 않는다. `(5,0), (7,1)`의 미완료 표시는 유지한다.
4. **오류 화면에서 삭제 유도 방지**: 고교·프로 오류 화면의 기록 삭제 버튼을 제거했다. 재시도 경로를 유지하며, 사용자가 명시적으로 모든 기록을 지우는 설정 메뉴는 유지한다.
5. **안전한 UI 재현**: Debug 전용 `-uiTestIsolatedCareer` 인자로 별도 로컬 파일을 사용하고 원격 저장소에는 쓰지 않는 UI 테스트 경로를 추가했다. 실제 플레이용 고교·프로 저장을 초기화하지 않고 재현할 수 있다.

구버전 회차의 기존 기억 선택 규칙을 유지한다. 이번 수정은 저장 스키마, 선수 능력치 규칙, 시즌 엔진을 변경하지 않는다.
