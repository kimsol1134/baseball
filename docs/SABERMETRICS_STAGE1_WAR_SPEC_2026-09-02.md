# 세이버메트릭스 1단계 + 간이 WAR 스펙 (계획)

작성: PM, 2026-09-02. 상태: 계획(착수 대기). 원칙: **저장 형식·시뮬레이션·픽스처 무변경. 전부 기존 시즌 기록에서 파생해 표시만 한다.** 안드로이드 패리티 부담 없음(프레젠테이션 전용). 

## 0. 재료 (이미 저장되는 값)
`ProSeasonStats`: games, starts, inningsOuts, strikeouts, walks, runsAllowed, hits, homeRuns, pitches, wins, losses, saves. 경기 라인(`ProGameLine`)에 이닝·실점·투구 수·선발 여부.
없는 값: 자책점(→ ERA는 RA9로 표기 통일), 사구, 타자 수(→ 근사), 타구 유형. 이번 단계에서는 추가하지 않는다.

## 1. 파생 지표 (`SabermetricsRules`, SimulationCore 새 파일, 순수 함수·정수 산술)
입력은 `ProSeasonStats` 하나 또는 배열(통산). 출력은 퍼밀/센티 단위 정수(`Int`)와 표시용 포맷터.

| 지표 | 식 | 비고 |
|---|---|---|
| IP | inningsOuts/3 (표기 5.2 형식) | 기존 포맷터 재사용 |
| PA(근사) | inningsOuts + hits + walks | 사구·실책 없음이므로 이 근사가 정확 |
| K/9, BB/9, HR/9 | 각 ×27/inningsOuts | |
| K%, BB%, K-BB% | K/PA, BB/PA | |
| WHIP | (H+BB)×3/inningsOuts | 이미 있음, 재사용 |
| RA9 | runsAllowed×27/inningsOuts | "방어율" 라벨은 유지하되 용어 사전에 "자책점 구분 없음" 명시 |
| FIP | (13·HR + 3·BB − 2·K)×27/inningsOuts + FIP상수 | FIP상수는 규칙 버전별 동결 상수(아래) |
| RA9+ / FIP− | 리그 기준 대비 100 스케일 | 리그 기준도 동결 상수 |
| QS, QS% | 경기 라인에서 선발·18아웃 이상·실점 ≤3 | 주간 결정 후속 카드가 이미 쓰는 판정 재사용 |
| IP/GS, P/IP, 완투·완봉 | 경기 라인 집계 | 완투=27아웃, 완봉=27아웃·0실점 |

**리그 상수(동결, v1)**: 분포 스모크(8시드×20시즌)와 밸런스 밴드에서 측정해 정수로 고정한다. 초안: 리그 RA9 3.60, K/9 7.7, BB/9 2.3, HR/9 0.9 → FIP상수 = RA9 − (13·HR9 + 3·BB9 − 2·K9)/9. 측정값이 다르면 측정값으로 바꾸고 보고서에 기록. 상수는 `SabermetricsRules.LeagueConstants.v1`로 두고, 나중에 리그 환경이 바뀌면 v2를 추가(과거 시즌은 자기 버전으로 계산).

## 2. 간이 WAR (FIP 기반, fWAR 구조 축약)
```
RAAP9      = lgFIP − FIP                       (9이닝당 평균 대비 실점 절감)
replacement= 0.12·(GS/G) + 0.03·(1 − GS/G)     (선발 0.12, 구원 0.03, 혼합은 비율)
leverage   = 마무리(saves ≥ 10 && starts == 0) 1.3, 그 외 구원 1.0, 선발 1.0
runsPerWin = 9.0 (v1 고정)
WAR        = (RAAP9 + replacement) × IP/9 / runsPerWin × leverage
```
- 전부 퍼밀 정수 연산(예: RAAP9는 센티런, 결과는 WAR×100 정수). 반올림 규칙 고정, 결정적.
- 통산 WAR = 시즌 WAR 합. 포스트시즌·국가대표는 제외(리그 기록만).
- **WAR는 이번 단계에서 표시 전용**이다. 명예의 전당 점수·목표판 판정·계약 시장 점수에 넣지 않는다(규칙 버전·픽스처·안드로이드 연쇄를 피함). 목표판에는 "통산 WAR" 행을 **표시 전용 마일스톤**(10/25/50)으로만 추가할지 검토 — 추가하면 파생 행이므로 저장 영향 없음.

## 3. 표시
- **기록 탭 "세이버" 섹션**: 시즌별 표(IP·RA9·FIP·K%·BB%·WHIP·WAR) + 통산 합계 행. 리그 기준 대비 좋으면 파랑, 나쁘면 빨강(디자인 시스템 토큰). 가로 스크롤 표(작은 화면 잘림 방지).
- **시즌 정산**: "이번 시즌 FIP 3.12 · WAR 4.3" 한 줄.
- **은퇴 화면·은퇴 공유 카드**: 통산 WAR 타일 추가(카드는 2×2 + 시즌 행 구조 유지: 시즌 행을 "시즌 12 · WAR 38.5"로 합침).
- **커리어 목표판**: "통산 WAR" 행(표시 전용, 위 검토 결과에 따라).
- **용어 사전** 8항목: FIP, WAR, K%, BB%, RA9(방어율), QS, WHIP(기존), 대체 수준.
- ko/en/ja 전부.

## 4. 검증
- 단위: 알려진 값 테스트(예: 200이닝 K 200 BB 50 HR 15 → FIP·WAR 기대값), 0이닝·0타자 방어, 정수 반올림 결정성.
- 정합성 불변식: K ≤ inningsOuts+…(기존 규칙 유지), FIP와 RA9가 리그 평균 투수에서 ±0.3 이내(분포 스모크 8시드 평균), 시즌 WAR 밴드: 리그 평균 선발 1.5~2.5, 상위 시드 4~8, 구원 −0.5~2.5. 밴드가 어긋나면 상수를 조정하고 기록.
- `check:balance`에 WAR 밴드 2줄 추가(선발 평균 WAR, 마무리 평균 WAR).
- iOS: 기록 섹션 뷰 계약·접근성 ID·LocalizationCoverage, 정산·은퇴·카드 스냅샷.
- 저장 형식 무변경 확인(스키마 5/6 유지, 골든 픽스처 무변경).

## 5. 범위 밖 (다음 단계 후보)
자책점·사구·타구 유형 카운터(BABIP·GB%·HR/FB), LOB%, 홀드, WPA. WAR를 명예의 전당·계약 시장에 반영하는 것은 규칙 버전 11 항목으로 따로.
