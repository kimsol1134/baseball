# 야구 못하면 또 환생함 1.0.3 구현 노트

## 플레이 흐름

- 훈련은 같은 방향으로 최대 3회를 묶어 진행할 수 있고, 관계·경기·각성처럼 중요한 장면에서는 자동으로 멈춘다.
- 프로 생활은 한 주가 아니라 다음 의미 있는 장면까지 이어서 진행할 수 있다.
- 승부가 기운 타석은 빠르게 넘길 수 있고, 선수의 선택이 필요한 타석은 직접 투구를 유지한다.
- 고교 입학부터 프로 은퇴까지 실제 UI로 완주하는 회귀 테스트를 추가했다.

## 성장과 반복 플레이

- 고교 공식 경기의 좋은 투구가 직접 능력 성장으로 이어진다.
- 한 선수에게서 직접 키운 대표 능력을 다음 선수에게 하나 물려줄 수 있다.
- 프로 경력 보상은 자동 능력치가 아니라 구매 가능한 야구혼으로 지급해, 긴 프로 생활이 다음 회차의 자동 성공으로 변하지 않게 했다.
- 첫 선수는 어렵지만 도달 가능하고, 대표 유산과 선택형 강화로 두 번째·세 번째 선수의 성장이 체감되도록 재조정했다.

## 이야기와 표현

- 선수의 훈련, 관계, 부상 위험, 각성, 지명 결과를 따라 달라지는 성장 문구와 은퇴 후일담을 보강했다.
- 다음 선수에게 남기는 대표 유산의 근거와 효과를 기록과 보관함에서 다시 볼 수 있다.
- 개발자 용어를 실제 플레이어가 이해하기 쉬운 표현으로 교체하고 한국어 조사·기간 표현을 바로잡았다.

## 안정성

- 고교·프로 경기, 관계 선택, 회차 목표, 주간 보상, 삭제·동기화 과정은 저장 성공 뒤에만 완료되도록 원자성을 강화했다.
- 다른 기기에서 삭제된 선수를 진행 중 경기나 백그라운드 저장이 되살리지 않도록 원격 삭제 묘비를 우선 적용한다.
- 구버전 진행은 당시 규칙과 결과를 유지하고, 새 규칙은 새로 시작한 선수에게만 적용한다.

## 배포 검증

- iOS 단위 테스트, 고교→프로 은퇴 UI 완주 테스트, SimulationCore 전체 테스트를 실행한다.
- 카피, 디자인 시스템, 밸런스, 실존 야구 IP 노출 검사와 `git diff --check`를 통과한 빌드만 App Store Connect에 업로드한다.

이전 변경 사항은 [1.0.2 구현 노트](./RELEASE_NOTES_1.0.2.md)를 참고한다.
