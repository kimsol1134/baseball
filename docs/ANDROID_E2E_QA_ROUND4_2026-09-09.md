## 신규 — 높음

### S-01 멈춰 둔 투구를 포기하면 저장이 거부되고, 안내가 틀렸다

재현 100%:
1. 등판 중 `나중에 이어하기` → `나가기` (투구가 `suspended`로 저장)
2. 돌아와서 `투구를 멈추고 나가기`(`action.abandonPitch`) 탭
3. 빨간 배너 "저장하지 못했어요. 같은 버튼을 한 번 더 눌러 주세요." — 3회 반복 모두 동일

logcat:
```
java.lang.IllegalArgumentException: pitch.abandoned_shape
  at PitchDurableState.validate(GameAggregateModels.kt:122)
  at CSharpLegacyAggregateBridge.project(CSharpLegacyAggregateBridge.kt:41)
  at CSharpLegacyGameStoreRepository$dispatchLegacy$2.invokeSuspend(...:192)
```

불변식은 `ABANDONED -> require(!abandonedReason.isNullOrBlank() && suspendedFrom == null && terminalPitchId == null)`. 저장 상태는 `boundary=suspended, suspendedFrom=playing`이었고, ABANDONED로 전이하면 `suspendedFrom`이 남아 자기 검증을 통과하지 못한다. **SUSPENDED에서의 포기 경로만** 위반한다(PLAYING에서 바로 포기는 3차까지 정상). 결과적으로 멈춰 둔 등판을 포기할 수 없고, 앱은 성공할 수 없는 재시도를 권한다.

## 신규 — 중간

- **S-02** 위 오류 배너가 본문을 밀어 `action.abandonPitch`가 **25px(9.5dp)** 로 잘리고 `action.resumePitch`(48dp)에 덮인다. 안내대로 다시 누르려 해도 닿지 않는다.
- **S-03** **하단 내비게이션이 화면 최상단에도 그려진다.** 상태 표시줄 자리에 `기록`(화면에 따라 `설정`도)이 회색으로 겹친다. 기본 설정·기본 해상도의 내 빌드에서 재현했고, 팀의 3차 캡처 `draft.png`·`contract.png`에도 동일하게 있다. 접근성 트리에는 없다(그려지기만 하는 잔상). 1차 M-10으로 "확인 필요"로 남겼던 항목이 서로 다른 두 세션·세 화면에서 재현됐다.
- **S-04** **투구 비행 화면에서 홈플레이트 사다리꼴이 포수 얼굴 위에 겹쳐 그려진다.** 타자는 오른쪽으로 잘린다. 이 화면은 조작 요소 없이 12초 이상 유지됐고 탭해야 결과로 넘어가는데 안내가 없다.
- **S-05** 새 드래프트 화면에서 **감독의 마지막 한마디가 하단 고정 CTA에 잘린다.** 주간 화면에서 고친 것과 같은 원인이 이 화면에 미적용.

## 신규 — 낮음·관찰

- **S-06** 프로 대화 세 번째 선택지 `맞대결까지 보류한다`에만 `효과 자세히`가 없다.
- **S-07** 시즌 목표 "첫 완투에 도전 / 투구 수와 체력을 아껴 마지막 아웃까지"가 3주차~18주차 내내 동일.
- **S-08** 드래프트 결과의 `처음의 나 → 지금의 나`에 `제구 23 −2`가 설명 없이 나온다.
- **S-09** 2시즌 내내 `level: minor`(2군). 1군 승격 조건·진척이 화면에 없다.
- **S-10** `pitch.exhaustionExit`가 실제 플레이에서 한 번도 노출되지 않았다(`canFastForward` 조건 확인 필요).
