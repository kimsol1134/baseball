이 문서는 [선수 육성·세대 계승 루프 구현 계획](./PLAYER_DEVELOPMENT_LOOP_PLAN_2026-08.md)의 출시 전 내부 검증 기록이다. 수치는 실제 `PitchKernelEngine`을 사용한 결정론적 정책 시뮬레이션이며, 사용자 행동이나 유지율의 예측값이 아니다. 정식 출시 뒤에는 `distribution=app_store`, `environment=production` 코호트로 다시 측정한다.

## 1. 최종 난이도 규칙

- 첫 선수의 프로 진입을 환생 횟수로 막지 않는다.
- 신규 시작 유형 네 개의 초기 능력 총합은 모두 150이다.
- 자동 시즌 기록은 시작 유형별 기대 기록을 영점으로 삼고, 드래프트 반영을 최대 ±2로 제한한다.
- 직접 경기 결과는 기대 피해와 중복 가산되지 않도록 완만하게 반영한다.
- 최종 운은 `-1 / 0 / +1 = 20% / 60% / 20%`다. `luck_flip_rate`는 최종 운을 0으로 뒀을 때와 당락이 달라진 전체 비율이다.
- 경기에서 충분한 근거를 만든 경우에만 경기당 최대 능력치 +1을 적용한다.
- 구버전 v3 진행은 당시 능력·자동 시즌·드래프트 문턱·±5 운·4타자 승부를 그대로 유지한다.

## 2. 배치 방법

모든 정책은 앱과 같은 시드 전진, 학교 일정, 자동 시즌, 드래프트 정산과 실제 직접 투구 커널을 사용했다. 신규 승부는 장면에 따라 2·4·5·6타자를 상대한다.

| 정책 | 공개 정보 사용 방식 | 표본 |
|---|---|---:|
| UI 정보 활용 | 화면의 오늘의 기회를 따르고 피로 75 이상에서 회복, 첫 각성·기본 포수 추천 사용 | 시작 유형별 1,000 |
| 일관된 방향 육성 | 시작 유형·학교·훈련·각성을 맞추고 화면에 표시된 관계 선택 효과 활용 | 방향별 1,000 |
| 방향 분산 | 여섯 훈련을 순환하고 관계에서 안전한 기본 선택 사용 | 1,000 |
| 저관리 | 가벼운 회복 위주, 추천 사인을 피하며 성장 기회를 거의 사용하지 않음 | 독립 시드 2,000 |

`UI 정보 활용`은 초보자를 뜻하지 않는다. 화면이 실제로 공개한 단서만 사용한 재현 가능한 정책이다. `일관된 방향 육성`도 결과나 시드를 미리 알지 않고 같은 수의 선택을 한다.

## 4. 대표 유산과 세대 성장

### 4.1 보이는 유산은 강하게, 수동 누적은 완만하게

한 선수의 실제 성장·경기·관계 기록에서 서로 다른 대표 유산 세 개를 만들고 하나만 다음 선수에게 직접 적용한다. 고른 대표 유산의 총 능력 보너스 +4는 유지했다.

야구혼 자동 스며듦 v2는 누적 0이면 0, 양수면 `max(1, (자동 누적 - 20) / 4)`, 최대 20이다. v1 공식은 저장 호환을 위해 그대로 남는다.

UI 정보 활용 정책, 실제 경기, 기억 카드 없음, 같은 시드 1,000쌍의 결과는 다음과 같다.

| 선수 | 대표 유산 없음 | 대표 유산 1개 | 유산 효과 | 자동 누적 중앙값 → 실제 적용 |
|---|---:|---:|---:|---:|
| 첫 선수 | — | 45.1% | — | 0 → 0 |
| 두 번째 선수 | 45.7% | 60.6% | +14.9%p | 24 → 1 |
| 세 번째 선수 | 64.0% | 76.4% | +12.4%p | 48 → 7 |

두 번째 선수 50~65%, 세 번째 선수 70~80% 목표를 통과한다. 대표 유산을 +3으로 약화하는 대신, 눈에 덜 보이는 자동 누적 곡선만 완만하게 해 사용자가 직접 만든 한 가지의 의미를 보존했다.

### 4.2 프로 보상은 자동 합격이 아니라 선택권

프로 야구혼을 자동 성장 총량과 지갑에 동시에 더하면 짧은 프로 생활만으로 두 번째 선수 지명률이 89.6%가 되고, 평범한 경력부터 자동 상한 20에 닿아 경력 차이가 사라졌다. 최종 규칙은 이를 분리한다.

- 고교 완주와 주간 보상은 자동 누적과 지갑을 함께 올린다.
- 프로 은퇴 보상은 지갑에만 들어간다.
- 구저장에 분리 필드가 없으면 기존 평생 총량을 자동 누적으로 한 번 복원한다.
- 구매는 지갑만 차감하며 이미 얻은 자동 누적을 낮추지 않는다.
- 코어 시작 요청에는 지갑이 아니라 자동 누적만 전달한다.

같은 시드 250쌍의 스트레스 테스트에서 프로 보상을 쓰지 않으면 짧은·평범한·전설 경력 모두 L2 59.6%, L3 70.8%로 동일했다. 지갑으로 가장 강한 구매를 명시적으로 고른 경우는 다음과 같다.

| 프로 경력 | 지갑 보상 예시 | L2 최강 구매 | L3 최강 구매 |
|---|---:|---:|---:|
| 없음 | 0 | 59.6% | 70.8% |
| 짧음 | +30 | 59.6% | 75.2% |
| 평범 | +80 | 60.8% | 75.2% |
| 전설 | +220 | 80.9% | 88.5% |

전설 최강 조합은 별도 1,000시드로 재현했다. `조기 성장`은 +6에서 +5로 한 점 낮췄고, `성장 리듬`과 함께 구매해도 L3 90% 아래를 유지했다. 높은 성공률은 자동 지급이 아니라 긴 프로 경력 뒤 두 효과를 지갑으로 고른 결과다.

## 7. 4주 야구혼 경제

대표 가정은 매주 보통 고교 회차 1회와 주간 목표 2/3을 4주 연속 완료하는 경우다. 보통 회차는 실제 정산으로 주 41 야구혼을 얻는다.

| 주간 보상 | 4주 회차 보상 | 4주 주간 보상 | 총 획득 중 주간 비중 | 판정 |
|---:|---:|---:|---:|---|
| 25 | 164 | 100 | 37.8% | 과다 |
| 15 | 164 | 60 | 26.7% | 최종 적용 |

같은 주 보상 ID는 한 번만 지급한다. 고교·주간 진행·외부 보상·프로 정산은 저장 성공 뒤에만 확정하며 실패하면 원상 복구 후 같은 행동을 한 번 재시도할 수 있다.

## 8. 출시 판단과 후속 측정

내부 출시 가드:

- UI 정보 활용·일관된 방향 각각 35~55%, 방향 차이 15%p 이하.
- 방향 분산 20~40%, 실제 저관리 5~20%.
- `luck_flip_rate` 10% 이하.
- 각 바람은 전체 지명률 대비 ±12%p.
- 대표 유산 후보 정확히 3개, 직접 적용 정확히 1개.
- 저장 유실·중복 보상·선택과 다른 효과 재현 0건.

출시 뒤 반드시 다시 볼 지표:

- 한 선수의 실제 활성 시간이 60~90분인지.
- 첫 공식 경기 이후 두 번째 세션 복귀가 늘었는지.
- 결말 노출 → 대표 유산 선택 → 다음 선수 시작 전환.
- 시작 방향·목표 카드·바람별 실제 선택과 달성률.
- 프로 보상 사용자가 자동 누적과 지갑 차이를 이해하는지.

정식 코호트가 충분하기 전에는 이 구현이 D1·D7 또는 다운로드를 올렸다고 주장하지 않는다.
