# 야구 못하면 또 환생함 Steam 스토어 페이지 초안

기준일: 2026-07-22
상태: Steamworks App ID 발급 전 초안

## 제품명

공식 제품명은 `야구 못하면 또 환생함`으로 확정한다. Steam 사전 출시 검토 전 한국·미국·유럽의 게임 소프트웨어 상표 검색과 전문가 확인을 거쳐 충돌 가능성을 점검한다.

## 짧은 설명

포수의 사인을 읽고 한 공을 고르세요. 고교 시절의 훈련과 관계가 중요 경기, 드래프트, 프로 커리어로 이어지는 투수 육성 로그라이트 RPG입니다.

## 소개 첫 문단

모든 경기를 직접 던질 필요는 없습니다. 평범한 날은 빠르게 지나가고, 결과를 바꿀 수 있는 순간에만 마운드에 오릅니다. 구종, 코스, 승부 방식, 힘 조절을 고른 뒤 실제 제구와 타자의 노림수가 맞부딪히는 결과를 확인하세요.

## 주요 특징

### 한 공에 담긴 선택

포수는 상대 타자의 약점과 지금까지의 승부를 바탕으로 사인을 냅니다. 그대로 던질지, 다른 구종을 택할지, 존 가장자리를 노릴지 결정하는 것은 플레이어입니다. 좋은 선택도 실행이 흔들릴 수 있고, 위험한 선택도 완벽한 공 하나로 살아날 수 있습니다.

### 중요한 순간은 직접 투구

모든 이닝을 반복하지 않습니다. 라이벌과 다시 만난 경기, 감독의 신뢰가 걸린 등판, 드래프트 평가가 바뀌는 승부처에서 직접 공을 던집니다. 결과 화면은 단순히 성공과 실패만 말하지 않고 선택과 실행 중 무엇이 영향을 줬는지 보여 줍니다.

### 고교 3년이 프로 커리어로

학교, 훈련, 감독, 포수, 라이벌과의 관계가 선수의 구종과 평가를 바꿉니다. 드래프트에서 지명되면 같은 선수로 2군 경쟁, 1군 콜업, 보직 변화, 계약, FA와 은퇴까지 이어집니다.

### 실패 뒤에 남는 기억

지명받지 못한 선수의 기록도 사라지지 않습니다. 다음 선수에게 남길 기억을 고르고 다시 시작하면 이전에는 없던 성장 방향과 선택지가 열립니다.

### 빠르게 진행하고 오래 고민하기

반복 경기는 압축하고 훈련, 관계, 중요 이닝에 시간을 집중합니다. 야구 규칙을 잘 몰라도 포수 추천으로 시작할 수 있으며, 익숙해질수록 상대의 노림수와 반복 패턴을 읽을 수 있습니다.

## 정식판에 포함할 기능

- 자유 선수 생성과 네 가지 투수 유형
- 학교·감독·포수·라이벌 조합
- 훈련, 관계, 각성과 다섯 번의 중요 경기
- 드래프트 지명과 미지명 양쪽의 완결 경로
- 최대 12시즌 프로 커리어, 보직 경쟁, 계약, FA와 은퇴
- 기억을 남기는 다음 선수 시작
- 키보드 전용 조작, 글자 확대, 고대비, 모션 감소
- Windows와 macOS 사이의 Steam Cloud 저장 동기화

마지막 항목은 실제 Auto-Cloud 교차 기기 검증을 통과한 뒤에만 스토어 기능 목록에 게시한다.

## 데모 설명

첫 선수를 만들고 학교를 고른 뒤 훈련과 관계 선택을 경험합니다. 첫 중요 경기에서는 포수의 사인을 참고해 직접 한 이닝을 던집니다. 경기 결과와 선수 기록은 정식판에서 그대로 이어집니다.

예상 플레이 시간: 30~45분.

## 지원 범위 초안

- 인터페이스: 한국어
- 자막·게임 텍스트: 한국어
- 음성: 없음
- 플레이어: 싱글 플레이
- 입력: 키보드·마우스
- 첫 출시 OS: Windows 11 64비트
- macOS: Developer ID 서명·공증과 Intel/Apple Silicon QA 통과 후 표시
- Steam Deck: 현재 지원 표시하지 않음

## 시스템 요구 사항

CPU, 메모리, 저장 공간의 숫자는 Windows 실기기와 저사양 VM 프로파일링 전에는 게시하지 않는다. 현재 확정할 수 있는 요구 사항은 Windows 11 64비트와 WebView2 Evergreen Runtime뿐이다. Steam 검토 제출 전 설치 크기, 최고 메모리, 첫 실행 시간을 측정해 최소·권장 사양을 작성한다.

## 공개 전 문구 검토

- `야구 못하면 또 환생함` 명칭의 상표 충돌 확인
- 실제 KBO·MLB 구단, 선수, 리그를 연상시키는 명칭·로고 최종 확인
- 콘텐츠 설문의 생성형 AI 항목에 Steam 키아트 제작 방식과 사람이 수행한 권리·유사성 검수를 정확히 공개
- 개인정보 처리방침과 고객지원 주소 연결
- 환불을 게임 내부에서 별도 약속하지 않고 Steam 환불 정책으로 안내
- 게임 내부에서 사용자 리뷰를 요청하거나 보상을 제안하지 않음
