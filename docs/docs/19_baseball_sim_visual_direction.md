## 1. 문제 정의

기존 화면은 의미색, 타이포, 접근성, 결과 피드백은 정돈됐지만 다음 이유로 “그림판으로 그린 관리 화면”처럼 보였다.

- 거의 모든 면이 같은 암록 카드여서 앞·중간·뒤 공간감이 없었다.
- 야구장, 더그아웃, 선수, 장비가 없어 텍스트를 읽기 전에는 야구 게임임을 알기 어려웠다.
- 정보 위계는 있었지만 장면 위계가 없어서 커리어 시작과 일반 설정 화면의 감정 밀도가 같았다.
- 카드 모서리, 선, 그라디언트만 다듬어 미술 방향의 부재를 CSS 완성도로 가렸다.

## 3. 고유 방향: Midnight Dugout

“야간 경기 직전, 더그아웃에서 다음 선택을 내리는 순간”을 기준 장면으로 삼는다.

- 색: 기존 암록 캔버스는 야간 구장의 그림자, 라임은 전광판/행동, 골드는 커리어 보상으로 해석한다.
- 조명: 차가운 구장 조명과 따뜻한 더그아웃 조명을 함께 사용한다.
- 인물: 실존 선수·구단과 닮지 않은 한국 고교 야구 인물, 과장되지 않은 반사실적 표현을 사용한다.
- 구도: 텍스트가 놓일 쪽에는 어두운 여백을 남기고 인물이나 조명은 반대쪽에 배치한다.
- 질감: 유니폼 천, 흙, 금속 펜스, 종이 기록지 정도만 허용한다. 무작위 네온과 유리 효과는 사용하지 않는다.

## 4. 이미지 사용 규칙

### 큰 키아트

- 커리어 진입: 투수의 등과 더그아웃, 텍스트는 왼쪽.
- 현재 커리어: 야간 구장 전경, 선수 상태·다음 행동이 그 위에 놓인다.
- 연결 대기: 빈 카드 대신 조명이 켜진 구장과 명시적인 연결 상태를 보여 준다.
- 이미지 위에는 두 단계 이상의 의미 오버레이를 사용해 본문 대비를 유지한다.

### 역할 인물

- 감독·포수·라이벌처럼 플레이 선택에 직접 영향을 주는 인물만 표시한다.
- 인물 사진은 이름 대신 역할과 분위기를 강화하는 보조 자산이다. 텍스트가 항상 정체성의 원본이다.
- 동일 초상을 동시에 여러 이름에 반복하지 않는다. 그래서 학교 선택 목록에는 공통 역할 초상을 넣지 않는다.
- 인물 이미지를 불러오지 못해도 모든 정보와 조작이 그대로 남아야 한다.

### 금지

- 실존 KBO/MLB 로고, 유니폼, 선수와 혼동되는 외형.
- 이미지 안의 임의 문자와 워터마크.
- 모든 카드마다 다른 배경을 넣어 판독을 해치는 구성.
- 결과 수치, 버튼, 긴 본문 바로 뒤의 고대비 디테일.
