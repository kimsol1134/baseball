## 1. 최종 판단

현재 빌드는 초기의 평면적인 관리 화면을 벗어났지만 **전면 적용 완료라고 부를 수 없다.** 색과 타이포는 정돈됐으나 화면의 행동 우선순위, 실패 복구, 결과 전달, 장면 정체성, GameCast 정확성, 자동 검증이 서로 다른 완성도에 머문다.

- 치명적인 데이터 손상이나 전면 진행 불가에 해당하는 P0는 발견하지 않았다.
- 출시를 막아야 할 P1은 모바일 행동 발견성, 코어 실패 상태, Pitcher Lab 결과 전달, 모달 키보드 동작, GameCast 상황 정확성·모션·고대비, 모드별 장면 분리다.
- 현 상태는 약 **6.5/10의 고급 프로토타입**이다. 아래 완료 조건을 모두 충족한 뒤에만 “디자인 시스템 전면 적용”으로 판정한다.

## 2. 개선 원칙

1. **행동이 장식보다 먼저다.** 첫 화면에서 지금 해야 할 선택과 그 결과를 발견할 수 있어야 한다.
2. **수치는 실제 상태만 말한다.** 모델에 없는 학년·신장·등번호·점수는 그럴듯하게 꾸며 넣지 않는다.
3. **결과는 다음 선택 전에 닫는다.** 능력·피로·관계의 변화를 확인한 뒤 다음 단계로 이동한다.
4. **모드마다 하나의 장소성을 갖는다.** 고교, 연구실, 프로, 경기 중계가 같은 전역 배경을 공유하지 않는다.
5. **이미지는 세계를 만들고 UI는 판단을 돕는다.** 한 화면의 큰 시각 앵커는 하나로 제한하고 텍스트 대비를 희생하지 않는다.
6. **접근성 설정은 실제 동작을 바꾼다.** 운영체제 모션 감소와 고대비가 CSS 장식뿐 아니라 RAF 재생·사진 배경에도 적용돼야 한다.
7. **완료는 자동 검증과 실제 화면 검토로 증명한다.** 토큰 검사 통과만으로 반응형·포커스·상태 정확성을 주장하지 않는다.

## 4. 화면별 적용 결정

### 고교 커리어

- 모바일 현재 행동 바로가기를 히어로 직후에 둔다.
- 능력치 증감 버튼에 지표 이름이 포함된 접근 가능한 이름을 부여한다.
- 튜토리얼과 드래프트 공개를 공통 모달 동작으로 통합한다.
- 학교색은 데이터 ID에서 파생한 의미 토큰으로만 표현하고 실존 학교·구단 문양을 만들지 않는다.

### Pitcher Lab

- 진입 실패를 공통 복구 화면으로 대체한다.
- 훈련 문구를 확정적 상승이 아닌 가능성·피로·반복 감쇠 언어로 바꾼다.
- 결과 전후 값, 피로, 관계 변화를 확인하는 단계를 고교 커리어와 같은 패턴으로 제공한다.
- 연구실은 사진을 추가로 겹치지 않고 TRACKLAB 좌표·계측 질감으로 장소성을 만든다.

### 프로 커리어

- 고교 전역 배경 의존을 제거하고 구장·기록 보드 중심의 프로 장면을 사용한다.
- 데이터에 없는 키·학년·등번호는 삭제한다.
- 구단별 강조색은 가상 구단 ID에만 매핑한다.

### GameCast

- 투구는 TRACKLAB 분석 좌표계, 인플레이는 구장 시점으로 역할을 분리한다.
- 리플레이 표시 상태는 반드시 결과 스냅샷을 기준으로 한다.
- OS 모션 감소, 앱 모션 감소, 고대비를 동일한 렌더 분기로 연결한다.
- 배경과 SVG가 서로 다른 카메라로 움직이지 않도록 사진은 변형하지 않고 안전 크롭을 사용한다.

## 5. 자산·세계관 계약

- 기본 배포물에 실존 프로 구단명, 구단 약칭, 리그명, 선수명, 로고, 유니폼 문양, 슬로건을 사용하지 않는다.
- 실제 도시명은 허용하되 가상 학교·구단·대회 명칭은 독자 명칭으로 유지한다.
- 역할 초상은 캐릭터의 신분증이 아니라 분위기를 보조하는 장식 자산이다. 이름과 연결되지 않으면 `alt=""`로 처리한다.
- 생성·파생 자산에는 파일명, 사용 위치, 생성/가공 방식, 실존 인물·상표 검토 결과를 기록한다.
- 고대비 모드에서는 큰 사진 배경을 제거해도 모든 정보와 조작이 남아야 한다.

## 7. 완료 판정

다음 조건을 모두 만족해야 전면 개선 완료로 판정한다.

- IMP-01부터 IMP-10까지 구현되거나, 구현하지 않은 항목에 재현 가능한 기술적 근거가 기록돼 있다.
- 모든 변경이 작업 단위별 커밋으로 분리되어 있다.
- 자동 검사와 전체 테스트가 통과한다.
- 모바일·고대비·모션 감소·코어 실패·GameCast 이닝 전환을 다시 검토한다.
- 실제 화면으로 확인하지 못한 플랫폼은 “검증 완료”라고 표현하지 않고 잔여 한계로 명시한다.
