# Steam 외부 테스트 계획

기준일: 2026-07-22
대상: Windows 정식판 비공개 브랜치와 Steam 데모
표본: 야구 게임 경험자와 비경험자를 섞은 최소 30명

## 1. 테스트 순서

### Wave 0 · 설치 스모크 5명

- 서로 다른 Windows 11 x64 PC와 표준 사용자 계정에서 Steam 설치, 첫 실행, 종료, 재실행, 업데이트, 삭제를 확인한다.
- 첫 선수 생성부터 자동 저장이 생기는 지점까지 진행하고, 강제 종료 뒤 마지막 확정 선택에서 재개한다.
- sidecar 실행 실패, WebView2 누락, 백신 격리, 한글 경로와 비 ASCII Windows 사용자명 문제를 기록한다.
- 진행 불가·저장 유실·반복 크래시가 한 건이라도 나오면 다음 Wave로 가지 않는다.

### Wave 1 · 데모 관찰 15명

- 설명 없이 데모를 시작하게 하고 첫 중요 경기 종료까지 화면과 발화를 관찰한다.
- 참가자의 절반 이상은 야구 게임을 평소 즐기지 않는 사용자로 구성한다.
- 로컬 분석 내보내기는 명시적으로 동의한 참가자에게만 받는다.
- 세션 직후 아래 질문을 같은 순서로 묻는다.

1. 가장 기억나는 순간은 무엇이었는가.
2. 마지막 승부 결과에 본인의 선택과 투구 실행이 각각 어떤 영향을 줬는가.
3. 감독, 포수, 라이벌 중 기억나는 인물과 그 이유는 무엇인가.
4. 막히거나 읽지 않고 넘긴 화면은 어디였는가.
5. 정식판에서 이 선수를 계속 키우고 싶은가. 아니라면 어디에서 흥미를 잃었는가.

### Wave 2 · 출시 후보 15명 이상

- Wave 1의 치명·고빈도 문제를 수정한 새 빌드만 사용한다.
- 데모 저장을 정식판에서 불러오고, 서로 다른 두 PC 또는 Windows·macOS 사이에서 Steam Auto-Cloud 복원을 확인한다.
- 정식판 참가자 중 최소 10개 고정 시드가 프로 은퇴까지 진행되는지 확인한다.
- Steam 상점이 공개된 뒤에는 데모 종료 화면의 상점 이동과 실제 위시리스트 추가 여부를 별도로 기록한다.

## 2. 출시 판정 기준

| 항목 | 통과 기준 |
|---|---|
| 치명적 안정성 | 진행 불가, 저장 유실, 반복 크래시 0건 |
| 설치 호환성 | Wave 0의 5대 모두 설치·실행·업데이트·삭제 성공 |
| 데모 완료 | 시작자의 70% 이상이 도움 없이 첫 중요 경기와 종료 화면 도달 |
| 플레이 시간 | 완료자 중앙값 25~50분 |
| 인과 이해 | 완료자의 70% 이상이 선택과 실행을 구분해 결과 원인 하나 이상 설명 |
| 인물 기억 | 완료자의 60% 이상이 감독·포수·라이벌 중 한 명과 구체적 장면을 회상 |
| 계속할 의향 | 완료자의 50% 이상이 같은 선수로 정식판을 이어갈 의향 표시 |
| 풀 커리어 | 10개 이상 시드에서 프로 은퇴까지 진행 불가 없이 완주 |
| 저장 승계 | 데모→정식판 및 Auto-Cloud 교차 기기 복원 100% 성공 |

비율 기준은 첫 외부 표본을 위한 가설이다. 수치를 맞추려고 드래프트 확률이나 난도를 몰래 바꾸지 않는다. 실패 지점의 관찰과 참가자 설명을 함께 보고 UI, 페이스, 피드백을 수정한 뒤 같은 문항으로 다시 측정한다.

## 3. 결함 우선순위

| 등급 | 예시 | 처리 |
|---|---|---|
| S0 | 저장 유실, 실행 불가, 진행 불가, 결제·권한 오류 | 즉시 중단, 수정 후 전체 Wave 재시작 |
| S1 | 중요 이닝 입력 불가, 데모가 끝나지 않음, 정식판 저장 승계 실패 | 해당 Wave 중단, 회귀 테스트 추가 |
| S2 | 핵심 원인 오해, 반복되는 대사, 중요한 버튼 탐색 실패 | 출시 후보 전에 수정하고 재측정 |
| S3 | 사소한 정렬·문구·연출 문제 | 묶어서 수정하되 출시 차단 여부 별도 판단 |

## 4. 기록물

- 빌드 버전, Steam 브랜치, OS·CPU·메모리·화면 배율
- 세션 시작·종료 시각, 완료 단계, 중단 이유
- 동의받은 로컬 분석 JSON과 결함 재현 절차
- 질문의 원문 답변과 관찰자의 해석을 분리한 기록
- 수정 전후 빌드의 지표 비교와 잔존 S0/S1 목록

개인정보와 영상·음성 기록은 별도 동의 없이 수집하지 않는다. 참가자 이름 대신 테스트 ID를 사용하며, 외부 전송 기능은 기본으로 켜지 않는다.
