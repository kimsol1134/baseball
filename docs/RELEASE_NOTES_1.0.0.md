# 야구 못하면 또 환생함 1.0.0 출시 노트

야구 못하면 또 환생함의 첫 무료 고교 커리어 출시 후보다. 선수를 만들고 세 계절 동안 훈련과 관계를 선택하며, 중요한 이닝은 직접 투구한다. 마지막에는 드래프트 결과 또는 다음 삶에 남길 기억으로 커리어가 이어진다.

## 핵심 기능

- 구종·코스·존 의도·강도를 고르는 결정론적 투구 시뮬레이션
- 포수의 기본 콜 자동 적용, 대안 콜, 직전 선택 반복
- 목표와 실제 투구 궤적, 한 줄 결과 우선 공개, 상세 분석 접기
- 공·미트·타격·마일스톤 절차적 효과음과 선택적 진동
- 감독·포수 성향과 라이벌 상황에 따라 달라지는 관계 결과
- 최근 훈련과 경기 내용을 반영하는 각성 후보 3개와 장단점
- 결과를 미리 확정한 뒤 순서대로 보여 주는 드래프트 발표
- 미지명 뒤 서로 다른 구종·능력 변화를 남기는 기억 18개
- 자동 저장, 손상 복구, 정상 백업 3개 순환
- 고대비, 글자 확대, 모션 감소, 효과음·진동 개별 설정

## 함께 구현된 다음 단계

- 기록 기반 1군 콜업과 보직 변화, 3주 반복, 수상·마일스톤을 갖춘 프로 커리어
- 세 가지 중요 승부 전략, 성공 햅틱, 커리어 타임라인을 갖춘 SwiftUI iOS 클라이언트

프로 커리어는 검증된 구매·복원 어댑터가 연결되기 전 공개 빌드에서 잠긴다. iOS는 generic Simulator 빌드까지 검증됐으며 실제 장치 QA와 StoreKit 연동 전에는 배포 범위가 아니다.

## 알려진 출시 조건

- macOS 공개 배포에는 Developer ID 서명과 Apple 공증이 필요하다.
- Windows NSIS 설치 파일은 원격 CI에서 생성·무인 설치·Swift 엔진 상태 검사까지 통과했다. Steam 무설치 데포와 깨끗한 Windows 11 Steam 클라이언트 검증은 남아 있다.
- 게임의 재미와 반복 의향은 외부 플레이테스트를 통과해야 하며 자동 테스트로 대체하지 않는다.

자세한 상태는 [출시 체크리스트](./RELEASE_1_0_CHECKLIST.md)와 [QA 게이트](./QA_RELEASE_GATES.md)에서 확인한다.
