## 페르소나 정의 (플레이 전에 확정)

### P1 `light-fan` — 박하은, 28, 콘텐츠 마케터

- **야구 지식:** 주말 중계는 본다. 스트라이크·볼·홈런은 안다. ERA·WAR·보직 용어는 모른다. 시뮬 게임은 처음.
- **플레이 습관:** 출퇴근·잠들기 전 10~15분. 길게 붙잡지 않는다.
- **기대:** “내가 투수가 돼서 공을 던진다”는 손맛. 스토리는 있으면 좋고 없어도 된다.
- **인내심:** 한 화면에서 뭘 눌러야 할지 30초면 초조, 2분이면 이탈을 고민, 5분이면 나간다.
- **읽기 성향:** 훑는다. 두 줄 넘는 설명은 건너뛴다. 큰 버튼만 본다.

**의사결정 규칙**
1. 화면에 가장 크고 아래쪽에 있는 주 버튼(시작하기·다음·훈련하기)을 바로 누른다.
2. 이름은 `민서준 쓰기`로 채운다. 지역은 첫 권역의 첫 도시. 유형·구종은 기본값 유지.
3. 목표는 `목표 없이 시작`. 학교는 맨 위 카드.
4. 훈련은 맨 위 카드 + `같은 훈련 최대 3회`. 포수 제안은 항상 수락. 승부는 던지기 버튼을 연타하고, 보이면 타자 빨리 넘기기를 쓴다.
5. 선택지는 글자가 가장 짧은 것. 설정은 건드리지 않거나 글자만 조금 키운다. 피로 숫자는 안 본다.

### P2 `sim-veteran` — 정민호, 34, 게임 QA / 육성 시뮬 다수 경험

- **야구 지식:** 구종·보직·피로·스카우팅을 읽는다. 숫자의 단위가 흔들리면 바로 적는다.
- **플레이 습관:** 위키를 켜 두고 최적화를 찾는다. 한 세션 40분도 버틴다.
- **기대:** 규칙이 일관되고, 선택이 능력치·지명에 실제로 이어질 것.
- **인내심:** 막혀도 규칙을 찾아 본다. 용어 오류·같은 말 반복·숨은 버튼에는 빨리 짜증.
- **읽기 성향:** 다 읽는다. 용어 링크가 있으면 연다.

**의사결정 규칙**
1. 선수 만들기에서 이름·지역·유형·구종을 직접 고른다. 제구형, 우완, 학습 구종은 변화구.
2. 목표는 가장 야심 있는 카드. 학교는 설명에 지명·경쟁이 적힌 쪽.
3. 훈련은 제구/변화구 집중. 피로가 높거나 회복 카드가 권장이면 회복. 강도는 가능한 한 높게.
4. 관계 선택은 성장·신뢰가 커 보이는 쪽. 포수 제안은 읽고, 내 구종과 다르면 바꾼 뒤 던진다.
5. 프로는 선발 보직을 노리고, 주간 계획은 능력 성장 카드를 고른 뒤 구간 자동 진행. 기록·설정(설명 밀도 높음)을 열어 숫자를 대조한다.

### P3 `casual-story` — 이수빈, 24, 웹툰 작가

- **야구 지식:** 만화·드라마로 야구를 안다. 능력치 표는 부담이다.
- **플레이 습관:** 대사와 캐릭터가 재밌으면 남고, 같은 훈련을 반복하면 접는다.
- **기대:** 감독·포수·라이벌과의 관계, “이 선수의 3년”이 이야기로 남을 것.
- **인내심:** 반복 작업 1~2분이면 자동 진행을 찾고, 없으면 이탈.
- **읽기 성향:** 대사는 다 읽고 시스템 설명은 훑는다.

**의사결정 규칙**
1. 이름은 직접 짓고, 지역은 이야기가 있어 보이는 도시. 유형은 캐릭터가 선명해 보이는 카드.
2. 목표는 서사 문장이 긴 것. 학교는 교훈· rival 문구가 있는 카드.
3. 훈련은 자동 3회를 쓰고 빨리 대화로 돌아간다. 관계 선택지는 사람·마음을 고른다.
4. 승부는 몇 구만 던지고 타자 빨리 넘기기를 쓴다. 포수는 이야기의 파트너라 제안을 따른다.
5. 설정에서 글자 크기와 설명 밀도를 올린다. 프로는 계약 문장을 읽고 수락한 뒤, 반복 주는 자동 진행으로 넘긴다.

## 4. 개발팀 우선순위 제안

1. **탭 바 vs 주 행동 (P0).** 훈련 커밋, 학교 카드, 목표, 각성 첫 노드, 관계 선택지, 계약 서명/연봉이 스크롤 없이 탭 바 위에 오게. 플로팅 탭 바 클리어런스를 계약·목표에도 적용.
2. **고교 HUD에 드래프트 거리.** 현재 없음 → 예: `지명 전망 61 / 당락선 66`. P2가 2회차 프로 허브에서야 본 줄을 1학년 봄부터.
3. **목표·관계 탭이 하단 탭을 먹지 않게.** 현재: 목표 카드 탭 → 프로 허브. → 히트 영역을 카드 안으로, 탭 바 `simultaneousGesture` 정리.
4. **계약: 장기 목표 + 서명 + 확인을 한 스크롤에.** 현재 `서명하려면 목표 하나를 선택하세요`가 접힌 아래. 서명 비활성 이유를 버튼 위에 고정.
5. **확인 알럿 접근성.** `제안 수락` id 중복 제거. 알럿 버튼은 유일 id 하나.
6. **3년 돌아보기 첫 프레임.** 현재 제목만 있는 빈 화면 → 미지명/지명 칩이 첫 프레임에.
7. **프로 `오늘` vs `이번 주`.** 현재 `위의 '이번 주'에서 다음 일정을 확인하세요.` → `이번 주 계획 열기` 버튼 하나. 또는 오늘 탭에 주간 계획 요약.
8. **문구.**
   - 현재 `다음 경로 확인`(스킬트리) → `아직 찍은 스킬 없음 · 경로 보기`
   - 현재 `시드 또는 카드 공유 코드 (선택)` → `친구 코드가 있으면 붙여 넣으세요 (없어도 됩니다)`
   - 현재 `서명하려면 목표 하나를 선택하세요.` → `아래에서 장기 목표를 고르면 서명할 수 있습니다`
   - 현재 `고교를 건너뛰고 바로 프로 시작` 본문 → `이 경로는 고교 3년 성장 없이 시드로 지명됩니다. 첫 회차에는 추천하지 않습니다`
9. **피로 100 경고.** 구위만 반복하면 목표(피로 78 이하)와 팔이 동시에 깨진다. 훈련 카드에 `지금은 회복이 안전` 칩을 라이트 팬도 보이게.
10. **2시즌 루프 검증.** 이번 세션에서 정규 경로 2시즌 결산은 재현하지 못했다(미지명 2 / 지명 후 계약에서 시간 소진 1). 지명 빌드 + 주간 구간 진행으로 결산 2회를 별도 스모크로.
