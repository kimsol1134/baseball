# 등판·시즌 기록·각성 개선 검증

2026-09-08 / Android QA / `android/core-fun-quality-2026-09-07`

## 구현

- 고교·프로의 새 직접 등판은 타석이 끝나도 다음 타자를 상대한다. 주자, 점수 차, 투구 수, 피로를 유지하며 타순을 순환한다. 특별한 승부처의 진입 아웃 수는 유지한다.
- 고교 정규 선발 등판은 1회 무사에서 시작한다. 이닝 종료 후 계속 던지기 또는 남은 경기 자동 진행을 직접 선택한다. 투구 수·피로·이닝 한도를 넘으면 연장하지 않는다.
- 고교 정규 등판의 자동 잔여 구간은 같은 투구 커널로 계산한다. 수동·자동 구간은 동일 경기 번호로 합쳐 표시한다. 자동 구간에는 퍼펙트 릴리스·직접 투구 업적을 주지 않는다.
- 장별 자동 경기의 개별 이닝·삼진·볼넷·안타·홈런·실점과 경기 점수를 저장한다. 다음 장 이동이 없는 마지막 장도 드래프트 전에 정산한다. 기존 저장에서 개별 기록이 없는 자동 경기는 알려진 이닝·실점만 합산한다.
- 프로의 기존 자동 경기와 수동 구간을 합산하는 정산 구조를 유지하고, 전체 시즌 등판 목록을 표시한다.
- 새 직접·자동 투구의 힘배분은 균형 대비 제구 우선 −2.5km/h, 전력 +2.5km/h를 기본으로 한다. 피로·구종 상한은 별도로 적용하며 UI와 실제 구속은 동일 계산을 사용한다.
- 드래프트는 전체 시즌 이닝에 따른 근거의 양과 실점률을 반영한다. 짧은 수동 구간의 누적 삼진만으로 평가가 과도하게 증가하지 않도록 정규화한다. 이미 확정된 결과는 다시 판정하지 않는다.
- 새 고교 일정은 첫 각성과 후반부 두 번째 각성을 제공한다. 두 번째에는 훈련 6회·시즌 12이닝 조건이 있고, 상위 각성은 환생·능력 조건을 요구한다. 기존 보유 스킬과 이미 제시된 선택지는 유지한다.
- 점수 차에 맞는 동점·역전 주자 안내, 선수 상세 명칭, 주간 과제의 한국어 이름, 원탭 릴리스 햅틱을 추가했다. 원탭은 중립 판정이며 기본 조작은 슬라이더다.
- 각성 18종에 개별 WebP 그림을 연결했다. 합계 894,142바이트. 폭발적 직구 그림의 중복 투수와 일관되지 않은 글러브는 제거하고, 한 명의 우투수가 왼손 글러브와 맨손인 오른손으로 구분되도록 수정했다. 대표 스킬 이름은 기존 네이티브 현지화 UI가 표시한다.

## 저장 호환성

새 등판/타석 ID의 `outing-v2` 표식으로 새 종료·힘배분 규칙을 구분한다. 기존 예약 투구의 ID·준비 토큰·판정 경로는 유지한다. 새 `ContinueOuting` 명령은 기존 명령 코덱에 추가했으며, 기존 명령 인코딩을 변경하지 않았다. 준비 토큰이 맞지 않으면 계속 거부한다.

## 검증

- 핵심 테스트 32개 통과: 고교 8장, 저장 경계 재시작, 프로 20시즌, 구속 차이, 다음 타자·이닝, 자동 잔여 구간, 기록 합산, 각성 수, 과거 준비 토큰.
- 관련 애플리케이션 테스트 32개 통과: 실제 네이티브 저장소에서 이닝 연장 후 재시작·후속 투구·경기 카운터 불변, 스코어보드, 각성 조건, 현지화 등.
- 별도 장기 커리어·프로 진입·20시즌 은퇴·환생·화면 투영 검증 39개 통과. 후속 정산/문구 수정은 위 핵심·관련 테스트와 패키지 스모크로 확인했다.
- 네 가지 투수 유형 × 입력 정확도 450/750/1000 × 30개 시드 = 직접 투구 360이닝. 모든 조합에서 안타 발생. 안타나 드래프트 결과를 강제로 만드는 보정은 추가하지 않았다.
- 고교 3년 8개 시드: 총 97.1~104.1이닝, 각성 2개, 지명 4회·미지명 4회. 이는 작은 회귀 표본이며 출시 전체 분포를 추정하는 수치는 아니다.
- 에뮬레이터 UI 테스트 10개 통과: 이닝 종료 선택 유지, 개별 그림 18종, 중립 원탭, 기본 슬라이더 실제 입력, 구종·코스·힘배분 노출, 온보딩 전환, 큰 글꼴 및 공통 버튼.
- `assembleDebug`, `assembleDebugAndroidTest`, `git diff --check` 통과. 추가 문구의 실존 구단·리그 이름 검색 결과 없음.
