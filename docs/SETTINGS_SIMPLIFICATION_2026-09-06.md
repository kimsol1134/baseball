# Android 설정 간소화와 추가 오류 수정

2026-09-06. 제안한 설정 구조를 구현하고 Galaxy A53에서 검증했다. 현재 플레이용 core QA 앱을 최신 빌드 42로 업데이트했다. 설치 전후 기존 저장 파일의 SHA-256이 같음을 확인했다.

## 실제 변경

기본 화면에는 효과음·배경 음악·진동 스위치와 조작/화면·알림·저장/기록·도움말 링크만 남겼다. 같은 설정의 상태 설명과 실행 버튼을 중복해서 보여주지 않는다.

- 설정을 바꿔도 현재 설정 페이지를 유지한다. 저장이 끝난 실제 값이 스위치에 반영되고 저장 중에는 중복 변경을 막는다.
- 자동 투구·대비·움직임 옵션은 ‘조작과 화면’에 모았다. 직접 슬라이더가 기본이며, 보조 조작 이름은 ‘한 번 눌러 던지기’다.
- 알림은 실제 기기 권한 상태와 변경 버튼을 보여준다.
- 파일 보관·불러오기·전체 진행 삭제는 ‘저장과 기록’ 안에 모았다. 파일을 복원하면 ‘이어서 플레이’로 복원한 기록의 목적지로 이동할 수 있다.
- 용어집 29개는 도움말 안에서 검색하고 원하는 항목만 펼친다. 설정 첫 화면에 용어 설명·도전 코드·기록 이야기를 나열하지 않는다.
- 한국어·영어·일본어와 시스템 글자 크기를 지원한다.

## 확인해서 고친 문제

| 문제 | 수정 |
|---|---|
| 설정 하나를 바꿀 때마다 게임 화면으로 나감 | 설정 변경은 같은 페이지에 머문다. 게임으로 돌아간 뒤 불필요한 추가 뒤로 가기 단계도 제거했다. |
| 설정 저장 실패의 안내가 긴 화면 위쪽에 가려짐 | 현재 설정 화면의 고정 영역에 오류를 표시한다. 실패한 변경을 저장된 값처럼 표시하지 않는다. |
| 투구 중 보조 옵션 저장 오류가 처리되지 않거나 안내가 일반 HUD 문구에 가려짐 | 오류를 처리하고 별도 대화상자에 표시한다. 투구 저장·불러오기·결과 저장 실패도 같은 표시 경로를 쓴다. |
| 보관한 기록에서 음악 설정을 복원해도 즉시 재생 상태에 반영되지 않을 수 있음 | 전면에 있는 앱에서 복원된 음악 설정을 적용한다. 배경에 있는 메인 화면이 임의로 음악을 재개하지 않게 했다. |
| 도전 중 파일 복원으로 보관 중인 정규 커리어를 덮어쓸 수 있음 | 도전 중에는 보관·복원을 막고, 도전 스냅샷을 일반 커리어 백업으로 불러오지 못하게 UI와 저장 계층에서 모두 검사한다. |

이전 턴에 수정한 진행 삭제의 확인창·취소·실제 삭제·재시작 동작도 새 설정 구조에서 다시 검사했다.

## 검증

- 저장·커리어 애플리케이션 전체 회귀 검사를 실행했다. 통과한 113개 외에 테스트 선언/세션 조건을 바로잡은 백업 2개도 재실행해 통과했다.
- 저장 계층 14개, 앱 단위 10개 통과. 삭제·백업 경계는 최종 변경 뒤 다시 검사했다.
- Galaxy A53 한국어·영어·일본어 설정 흐름 통과: 옵션 변경 후 페이지 유지, 설정 저장/재로드, 고의 저장 실패와 재시도, 보조 조작·대비·움직임, 용어 검색, 파일 선택 취소 시 커리어 보존.
- 글자 크기 2배의 3개 언어 화면 검사와 알림 권한/페이로드/화면 연결 검사, 총 6개 통과.
- 새 ‘저장과 기록’ 화면에서 전체 삭제 확인·취소·삭제 후 첫 화면 이동 통과.
- 투구 화면에서 고의로 설정 저장을 실패시킨 뒤 오류 확인 → 기본 수동 슬라이더로 한 구 → 학교 선택까지 통과. 일본어 신규 수동 투구도 통과했다.
- debug/release 컴파일, lint, 소스 경계 검사 통과. 문구 카탈로그 5,698개 일치, Kotlin 문구 2,643개 매핑, 전체 제품 문구 검사와 변경분 공백 검사 통과.
- 실기기 테스트는 별도의 reset QA 앱에서 수행했다. 사용자가 플레이 중인 core QA 기록은 테스트로 삭제하거나 교체하지 않았다.
