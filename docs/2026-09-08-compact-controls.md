# 버튼 크기·줄바꿈 정리

2026-09-08 / Android QA

## 변경

1. 훈련 종류와 강도는 이름만 표시한다. 추천은 제목 옆, 성장 확률·피로·팔 부담은 선택 결과 영역에서 확인한다. 묶음 훈련 순서는 선택한 계획 아래에 한 번만 표시한다.
2. 공통 액션 배치는 버튼의 자연스러운 폭을 유지하고 넘치는 항목만 다음 줄로 보낸다. 훈련·힘배분처럼 같은 크기가 필요한 선택 그룹과 통계 타일은 명시적으로 같은 폭을 요청한다. 네 항목이 한 줄에 들어가지 않으면 두 열로 배치한다.
3. 초기 유형 버튼에서 능력치 설명을 분리했다. 선택한 유형의 기본 능력만 아래에 표시한다. 주 구종·학습 구종은 짧은 선택 그룹으로 배치하고, 색과 고정 폭 체크 표시로 상태를 알린다. 환생 상세 선택의 설명과 야구혼 비용도 버튼 밖에 표시한다.
4. 성장트리 계열 탭은 짧은 제목을 사용하며 전체 계열명은 아래에 표시한다. 습득 버튼은 짧은 동작명으로 유지하고 불가 사유를 밖에 둔다. 기록 탭의 알림 점은 항상 같은 공간을 차지한다. 공유·알림·백업·결과·연습·등판 문구와 높이를 정리했다.

선택 상태와 접근성 이름은 유지한다. 기본 조작인 투구 슬라이더의 64dp 영역과 판정 로직, 훈련 성장·비용·저장 규칙은 변경하지 않는다. 내용이 필요한 스킬 노드와 업적 카드도 일반 버튼처럼 축소하지 않는다.

## 검증

- 문구·성장 표시 로직 JUnit 9개 통과.
- 관련 UI 테스트 32개 통과(최초 28개 및 실패 조건을 수정한 4개 재검증).
- 훈련 선택은 한국어·영어·일본어, 글자 배율 1.0/1.6에서 텍스트 한 줄·추가 설명 없음·터치 영역 48dp 기준을 검증했다. 기본 글씨 버튼 높이는 50dp 이내 허용 오차로 확인했다.
- 짧은 버튼의 불필요한 폭 확장 방지, 필요한 항목만 다음 줄로 이동, 긴 제목과 실행 버튼의 겹침 방지를 검증했다.
- 초기 설정·환생 구종 선택, 성장트리 잠금·습득, 기록·학교·프로필, 훈련 강도·목표 구종·묶음 계획의 실제 선택과 저장을 확인했다.
- 기본 슬라이더의 실 입력으로 한 구가 완료되는 회귀 테스트를 포함했다.
- 작은 뷰포트에서 훈련 후 스크롤 위치 유지, 큰 글씨에서 설명창 접근, 온보딩의 명시적인 다음 단계 동작을 검증했다.
- 기존 훈련 저장 테스트는 설치된 사용자 기록 대신 임시 네이티브 저장소를 쓰도록 변경했고, 저장소 재시작 후 훈련 증거가 유지되는 검증을 보존했다.
- 마지막 상세 옵션 정리 후 초기 설정·안내 전환·기본 슬라이더 등 6개 테스트를 추가 재검증했다.
- `assembleDebug`, `assembleDebugAndroidTest`, `git diff --check` 통과.

검증 이미지는 `artifacts/android-compose/compact-training-final.png`, `compact-awakening-final.png`에 보관했다. 로그는 같은 디렉터리의 `compact-controls-*.log`에 남겼다.

최종 확인 시 ADB에는 `emulator-5554`만 연결되어 있었다. 실기기 업데이트는 연결 후 진행한다.
