# ADR-009: 포지션 수비와 이닝 상태 전이

- 상태: 채택
- 날짜: 2026-07-22

## 맥락

내야·외야 평균 수비와 타석 종료만으로는 누가 타구를 처리했는지, 도루가 아웃카운트에 어떤 영향을 주는지, 병살과 세 번째 아웃 뒤 경기가 어디로 이어지는지 표현할 수 없다. 이 상태를 화면에서 별도로 추측하면 코어와 클라이언트의 이닝·주자 정보가 어긋나고 준비 토큰의 재현성도 깨진다.

## 결정

- 수비는 기존 내야·외야·송구 평균을 호환용 기본값으로 유지하면서 9개 포지션의 범위, 포구와 송구 능력을 선택적으로 받는다.
- 타구 방향과 구역으로 담당 야수를 결정하고 해당 야수의 범위와 포구를 최종 수비 판정에 사용한다.
- 도루는 투구 결과와 분리된 RNG 도메인에서 주자 속도, 포수 송구와 레버리지를 사용해 자동 판정한다.
- 도루 실패는 즉시 아웃으로 기록하며, 2아웃에서는 새로운 도루 시도를 만들지 않는다.
- 1루 주자가 있는 땅볼 아웃은 2루수·유격수의 포구와 송구를 사용해 병살 여부를 판정한다.
- `InningStateSnapshot`을 경기 상태의 기준으로 삼고 투구 문맥의 이닝·아웃과 일치하지 않는 요청은 거부한다.
- `InningTransitionSnapshot`은 전후 상태, 추가 아웃, 병살, 공수 전환과 설명을 한 이벤트로 기록한다.
- 세 번째 아웃이면 주자를 비우고 초에서 말, 말에서 다음 회 초로 전환한다.
- 포지션 수비, 이닝 상태와 주자 상태를 준비 토큰과 이벤트 해시에 포함한다.

## 결과

- 동일한 시드와 상태에서 담당 야수, 도루, 병살과 공수 전환이 항상 동일하다.
- 강한 포수는 장기 표본에서 도루를 더 많이 억제하고, 강한 키스톤 수비는 병살을 더 많이 완성한다.
- React 화면은 코어가 반환한 `GameStateSnapshot`만으로 다음 투구와 새 타석을 준비하므로 상태를 재구성하지 않는다.
- 포지션 배열과 이닝 상태를 생략한 기존 클라이언트는 평균 수비와 기존 문맥으로 계속 동작한다.

## 후속 작업

- 실제 리그 데이터에 맞춰 도루 시도율, 포수 팝타임과 병살 전환율을 보정한다.
- P2 Pitcher Lab에서 중요 이닝 세 개를 연결하고 훈련·포수 관계가 수비 및 주루 판단에 미치는 효과를 추가한다.
