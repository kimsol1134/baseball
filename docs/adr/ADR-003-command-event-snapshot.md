# ADR-003: 명령·이벤트·스냅숏 모델

- 상태: 승인
- 결정일: 2026-07-21

## 맥락

자동 저장, 버그 재현, 밸런스 대량 실험, 세이브 마이그레이션에는 결과를 다시 만들 수 있는 입력 기록이 필요하다. UI가 코어 상태를 직접 수정하면 이 조건을 보장하기 어렵다.

## 결정

- UI는 의도를 나타내는 명령만 전송한다.
- 코어는 검증 후 발생한 사실을 이벤트로 반환한다.
- 이벤트에는 입력 시드, 다음 시드, 결과, 피드백, 비암호학적 안정 해시를 포함한다.
- 상태는 이벤트로부터 투영하고, 장기 실행에서는 일정 간격의 스냅숏을 추가한다.
- 같은 코어·콘텐츠 버전, 초기 상태, 시드, 명령 순서는 같은 이벤트 스트림을 만든다.

## P0 구현

- 명령: `simulatePitch`
- 이벤트: `pitch_resolved`
- RNG: SplitMix64
- 해시: FNV-1a 64-bit

FNV 해시는 재현성 비교용이며 보안이나 변조 방지 용도가 아니다.

## 후속 작업

- P1: 타석·이닝 상태와 이벤트 순번
- P2: 훈련·관계·각성 명령과 이벤트
- P3: 원자적 자동 저장, manifest, 스냅숏, 마이그레이션
