# ADR-012: 무료 고교 1.0 공개 계약

- 상태: 채택
- 날짜: 2026-07-22

## 맥락

P4는 기능 수량뿐 아니라 첫 사용자 이해, 저장 호환성, 개인정보 최소화, 접근성과 외부 콘텐츠의 안전 경계가 필요하다.

## 결정

- 커리어 가혹도·정보 명확도·시뮬레이션 난이도·개입 보조를 독립 축으로 저장하고 상태 커밋에 포함한다.
- 업보는 최대 2개이며 규칙 페널티와 유산 배율을 함께 공개한다. `지워진 기억`만 기억 슬롯을 2장으로 바꾼다.
- 첫 삶 튜토리얼은 한 번만 표시하고 현재 능력 위치, 중요 경기 조작, 선택 확정과 자동 저장만 설명한다. 삶의 의미와 실패·기억의 해석은 실제 플레이 뒤 화면이 드러내게 한다.
- 저장 v1은 원본을 덮지 않고 런타임에서 v2 기본값으로 이행한다. 새 저장은 v2로 쓴다.
- 분석은 기본 미동의이며 동의 후에도 외부 전송 없이 로컬 500개 이벤트만 보관한다.
- 진단 파일은 선수 이름, 시드, 커밋 해시와 자유 입력을 제외한 JSON이다.
- 초기 모드는 실행 코드가 없는 선언형 콘텐츠 팩만 허용한다. 상대 경로와 중복 ID를 검증한다.
- Windows 1.0 입력은 키보드·마우스를 필수로 하고 게임패드는 데이터 밀도와 텍스트 입력 때문에 후속 지원으로 결정한다.

## 결과

공개 빌드의 개인정보·저장·모드 경계가 테스트 가능해졌다. 30명 외부 테스트, 첫 삶 중앙값, 2회차 시작률과 크래시 없는 세션은 제품 외부 측정이므로 릴리스 차단 게이트로 남긴다.
