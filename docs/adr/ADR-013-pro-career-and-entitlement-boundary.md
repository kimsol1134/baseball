# ADR-013: 프로 커리어와 권한 경계

- 상태: 채택
- 날짜: 2026-07-22

## 결정

- 프로 시작은 지명 결과와 활성 `ProEntitlementSnapshot`을 모두 요구한다.
- 구매·복원·오프라인 캐시·개발 권한은 동일한 인터페이스를 사용하며 시뮬레이션 코어는 스토어 SDK를 알지 못한다.
- 프로 상태 머신은 신인 계약, 24주 시즌, 중요 경기, 시즌 회고와 오프시즌을 소유한다.
- 감독 신뢰가 1·2군과 보직을 설명 가능하게 바꾸며 훈련·피로·부상·관계·기록은 같은 커밋에 포함한다.
- 6년 서비스 이후 FA, 1회 군 복무, 33세 이후 노쇠화, 최대 12시즌과 은퇴·명예의 전당 평가를 제공한다.
- Windows 저장은 고교 원본과 프로 상태를 함께 primary/backup으로 보존한다.

## 검증

동일 시드의 20개 커리어를 각각 12시즌 반복해 결정론, 완주, 비음수 자원과 은퇴 평가를 검사한다.
