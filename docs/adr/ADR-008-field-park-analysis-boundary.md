# ADR-008: 타구 결과와 수비·구장·분석의 경계

- 상태: 채택
- 날짜: 2026-07-22

## 맥락

접촉 품질만으로 안타와 아웃을 즉시 결정하면 좋은 투구가 수비 때문에 실패하거나, 강한 타구가 야수 정면으로 가는 야구의 변동성을 설명할 수 없다. 반대로 수비와 구장 확률을 타자 접촉 계산에 섞으면 선택·실행·결과를 분리한 분석이 불가능해진다.

## 결정

- 투구와 타자 반응은 먼저 타구 속도, 발사각, 방향과 중립 결과를 생성한다.
- 수비와 구장 판정은 별도 RNG 도메인에서 중립 결과를 최종 결과로 변환한다.
- 수비는 내야, 외야와 송구 능력을 20~80으로 표현한다.
- 구장은 안타와 홈런 팩터를 중립값 1000 기준으로 표현한다.
- 주자 진루는 타석이 종료된 뒤 최종 결과, 주자 속도와 수비 송구를 사용해 계산한다.
- 준비 토큰에 경기 상태와 분석 로그를 포함해 준비 후 환경을 바꾼 요청을 거부한다.
- 경기 로그는 최근 120구만 보관하며 존율, 헛스윙률, 강한 타구율, 선택·실행 품질, 예상 피해와 실제 피해를 집계한다.
- 예상 피해는 중립 타구 결과를, 실제 피해는 수비·구장이 반영된 최종 결과를 사용한다.
- 작은 표본은 숨기지 않고 신뢰도와 필요한 최소 표본을 함께 표시한다.

## 결과

- 같은 시드, 경기 상태와 투구는 동일한 수비·주루 이벤트를 만든다.
- 좋은 수비와 투수 친화 구장은 장기 표본에서 실점 위험을 낮추지만 개별 결과를 보장하지 않는다.
- 좋은 선택과 실제 안타 허용을 독립적으로 설명할 수 있다.
- 기존 클라이언트는 새 입력을 생략하면 중립 수비·구장과 빈 분석 로그로 계속 동작한다.

## 후속 작업

- P2에서 포지션별 야수, 병살, 도루와 아웃카운트 전이를 추가한다.
- 실제 리그 데이터에 맞춰 선형 가중치와 구장 팩터를 재보정한다.
