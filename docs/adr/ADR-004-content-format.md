# ADR-004: 스키마 기반 콘텐츠와 밸런스 데이터

- 상태: 승인
- 결정일: 2026-07-21

## 맥락

이벤트, 학교, 인물 원형, 구단, 밸런스 수치가 코드에 섞이면 콘텐츠 제작과 회귀 검사가 느려진다. 고정 제품 규칙과 자주 조정할 수치를 구분해야 한다.

## 결정

- 명령·이벤트·콘텐츠 구조는 JSON Schema로 검증한다.
- 밸런스 수치는 P1부터 사람이 읽기 쉬운 YAML 또는 JSON 데이터로 분리한다.
- 모든 콘텐츠 레코드에 고유 ID와 스키마 버전을 둔다.
- 런타임에서 임의 스크립트 실행을 허용하지 않는다.
- 현재 능력의 실제 값과 플레이어에게 노출할 추정값을 별도 필드로 관리한다.

## 현재 상태

- JSON-RPC 요청 스키마
- `simulatePitch` 파라미터 스키마

## 후속 작업

- P1: 능력치와 구종 밸런스 파일
- P2: 훈련·관계·각성 이벤트 스키마
- P3: 학교·감독·포수·라이벌 원형과 로컬라이제이션 키
