# ADR-007: 라이벌 패턴 기억의 공정성 경계

- 상태: 채택
- 날짜: 2026-07-22

## 맥락

라이벌 타자는 이전 대결의 구종과 코스 반복을 학습해야 한다. 그러나 현재 투구 선택을 본 뒤 노림수를 바꾸거나, 표본이 적은데도 완벽하게 대응하면 플레이어가 결과를 신뢰할 수 없다.

## 결정

- 라이벌 기억은 같은 투수–타자 매치업의 공개된 과거 투구만 보관한다.
- 최근 관찰은 최대 24구로 제한하고 구종, 목표 코스, 존 의도, 당시 카운트와 결과만 저장한다.
- 현재 공의 타자 계획과 포수 추천은 플레이어의 투구 입력 전에 기억 스냅숏을 읽어 확정한다.
- 현재 투구는 결과가 확정된 뒤에만 기억에 추가하며 다음 공부터 사용할 수 있다.
- 준비 토큰에 기억 스냅숏을 포함해 준비 이후 기억을 바꾼 요청을 거부한다.
- 표본 수, 구종 집중도, 코스 집중도와 재대결 횟수로 적응 수준을 계산한다.
- 첫 타석의 적응 상한을 두고, 적은 표본에서는 패턴을 확정하지 않는다.
- 라이벌의 적응은 노림수 확률과 인식에 영향을 주지만 결과를 직접 지정하지 않는다.
- 포수는 동일한 공개 기억에서 반복을 감지했을 때 다른 구종을 추천할 수 있다.

## 결과

- 같은 시드, 상태, 기억과 투구는 항상 같은 이벤트를 만든다.
- 첫 대결의 단일 해법을 그대로 반복하면 재대결에서 평균 손해가 발생한다.
- 구종과 코스를 섞으면 적응을 늦출 수 있지만 결과를 보장하지 않는다.
- 이벤트 로그와 기억 스냅숏만으로 라이벌의 판단 근거를 재현할 수 있다.

## 후속 작업

- P2에서 라이벌별 분석 능력과 기억 길이를 콘텐츠 데이터로 분리한다.
- 경기 후 분석에 카운트별 패턴과 예상 피해 변화를 표시한다.
