# ADR-011: 고교 커리어 챕터 상태 머신과 드래프트 수요

- 상태: 채택
- 날짜: 2026-07-22

## 맥락

고교 3년은 훈련 횟수만 늘린 Pitcher Lab이 아니다. 학교 철학, 감독·포수·라이벌 관계, 중요한 경기, 각성, 뉴스와 프로 구단 수요가 같은 시간축에서 재조합되어야 한다. 화면이 이 순서를 소유하면 챕터를 건너뛰거나 드래프트 입력을 바꾸는 문제가 생긴다.

## 결정

- Swift 코어가 중학교 프롤로그, 학교 선택, 8개 챕터와 각 챕터의 훈련·관계·각성·중요 경기 순서를 소유한다.
- 한 삶은 훈련 16회, 관계 사건 5회, 중요 경기 5회, 각성 3회를 거쳐 드래프트에 도달한다.
- 학교 4종은 서로 다른 훈련 보너스와 명시적 trade-off를 갖고, 감독·포수 조합과 라이벌 6종은 안정 ID로 생성한다.
- 콘텐츠 기준선은 관계·성장 사건 36개, 중요 경기 상황 12개, 각성 18개, 기억 18개로 고정한다.
- 중요한 경기는 코어가 선택한 상황을 기존 Pitch Kernel에 전달한다. 타자 계획 선확정과 라이벌 기억 규칙은 그대로 유지한다.
- 10개 구단은 각자 필요한 성장 영역과 수요 강도를 가진다. 드래프트는 현재 능력, 경기의 결과·과정, 각성, 관계와 구단 fit을 합쳐 결정한다.
- 지명 시 계약금·육성 계획·경쟁자·담당 코치·첫 시즌 목표를 무료 화면에서 공개한다. 미지명 시 후보 5장 중 기억 3장을 골라 다음 삶에 적용한다.
- 고교 커리어 상태와 중요 경기의 마지막 확정 투구는 Pitcher Lab과 분리된 체크섬 자동 저장에 기록한다.

## 결과

- 지명과 미지명 경로 모두 같은 결정론적 커리어 상태에서 완결된다.
- 학교 선택과 훈련 방향이 구단 수요에 맞는지 설명할 수 있고, 드래프트 결과를 단일 경기 결과가 임의로 보정하지 않는다.
- 콘텐츠 추가는 상태 전이 코드를 바꾸지 않고 안정 ID 카탈로그를 확장하는 방식으로 진행할 수 있다.
- 앱 재시작 시 마지막 확정 챕터 결정 또는 중요 경기 투구부터 재개한다.

## 후속 작업

- P4에서 4축 난이도, 튜토리얼, 업보 카드, 콘텐츠 팩과 저장 마이그레이션을 추가한다.
- 플레이테스트와 대량 실행으로 삶 번호별 지명률과 60~90분 페이스를 보정한다.
- P5에서 드래프트 결과의 구단 수요를 프로 로스터·계약·옵션 상태로 이어간다.
