# ADR-002: Tauri 명령을 통한 JSON-RPC sidecar IPC

- 상태: 승인
- 결정일: 2026-07-21

## 맥락

React 화면은 Swift 타입이나 프로세스에 직접 접근할 수 없다. 프로토콜은 디버깅 가능하고 버전 관리가 쉬워야 하며, 화면에 임의 프로세스 실행 권한을 주면 안 된다.

## 결정

`React → Tauri command → Swift sidecar` 구조를 사용한다.

- React는 문자열 JSON-RPC 요청만 `execute_core` Tauri 명령에 전달한다.
- Rust 경계는 번들된 `simulation-sidecar`만 실행한다.
- Swift sidecar는 표준 입력·출력의 UTF-8 NDJSON으로 JSON-RPC 2.0 한 줄 요청과 한 줄 응답을 사용한다.
- P0에서는 요청마다 sidecar를 실행하고 응답 뒤 종료하는 단순한 모델을 사용한다.
- 요청·응답 데이터는 JSON Schema와 양쪽의 정적 타입으로 관리한다.

## 결과

- 프런트엔드에는 shell 실행 권한이 없다.
- 한 요청의 실패가 다음 요청에 남지 않아 P0 복구가 단순하다.
- 프로세스 시작 비용이 있으므로 P1 성능 측정 후 영속 프로세스 전환 여부를 결정한다.

## 오류 계약

- `-32700`: JSON 파싱 실패
- `-32600`: 잘못된 JSON-RPC 요청
- `-32601`: 지원하지 않는 메서드
- `-32602`: 잘못된 시뮬레이션 입력
- `-32603`: 내부 오류
