## 수동 초보자 QA 체크리스트

서사와 플레이 의미는 플레이 과정에서 발견하게 한다. 온보딩 문구가 삶의 정답, 실패의 의미, 권장 플레이 태도를 대신 해석하지 않는다.

1. 새 저장에서 첫 선택에 필요한 조작과 저장 방식을 이해할 수 있는가.
2. 기억과 다음 삶의 관계를 실제 결말 이후 화면만으로 이해하는가.
3. 네 가지 난이도 축과 업보의 보상·제약을 선택 전에 예측할 수 있는가.
4. 키보드만으로 모든 버튼과 선택 항목에 도달하고 현재 상태를 색상 없이 구분하는가.
5. 강제 종료 뒤 마지막 확정 선택에서 재개하는가.
6. 지명 뒤 프로 확장의 구단·계약금·육성 계획·경쟁자·첫 시즌 가치를 이해하는가.
7. 프로에서 감독 신뢰가 1군·보직 변화로 이어진 이유를 설명할 수 있는가.
8. iPhone과 iPad에서 글자 확대·VoiceOver 순서·44pt 목표가 유지되는가.

## 2026-07-22 초보자 관점 데스크톱 점검

릴리스 패키지를 실제 앱으로 실행해 저장 복원, 관계 선택, 중요 이닝과 접근성 설정을 확인했다.

- 기존 고교 저장을 불러와 두 번의 중요 이닝을 처음부터 끝까지 직접 투구했다. 각각 35회와 30회의 화면 조작 뒤 이닝 종료, 경기 기록 반영, 고교 화면 복귀가 정상 동작했다.
- 2학년 봄까지 진행해 라이벌 면담을 확인했다. 인물 이름, 직접 인용한 대사, 상황에 맞는 세 가지 답변이 순서대로 읽혔고 선택 결과가 최신 뉴스에 반영됐다.
- 앱을 완전히 종료한 뒤 다시 실행해 `2학년 봄 · 관계 3/5 · 중요 경기 2/5`에서 재개되는 것을 확인했다.
- 고대비, 모션 감소, 글자 확대를 실제 화면에서 켰고 앱 재실행 뒤에도 세 설정이 유지됐다.
- 관계 선택 뒤 다음 중요 경기로 이동했고, 포수 추천 적용·구종·코스·존 의도·강도·투구 버튼이 접근성 트리에 올바른 순서로 노출됐다.
- 빠른 투구 개선 뒤 포수 추천이 자동 적용됐고 `포수 콜로 되돌리기`, `직전 선택 반복`으로 같은 전략을 한 번에 재사용할 수 있었다.
- 한 공을 직접 던져 목표·실제 궤적, 선택 평가, 한 줄 결과가 먼저 보이고 궤적·타구·분석 상세가 접힌 상태로 남는 것을 확인했다.
- 효과음·진동을 각각 끌 수 있고 고대비·모션 감소·글자 확대 설정과 함께 재실행 뒤 유지되는 것을 확인했다.

점검 중 발견해 수정한 문구 문제:

- 온보딩이 첫 삶의 의미나 플레이 방향을 미리 해석하던 문장을 제거하고 조작·확정·저장 정보만 남겼다.
- `계획을 둘러싼 대화` 같은 추상 설명을 없애고 감독·포수·라이벌별 실제 발화와 답변으로 교체했다.
- 모든 인물에게 같은 답변이 붙던 관계 결과를 인물 유형별 결과 문장으로 나눴다.
- 동적 이름 뒤에 잘못된 `이/가`, `와/과`가 붙던 뉴스 문장을 조사 없이 자연스러운 제목형 문장으로 바꿨다.
- 영문 각성 ID, 영문 프로 보직, 단계 번호와 내부 개발 용어가 사용자 화면에 나타나지 않게 했다.
- 프로 중요 경기는 자동 결과 버튼 대신 Windows에서 실제 투구 화면으로 진입하도록 연결했다. iOS의 현재 축약 흐름은 버튼 문구에 `포수 추천대로 승부`라고 정확히 표시한다.
- 경기 시나리오의 `표본`, `재현성`, `사인 언어`, `모든 선택이 모이는 무대` 같은 설명을 주자·아웃·상대 행동이 보이는 상황문으로 바꿨다.

## 2026-07-22 Steam 제출 화면 감사

실제 macOS 앱의 화면과 접근성 트리를 다시 확인해 개발 중에는 익숙해져 놓치기 쉬운 출시 표면을 점검했다.

- 화면 상단과 진행 카드에 남아 있던 `Pitcher Lab`, `IMPORTANT INNING`, `LIFE`, `RESULT` 등의 영문을 자연스러운 한국어로 통일했다.
- 결과와 기록 목록에서 사용자가 해석할 수 없는 내부 이벤트 해시를 제거하고, 선택에서 결과까지의 인과 관계만 보여 주도록 바꿨다.
- 일반 플레이 화면에서 개발자용 분석 JSON 내보내기 버튼을 제거했다. 문제 해결 자료 저장은 설정 안쪽에 두고 개인정보 제외와 기기 내 저장 범위를 설명한다.
- 진동 API가 없는 Windows/macOS 데스크톱에서는 진동 설정을 `지원 안 됨`으로 비활성화해 작동하지 않는 토글처럼 보이지 않게 했다.
- 앱 시작 또는 저장 복원 중 오류가 나면 빈 화면으로 끝나지 않고 재시도 안내와 로컬 저장 지속 상태를 표시한다.
- 상점 캡슐, 라이브러리 히어로·로고, 아이콘을 현재 Steam 규격으로 제작하고 `npm run steam:submission:check`로 크기와 버전·금지 문구를 함께 검사한다.

이 감사로 로컬에서 확인 가능한 제출 품질은 높였지만, Valve 승인 자체를 의미하지 않는다. 실제 Steam 클라이언트 설치, 코드 서명·공증, 상점 설문, 외부 플레이테스트와 실제 플레이 마케팅 자료는 별도 게이트로 유지한다.

이전 개발 빌드에서 이미 저장된 뉴스 데이터는 기록 보존을 위해 변경하지 않는다. 대신 화면 표시 단계에서 과거의 `이야기를 나눴습니다`, `대화를 마쳤습니다` 같은 문장을 자연스러운 사건형 문장으로 정리하고, 새 사건은 처음부터 수정된 문구로 저장한다.

iOS는 `generic/platform=iOS Simulator` 대상 Debug와 Release 빌드가 모두 통과했다. XcodeBuildMCP 연결은 전송 종료 상태였고 현재 부팅된 Simulator도 없었다. 프로젝트 지침에 따라 기기를 임의로 부팅하지 않았으므로, 화면 읽기 순서·동적 글자 크기·햅틱 검증은 구체적 Simulator나 실기기에서 다시 수행해야 한다. Release 빌드는 개발용 프로 커리어를 자동 생성하지 않고 검증된 구매·복원 권한만 허용한다.
