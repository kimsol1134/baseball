# Android 포수 추천 + 직접 조준 — 2026-09-06

- 새 투구는 현재 포수 추천 구종·코스가 기본 선택된다. 이전 선택 유지 설정은 화면에서 제거하고 다음 투구는 항상 추천으로 돌아간다.
- 기본 코스 격자 터치만으로 즉시 수동 조준한다. 구종을 바꿔도 고른 코스는 유지한다.
- 메인 화면의 `포수 추천`으로 추천 구종·코스에 한 번에 복귀한다.
- 선명한 원형 조준점은 실제 선택을 뜻한다. 추천 코스는 같은 격자에 포수 추천 표기로 표시하며, 수동 선택과 다르면 옅게 표시한다.
- 슬라이더를 잡으면 코스·구종·추천·작전 변경을 잠근다. 놓거나 취소하면 해제한다. 다음 투구 자동 준비는 그대로 유지하며 실제 투구는 직접 조작한다.
- 추천 알고리즘·성공 판정·물리·성장 수치는 변경하지 않았다.

검증: 단위 테스트·Lint·빌드 및 ko/en/ja 카탈로그/문구/Compose 정적 검사. 실기기 테스트는 자동 다음 공 준비, 추천 기본 적용, 수동 코스 변경, 구종 변경 시 코스 유지, 추천 복귀 및 실제 수동 투구를 검사한다.
