# 제구 성장과 슬라이더 안정 구간

2026-09-05. 사용자에게 제안한 ‘안정 릴리스 구간은 성장하고, 퍼펙트는 계속 노릴 가치가 있는 구조’를 iOS·Android에 반영했다.

## 구현한 규칙

- 안정 구간의 최소 폭은 기존과 같은 게이지 전체의 18%다. 제구 성장에 따라 최대 24%까지 넓어진다.
- 원시 제구 35 이하에서는 기존 입력 점수와 정확히 같다. 35~80에서 폭이 완만하게 증가한다. 화면용 1~100 점수와 저장용 제구 20~80을 혼동하지 않는다.
- 정중앙 퍼펙트는 기존 2.5% 구간을 유지한다. 보정은 퍼펙트 직전에서 제한되어 퍼펙트를 만들어낼 수 없다.
- 타이밍을 크게 놓친 입력(원래 릴리스 점수 500 이하), 자동 릴리스 500/500, 직접 조준 점수는 보정하지 않는다.
- 같은 제구를 모든 구종의 안정 구간에 사용한다. 구종·피로에 따른 기존 속도·조준 흔들림 규칙을 보존한다.
- 누르기 시작할 때 제구를 고정한다. 와인드업 중 상태가 바뀌어도 구간과 해당 투구의 판정이 함께 움직이지 않는다.

## 화면과 판정의 연결

안정 구간의 그리기, 진입 햅틱, ‘지금’ 안내, 실제 제출 점수는 같은 순수 규칙을 사용한다. 구간 안의 타이밍은 실제 안정 릴리스 문턱 820 이상으로 보정된다. 퍼펙트 975 이상은 실제 정중앙 입력만 가능하다.

결과 문구도 문턱과 맞췄다. ‘안정 릴리스’, ‘안정 구간에 가까웠어요’, ‘타이밍을 놓쳤어요’를 구분하고, 안정 릴리스라도 조준이 낮으면 그 사실을 함께 알린다. 릴리스 성공은 스트라이크·아웃 보장이 아니다.

선수 능력 상세·훈련 성장·경기 성장·환생 시작 비교에 실제 슬라이더 모양의 구간을 넣었다. 제구 숫자는 비교용으로 남기되 구간과 효과를 먼저 읽게 한다. 전후 구간이 실제로 늘어난 경우에만 확장됐다는 문구를 표시한다. 이전 표시선과 현재 초록 구간을 함께 보여 색상에만 의존하지 않는다.

## 기존 기록과 밸런스 보호

새 수동 입력을 만드는 순간 한 번만 보정한다. 기존 저장 형식은 변경하지 않았으며, 이미 저장된 `PitchDelivery`를 복원하거나 재생할 때 다시 보정하지 않는다. 게임 엔진의 난수 소비와 공의 조준 오차 계산도 변경하지 않았다.

보정되는 릴리스 점수의 최대 차이는 60/1000이다. 기존 엔진에 넣었을 때 추가 실행 품질은 최대 15/1000, 구속 차이는 반올림을 포함해 최대 0.2km/h로 제한된다. 조준이나 공의 퍼짐을 추가로 줄이지 않아 같은 성장 효과를 거기에 재적용하지 않는다.

고정된 투수·타자·코스에서 최대 보정을 넣은 2,048쌍의 입력/시드 경계 검사 결과:

- 목표·실제 공 위치는 모든 쌍에서 동일했다.
- 실행 품질 증가는 최대 15/1000이었다.
- 최종 타격 결과가 달라진 쌍은 4개였다.
- 자동·중립 입력 및 기존 입력 직렬화 검사는 통과했다.

이는 추가 효과의 상한과 재생 안정성을 확인한 검사다. 전체 시즌의 최적 육성 전략이나 실제 이용자의 재미·유지율을 입증하는 통계로 해석하지 않는다.

## 검증

- Swift 코어: 13개 테스트 통과. 모든 입력 점수 0~1000·제구 20~80 조합에서 단조성, 보정 상한, 퍼펙트 불변성을 검사했다.
- Swift/Kotlin의 공통 제구·릴리스 검증 벡터 일치. Kotlin은 좌우 대칭과 60/120Hz 시간 표본도 검사했다.
- iOS: 단위 및 실제 수동 투구·제구 훈련·영어/일본어 첫 플레이 28개 통과. 숫자 중복을 줄인 최종 배치에서도 제구 훈련 UI를 재검증했고 마지막 빌드가 성공했다.
- Android: Kotlin 조작 규칙 13개, 현지화 8개, 앱 검사 10개 통과. lint 오류 0개.
- Galaxy A53: 투구 중 제구가 바뀌어도 현재 구간 고정, 취소 시 0구, 다음 의도한 릴리스는 1구인 실기기 검사 통과.
- Galaxy A53: 제구 훈련의 실제 구간 비교와 파일 저장 재로드를 글자 크기 2배에서 검증했다.
- Galaxy A53: 일본어 120Hz 요청·영어 60Hz 요청 설정에서 신규 플레이의 기본 슬라이더 투구 완료. 새 문구의 한글 대체 미노출 검사 통과.
- 전체 제품 문구 검사: 내부 용어 38종·실존 야구 IP 42종 미노출.
