# 다음 공 자동 준비·상황별 햅틱

2026-09-06. iOS는 같은 타자와의 승부 중 직접 투구 입력으로 돌아가고, 타자 전환·등판 종료에서 별도 행동을 받는다. Android도 같은 타자에게 던지는 공마다 ‘다음 공’을 누를 필요가 없도록 변경했다.

## 투구 흐름

- 결과 재생과 저장이 완료된 뒤 잠시 결과를 보여주고, 진행 가능한 공식 투구는 다음 슬라이더를 자동으로 준비한다.
- 준비만 자동이다. 실제 공은 반드시 사용자가 슬라이더를 조작해야 던져진다. 투구 횟수·보상·난수 결과를 추가 생성하지 않는다.
- ‘자세히’나 ‘투구 다시 보기’를 선택하면 자동 준비를 멈춘다. 충분히 읽은 뒤 다음 공을 선택할 수 있다.
- 다음 준비 중에는 중복 요청을 막는다. 앱이 배경에 있거나 저장 오류가 표시된 동안에는 자동 전환을 시작하지 않는다.
- 한 구 연습 종료·타석/경기 정산처럼 현재 공식 투구를 계속할 수 없는 경계의 확인 버튼은 유지한다.

## 햅틱

| 순간 | 표현 |
|---|---|
| 누르기 | 짧고 묵직한 시작 |
| 안정 구간·미터 끝 | 짧은 경계 틱 |
| 릴리스·퍼펙트 | 일반/정확/놓침을 구분하는 패턴 |
| 파울 | 짧게 한 번 |
| 피안타 | 무게감 있는 두 번 |
| 피홈런 | 더 긴 세 부분 패턴 |
| 삼진·아웃 | 성공 패턴 |
| 볼넷·사구 | 불리한 결과 패턴 |
| 긴장 상황 | 두 박의 심장박동. 기기 지원에 따라 진폭 또는 지속시간으로 세기 차이 표현 |

피안타·볼넷 직후의 긴장을 다음 투구에도 유지한다. 현재 경기와 관계없는 이전 프로 저장이 긴장도 계산에 끼어들지 않게 했다. 공을 잡을 때 심박을 중단하고 조작 햅틱으로 전환한다. 모션 축소에서도 릴리스 직후 결과 햅틱이 겹치지 않게 최소 간격을 둔다. 앱/시스템 진동 끄기를 존중하며 시스템 설정은 변경하지 않는다.

## 검증

- 판정 피드백 테스트 3개, 플랫폼 테스트 28개, 앱 단위 13개 및 debug/release 컴파일·lint 통과.
- Galaxy A53: 실제 공식 투구 → 버튼 없이 다음 슬라이더 준비 → 투구 수가 정확히 1만 증가 → 두 번째 공 상세 확인 중 자동 준비 정지 → 홈 화면에서 추가 투구 없음 검사 통과.
- Galaxy A53: 파울·피안타·피홈런·삼진·심박 출력 검사 통과. 기본 진동 패턴과 심박이 시스템 진동 기록에 실행된 것을 확인했다.
