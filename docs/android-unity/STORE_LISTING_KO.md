# Google Play 한국어 등록정보 초안

## 상품 설정

- 앱 이름: 야구 못하면 또 환생함
- 앱/게임: 게임
- 기본 언어: 한국어(대한민국)
- 국가: 대한민국
- 가격: 4,400원
- 유료 게임 무료 체험: 60분, 켬
- 광고: 없음
- 인앱 구매/구독: 없음
- 로그인: 없음
- 지원: Android 스마트폰 세로

무료 체험은 Google Play Console의 유료 게임 기능으로 설정한다. 앱 내부에는 체험 타이머, 구매벽, Billing SDK를 구현하지 않는다. Play가 AAB에 체험 보호를 적용하므로 내부 트랙에서 시작·만료·구매 후 동일 로컬 저장 유지까지 확인한 뒤에만 등록정보에 노출한다.

## 짧은 설명 초안

한 투수의 선택과 승부를 쌓고, 남긴 유산으로 다시 시작하는 가상 야구 커리어 게임.

## 상세 설명 작성 계약

- 현재 Android Release에서 검증된 기능만 적는다.
- 독자적인 가상 야구 세계관임을 밝힌다.
- 오프라인 플레이, 광고/인앱 구매 없음, 유료 완전판을 정확히 표기한다.
- 실존 리그·구단·선수와의 공식 관계를 암시하지 않는다.
- 최상급·성과 보장 문구를 쓰지 않는다.

## 1.0.0 출시 노트 초안

> 첫 Android 버전입니다. 고교 3년부터 가상 프로 무대, 은퇴와 환생까지 이어지는 투수
> 커리어를 한국어로 즐길 수 있습니다. 포수 뒤 시점의 직접 투구, 능력별 성장 선택, 주간 과제,
> 로컬 업적과 기록 보관함을 담았습니다. 로그인 없이 오프라인으로 플레이할 수 있습니다.

이 문구는 서명 AAB의 실제 기능·오프라인 완주를 검증한 뒤 Play Console에 사용한다.

## 필요한 소재

- 512×512 앱 아이콘 — `apps/android-unity/StoreAssets/StoreIcon-512x512.png` 준비됨
- 1024×500 feature graphic — `apps/android-unity/StoreAssets/FeatureGraphic-1024x500.png` 준비됨
- 실제 Android Release 세로 스크린샷
- 개인정보처리방침/지원 HTTPS URL
- 한국어 release note — 위 1.0.0 초안 준비됨

앞의 두 이미지는 소스 후보이며 `StoreAssets/manifest.json` 해시로 고정한다. 세로 스크린샷은
프로덕션 서명 AAB를 물리 스마트폰에서 실행해 캡처하기 전까지 미완료로 남긴다.
