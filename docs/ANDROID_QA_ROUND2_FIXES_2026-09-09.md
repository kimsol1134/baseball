## 검증 증거

- Kotlin 관련 단위 테스트 **최종 40개 실행, 40개 통과**. 저장 복원·결과 재개·진행 무결성·한 타석 자동 진행·GameCopy 검사 포함. 세부 결과는 `unit-results.json`에 보존했다. 전체 application 테스트는 초기 작업 중 실행했다가 변경된 코드의 관련 검사로 전환하며 중단했으므로 전체 스위트 통과를 주장하지 않는다.
- A53 실기기: SM-A536N, Android 16, serial R5CT40GZSWZ. 신규 플레이어 기본 슬라이더, 네 프리셋 능력치, 프로 이름/주간 CTA, 대화 언어·탭·뒤로, 설정 큰 글자/언어, 조준/힘 배분/슬라이더 검사 통과.
- 420dp 조준 검사에서는 노드의 일부가 보이는 것만으로 통과시키지 않고 전체 높이가 48dp에 근접한지, 플레이트 전체 높이가 보이는지 검사했다. 테스트용 고정 높이 화면 캡처와 실제 선수 만들기 화면을 시각 확인했다.
- 파일 백업: A53에서 생성한 fixture를 에뮬레이터로 전달해 다른 설치 ID로 복원, 훈련, 재저장, 스토어 재개방까지 통과. OS 클라우드 백업 성공으로 해석하지 않는다.
- A53 QA 리플레이: 727 frames, janky 12 (1.65%), p95 20ms, p99 26ms. 이 측정의 legacy jank는 430/727 (59.15%)로 별도 정의의 지표다. 60Hz 고정 리플레이 검사이며 production 성능 판정이 아니다.
- A53 콜드 시작 단일 측정: TotalTime 2,299ms. 직후 TOTAL PSS 161,489KB(약 158MiB). 기기·빌드가 다른 기존 에뮬레이터 수치와 직접 비교하지 않는다.
- 정적/reference 및 release 소스 게이트, 내부 용어·실존 야구 IP 검사 통과. 카탈로그 재생성 일치 및 Kotlin 문구 3,199 / 3,199 매핑, 누락 0. `git diff --check` 통과.
- 초기 실기기 배치에서 성능 검사가 세이브를 먼저 생성해 신규 플레이어 검사의 OPENING 전제가 실패했다. 전용 QA 패키지의 이번 테스트 데이터를 초기화한 뒤 신규 플레이어 검사를 독립 실행하여 통과했다. 개인용 앱의 세이브는 초기화하지 않았다.

증거 디렉터리: `artifacts/qa/android-round2-fixes-2026-09-09/`. 주요 파일은 `a53-setup.png`, `a53-pitch.png`, `a53-performance.txt`, `first-player.log`, `final-ui.log`, `delivery-ui.log`, `backup-import.log`, `unit-final.log`, `integrity.log`이다.

## 최종 빌드 및 남은 검증

- QA 패키지: `com.solkim.baseball.android.reset.compose.qa`, `baseballResetQa=true`, `baseballQaNativeStore=true`, nativeAuthoritative. 최종 APK를 A53에 설치했다.
- APK: `apps/android/app/build/outputs/apk/debug/app-debug.apk` (재빌드로 덮어쓰이는 작업 산출물).
- SHA-256은 증거 디렉터리의 `apk-sha256.txt`에 기록했다. 최종 UI 관련 변경 후 A53 프로 주간/선수 만들기 및 조준 매트릭스 재검증 통과.
- **N-01/H-01은 부분 완료**: A53은 Google BackupTransportService를 선택하고 있지만 Backup Manager가 disabled였다. 개인 기기의 OS 백업 설정을 켜거나 공장 초기화하지 않았다. Google 계정 백업→다른 실기기 자동 복원, 케이블/제조사 이전은 여전히 실제 검증이 필요하다.
- **서명된 production RC 미생성**: 원래 RC 스크립트를 실행했으나 `BASEBALL_UPLOAD_KEYSTORE_PATH` 미설정으로 시작하지 못했다. 서명/Firebase/분석 조건을 우회하지 않았다.
- 태블릿·폴더블, TalkBack 실제 청취, 외부 음악 앱과의 오디오 포커스 상호작용은 미검증이다. A53 화면 확인으로 대화면·폴더블 검증을 대체하지 않는다.
- 원 보고서의 1차 보류 항목은 이번 변경과 겹치는 버튼·대화 이동 외에 일괄 해결로 처리하지 않는다. 1차 ‘26건’, 증거 ‘44장/9장’ 집계의 원 증거 전체 재감사는 이번 코드 개선 검증에 포함하지 않았다.

코드 개선과 위 범위의 QA 검증을 완료했으며, OS 자동 복원 및 서명된 RC 등 남은 조건까지 완료된 출시 후보라는 뜻은 아니다.
