# 야구 못하면 또 환생함 1.0.2 구현 노트

2026-08 리텐션 개선안의 웨이브 0~5 구현 기록이다. 기능 계약과 출시 판단의 원문은 [게임플레이 리텐션 구현 계획](./GAMEPLAY_RETENTION_IMPLEMENTATION_PLAN_2026-08.md), 이벤트 속성의 단일 목록은 [분석 이벤트 추적 계획](./ANALYTICS_TRACKING_PLAN.md)을 따른다.

## 기능

- 고교 3년의 내부 8구간을 사용자에게는 `1장 · 자리를 얻다`부터 `4장 · 이름을 남기다`까지 네 이야기로 묶었다. 진행 중 저장의 일정과 결과는 바꾸지 않는다.
- 승부처의 무게와 시작 아웃카운트에 따라 직접 상대하는 타자가 2·4·5·6명으로 달라진다. 타석 경계 복구에는 당시 목표 타자 수를 함께 저장해 업데이트 뒤에도 같은 경기로 이어진다.
- 직접 던진 경기에서 탈삼진·피해 억제·투구 수·수싸움 근거가 충분하면 경기당 최대 능력치 +1이 남는다. 승패보다 실제 투구 과정을 사용하고 같은 상태·선택에는 같은 성장을 적용한다.
- 한 선수의 최종 능력 성장, 직접 경기, 각성, 관계 기록에서 서로 다른 대표 유산 3개를 만든다. 사용자는 1개만 다음 선수에게 직접 남기고, 나머지 2개를 포함한 셋 모두 발견 목록과 선수 아카이브에 보존한다.
- 지명된 선수는 고교 결산에서 유산 선택을 강제하지 않는다. 프로 은퇴 뒤 고교와 프로 통산 기록을 합쳐 대표 유산 3개를 만들며, 고교를 건너뛴 프로 커리어는 다른 고교 선수와 섞지 않고 야구혼만 남긴다.
- 첫 선수의 프로 진입을 환생 횟수로 막지 않는다. 시작 유형별 능력 예산과 자동 시즌 평가를 같은 기준으로 맞추고 최종 운은 대부분 0, 최대 ±1로 제한해 직접 키운 방향과 경기 과정이 결과를 결정하게 했다.
- 고교에서 쌓은 야구혼은 다음 선수의 자동 성장에 스며들고, 프로 은퇴 보상은 지갑에만 남는다. 긴 프로 경력은 자동 합격이 아니라 성장 리듬·조기 성장 같은 다음 빌드 선택권을 넓힌다.
- 모든 이벤트에 배포 환경을 붙이고 경기 완료·공유 이벤트 계약을 정리했다.
- 새 선수를 시작할 때 결정론적인 목표 3개를 제안하고, 결과·야구혼 보너스·다음 선수의 재도전 의도를 기록한다.
- 목표 12종의 조건은 실제 엔진 1,000+1,000명으로 등급별 밴드에 맞췄다. 각성 목표는 무실점 기록을 반복하지 않고 선택 화면에 보이는 네 전략 계열 중 세 계열을 모은다. 최종 조건과 실측은 [리텐션 기능 밸런스 검증 보고서](./RETENTION_BALANCE_REPORT_2026-08.md)에 기록했다.
- 새 회차는 저장 버전 2의 커리어 바람을 받아 성장·관계 규칙과 회차 기록에 남긴다. 기존 저장은 버전 1 규칙을 유지한다.
- 직접 투구에 수싸움 적중 6종, 경기 내 배지·설명·정산 보상·타석 경계 복구를 추가했다.
- 기록 탭에 결정론적인 주간 목표 3개와 도장 보관함을 추가했다. 2개 완료 시 야구혼 15를 보상 ID 기준으로 한 번만 지급하며 미완료 손실은 없다.
- 프로 시즌 3·6·9·12·15·18·21주차에는 다른 국면과 충돌하지 않을 때 숫자를 모두 공개한 세 갈래 결정이 열린다. 확인 전에는 적용하지 않고 자동 진행은 결정 화면에서 멈춘다.
- 진행 중인 선수는 몸 상태·큰 경기·관계·성격에 따라 자기 마음을 짧게 말한다. 3년이 끝나면 실제 기록에서 대표 순간과 마지막 말을 남기고, 기록의 선수 계보와 다음 선수의 첫 화면까지 이어진다.

## 계측과 출시 판단

신규 이벤트는 `run_pledge_selected`, `run_pledge_resolved`, `career_wind_seen`, `next_run_intent_saved`, `next_run_intent_applied`, `weekly_program_opened`, `weekly_program_completed`, `pro_season_decision_selected`, `player_legacy_seen`, `career_training_completed`, `game_growth_applied`, `signature_legacy_options_seen`, `signature_legacy_selected`, `signature_legacy_equipped`, `life_completed`, `pro_legacy_recorded`이다. `game_finished`에는 수싸움 적중 횟수·태그·추천 수락률이 추가된다. 정식 지표는 `distribution=app_store`, `environment=production` 코호트만 사용한다.

웨이브 5의 데이터 착수 조건은 이 개발 환경에서 실측할 수 없었다. 구현은 완료하되 실제 출시는 프로 진입률과 3주차 이탈 구간을 확인한 뒤 판단한다. 웨이브별 최소 관찰 기간과 성공 기준은 구현 계획 §11을 따른다.

## 저장·호환성

- 신규 필드는 optional 또는 기본값으로 추가해 1.0.x 저장본을 계속 디코드한다.
- 시작 유형 밸런스는 새 선수부터 v4를 고정한다. v1·v2 선수만 직전 v3 카탈로그로 보정하고 v3 선수는 그대로 유지해, 진행 중 자동 시즌 평가가 시작 당시 버전을 끝까지 사용한다.
- 야구혼 환산 곡선과 대표 유산 생성 규칙을 별도 버전으로 저장한다. 기능 도입 전에 시작한 선수는 당시 복수 기억 규칙으로 끝내며 결말에서 새 선택을 강제하지 않는다.
- 대표 유산 후보 3개의 이름·효과·근거와 선택 1개를 완료 시점 payload로 동결한다. 후보 노출·선택·정산은 로컬 원자 저장이 성공한 뒤에만 외부 이벤트와 보상을 기록한다.
- 프로 저장에는 원본 고교 ID와 `highSchool/direct` 출처를 남긴다. 구버전 연결은 선수 신원·투수 ID·첫 프로 구단까지 맞을 때만 복원하며, 유산 저장과 프로 tombstone 삭제 실패는 각각 재시도 가능하고 중복 보상하지 않는다.
- 바람 규칙 버전, 약속·다음 회차 의도, 배합 복구 상태, 주간 진행·도장·외부 보상 영수증, 프로 pending 결정·선택 기록을 저장한다.
- 배포된 네 약속 ID의 진행 중 저장은 버전 필드가 없으면 v1 조건과 +15% 보상으로 정산한다. 새 선택과 건너뛰기는 v2를 명시하며, 선택 버전·숙적 전적은 SaveSync와 로컬 mirror에 함께 저장한다.
- 끝난 회차에는 약속 제목·등급·보상·전체 조건 문장을 완료 시점 값으로 보존해 이후 카탈로그 조정이 아카이브를 바꾸지 않는다.
- 선수가 떠날 때 남긴 마지막 말과 대표 순간도 완료 시점에 함께 보존한다. 이 필드가 없는 기존 기록은 당시 경기·성격·연대기로 같은 문장을 다시 만들 수 있다.
- 주간 보상은 `weekly-<weekKey>` 영수증과 마지막 관측 주 시작 시각으로 재시작·동기화·시계 되감기 뒤의 중복 지급을 막는다.
- 프로 결정은 같은 상태·결정 ID·선택지 ID에 결정론적이며 RNG를 소비하지 않는다. 저장 후에는 같은 결정 화면으로 복구되고, 이후 카탈로그 문구·효과가 조정돼도 commitment가 유효한 저장 payload를 그대로 한 번 적용한다.

## 롤아웃·롤백

첫 경기 활성화가 5%p 이상 하락하거나, 저장·복구 실패가 한 건이라도 재현되거나, 특정 바람 완주율이 전체보다 20%p 이상 낮거나, 신규 목표 도입 뒤 세션 중단율이 10%p 이상 오르면 해당 웨이브를 롤백한다. 같은 노력의 주요 시작 방향 가운데 첫 선수 지명률이 30~55%를 벗어나거나 방향 간 차이가 15%p를 넘는 경우에도 출시하지 않는다. VoiceOver 또는 큰 글자에서 주요 선택이 불가능한 경우에도 출시하지 않는다.

대표 완주 회차를 주 1회 마치는 4주 경제 계산에서 최초 25점 보상 비중은 37.8%로 20% 가드를 넘었다. 계획의 조정 규칙에 따라 15점으로 낮췄고 같은 가정에서 비중은 26.7%다. 한 빌드에는 한 웨이브만 노출해 지표 원인을 분리한다.
