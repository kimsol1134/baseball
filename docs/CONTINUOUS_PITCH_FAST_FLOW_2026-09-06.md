# 다음 공 자동 준비 UX — 2026-09-06

## 변경

- 진행 가능한 공식 투구는 결과 연출·저장이 끝난 뒤 자동으로 다음 수동 슬라이더를 준비한다.
- 동일 타석 추가 대기 650ms → 250ms. 타자가 바뀌는 경우 600ms로 결과를 읽을 여유를 둔다.
- 자동으로 진행되는 결과 카드에서는 `다음 공`/`다음 타자` 버튼을 숨겨 필수 확인처럼 보이지 않게 한다.
- 결과 자세히 보기·리플레이를 선택한 경우에는 자동 준비를 멈추고 재개 버튼을 제공한다.
- 경기 종료·튜토리얼 결과 확인은 유지한다. 자동으로 공을 던지지는 않는다.
- 자동 준비 효과가 저장 경계 변경도 관찰하도록 하고, 지연 종료 시 진행 가능 여부·포커스·검사 중 여부를 다시 확인한다.

## 검증 범위

별도 reset.compose.qa 앱에서 완료된 첫 투구 결과로 진입한 뒤, 다음 공 버튼을 누르지 않고 슬라이더가 준비되는지 검사한다. 자동 준비만으로 투구 수가 증가하지 않으며, 실제 슬라이더 조작 후에만 한 구 늘어나고 홈 이동 후 추가 투구가 발생하지 않는지 검증한다.

결과: Galaxy A53 실기기 테스트 통과(12.235초), 앱 단위 테스트 및 Lint·빌드·문구/Compose 정적 검사 통과. 사용자 core.compose.qa 앱 업데이트 설치 및 실행 완료. 설치 전후 save.json SHA-256 일치 확인. 별도 테스트 앱 제거.
