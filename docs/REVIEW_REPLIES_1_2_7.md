# App Store 리뷰 답글 초안 (1.2.7 승인 이후)

게시 규칙:

- (a)–(d)는 **1.2.7이 App Store에 나온 뒤에만** 올린다. 1.2.7 심사 중이거나 거절된 상태에서는 보내지 않는다.
- (e)는 **1.2.8이 실제로 출시된 뒤에만** 올린다. 1.2.7 답글 묶음에 섞지 않는다.
- 각 본문은 900자 이하. 출시일을 약속하지 않는다. 실존 구단·리그·선수명을 쓰지 않는다.
- 이미 한 번 답한 (d)는 짧은 후속만 보낸다.

글자 수는 유니코드 코드포인트 기준(`[...text].length`)이다.

## (a) 8/31 5★ — 투구 손

리뷰: "주인공 어느 손 투수인가요? 우완좌완 설정 있었으면"

게시: 1.2.7 출시 후

```
안녕하세요, 소중한 리뷰 감사합니다.

주인공이 어느 손 투수인지 고르고 싶다는 말씀, 그대로 읽고 1.2.7에 넣었습니다. 새 커리어를 시작할 때 좌완과 우완을 고를 수 있고, 기록 화면에도 표시됩니다. 타자와의 좌우 유불리에도 실제로 반영됩니다.

업데이트 후 새 선수로 시작해 보시면 바로 고르실 수 있습니다. 이미 진행 중인 세이브는 정해 둔 손을 유지합니다.

한 구씩 직접 던지는 손맛이 자기 선수답게 느껴지셨으면 좋겠습니다. 의견 정말 감사합니다.
```

## (b) 8/30 3★ — 저장 교착

리뷰: "저장용량은 넘치는데 프로기록 정리를 저장하지 못했대요"

게시: 1.2.7 출시 후

```
안녕하세요, 저장이 막혀 답답하셨을 텐데 리뷰로 알려 주셔서 감사합니다.

저장 공간이 넉넉한데도 프로 기록을 정리하지 못했다는 안내가 뜨던 상태를 1.2.7에서 고쳤습니다. 기기 용량 문제가 아니라 저장이 끝나지 않던 교착이었고, 업데이트하시면 막혀 있던 진행이 풀립니다.

이미 그 화면에 멈춰 계신다면 1.2.7로 올린 뒤 같은 세이브를 다시 열어 주세요. 기록이 사라진 것은 아니니 이어서 플레이하실 수 있습니다.

불편을 드려 죄송합니다. 같은 막힘이 남으면 이 답글에 이어서 말씀해 주세요.
```

```

4.2이닝 15탈삼진, 5.2이닝 19탈삼진처럼 이닝에 비해 삼진이 불가능한 숫자는 자동 등판의 이닝 집계 버그였습니다. 1.2.7에서 고쳐서, 이제 실제로 던진 이닝만큼만 기록됩니다.

재미있는 탈삼진 경기를 남겨 주셔서 기뻤습니다. 이제 숫자도 그 손맛에 맞게 따라가길 바랍니다.
```

```
아직 부족한 점은 계속 듣겠습니다. 의견을 게임의 다음 선택으로 삼아 주셔서 감사합니다.
```
