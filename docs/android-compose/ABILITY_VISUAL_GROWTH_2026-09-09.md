# 능력 시각화와 성장 기록

## 구현

1. 상시 능력 카드: 내 투수/훈련/프로 주간 화면에 구위·제구·무브먼트·체력의 0–100 막대를 표시한다. 좁은 화면에서는 2열로 배치하고 상세 화면에서는 같은 길이의 네 막대로 펼친다. 능력별 색은 주황·파랑·보라·청록으로 고정하고 숫자/증감도 같이 표시한다. 낮은 능력을 경고색으로 칠하지 않는다.
2. 훈련 결과: 실제 이전 수치에서 이후 수치로 450ms 동안 막대가 채워진다. 이전 위치는 얇은 선으로 남는다. 모션 감소 설정에서는 즉시 최종 값을 보여준다. 결과는 사용자 확인 전까지 남으며 애니메이션이 게임을 진행시키지 않는다. 고교 훈련과 프로 주간 결과에 동일한 컴포넌트를 사용한다.
3. 환생 비교: 이번 구간 시작→현재, 이전 생 시작→이번 생 시작, 저장된 이전 생 최고→현재를 구분한다. 새 경로를 선택하면 해당 명령을 불변 복사본에 적용해 실제 다음 시작 능력을 미리 계산한다. 능력이나 야구혼을 미리 지급하지 않는다. 이전 최고 데이터가 없으면 그 비교는 비활성화한다.
4. 상세 성장 기록: 능력 막대나 ‘능력’ 버튼을 누르면 능력의 의미, 기준 구속, 제구 안정 구간, 숙련, 실제 변화 그래프와 이력을 볼 수 있다. 그래프 가로축은 저장된 변화 순서이며 시간 간격을 가장하지 않는다. 과거 관측이 없으면 만들어 넣지 않는다.

## 기록 보존

`AbilityHistoryPoint`는 현재 선수의 실제 능력 또는 숙련이 변한 커밋에서만 추가한다. 새 커리어는 시작점부터 기록하고 기존 저장은 처음 관측한 지점부터 기록한다. 훈련하지 않거나 숫자가 그대로면 가짜 성장점을 추가하지 않는다. 모의 도전의 변화는 본래 선수의 기록에 섞지 않는다.

native 저장과 shadow 저장 모두 같은 전이 함수를 사용한다. optional 메타 필드이므로 과거 저장의 빈 이력은 기존 바이트/해시 규칙을 유지한다. 새 이력이 있으면 커밋 검증에 포함한다. 백업/복원·환생에서도 보존하고 명시적인 진행 삭제는 기존 초기화 경로를 사용한다.

## 검증

- AbilityHistoryTest: 실제 변화, 숙련만 오른 경우, 새 생애 분리, 중복 요청 거부 뒤 불변, native 재시작/백업/복원.
- 기존 앨범·백업·진행 삭제·모바일 표현 테스트. 기존 앨범 테스트의 새 시즌 fixture에서 ER/CG 등 이전 시즌 필드가 남던 잘못된 초기화를 실제 빈 시즌 객체로 수정했다.
- native 3생애: 이전 성장점 보존, 선택 경로 미리보기와 실제 시작 능력 일치.
- 에뮬레이터: 상시 네 능력 노출, 비교 선택, 상세 기록 열기/닫기의 불변, 글꼴 2배에서 숫자 1줄, 모션 감소, 애니메이션 이후 값 유지.
- 훈련 결과와 프로 주간 화면 회귀 검사 포함 UI 8개 통과.

증거: `artifacts/android-compose/ability-validation.log`, `ability-ui-qa.log`, `ability-qa/`. 화면 캡처 중 컴포넌트 fixture는 시각 검사용 예시 값이며 실제 사용자 선수 기록이 아니다.

현재 포인트가 없는 구버전의 상세 성장 곡선은 복원할 수 없다. 기존에 저장된 시작 능력 비교는 제공하며 이후 실제 변화부터 이력을 누적한다. 투구 화면의 기본 슬라이더와 구종·코스 선택 공간은 변경하지 않았다.

프로 20시즌→은퇴→환생의 실제 native 저장 테스트도 통과했다. 환생 전 성장 이력이 같은 순서와 값으로 보존되는 것을 명시적으로 검사했다. 로그: `ability-native-career.log` (5분 10초).

최종 UI 검사 9개 통과(`ability-ui-final.log`). 실제 새 게임 기본 슬라이더(`ability-slider-final.log`)와 학교 선택→첫 훈련→결과 확인 전 앱 복귀(`ability-newcomer-final.log`)도 통과했다. 훈련 직후 대화 화면으로 넘어가는 경로에서 결과가 누락되던 문제는 결과 표시를 화면별 분기보다 먼저 배치해 수정했다. `ability-qa/native-training.png`는 실제 native 첫 훈련 결과다. 일반 QA APK와 androidTest APK 빌드 완료(`ability-delivery-build.log`). 실기기 업데이트나 스토어 배포는 수행하지 않았다.
