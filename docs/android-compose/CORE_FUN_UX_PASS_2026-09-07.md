# Android 핵심 재미 UX·카피 개선 (2026-09-07)

배포 전 검토에서 확인한 문제와 이번에 바꾼 내용. 원칙은 하나다. **시스템은 말하지 않는다. 코치, 포수, 또는 내가 말한다.** "~를 저장합니다", "~장면을 엽니다" 같은 상태 서술은 제품 문구에서 제거했다.

## 바꾼 것

### 카피
- 화면 부제 28개, 설정 토글 설명 6개, 드래프트·결산·환생·계약·보직·주간 노트·복귀·리뷰 행과 액션 설명을 짧은 1인칭 또는 코치 말투로 다시 썼다. `Phase8ScreenModels.kt`
- 전 화면 하단의 "다음 선택" 헤딩과 비활성 버튼의 "이 장면에서는 아직 선택할 수 없습니다" 문장을 없앴다. 뒤로 가기는 "← 내 투수"로 탭 이름과 맞췄다. `Phase8Screens.kt`
- 개발자 노트가 제품에 보이던 행을 고쳤다. "현재 생이 최종 확정된 뒤에만…", "얼어붙은 세 가지 선택", 유산 ID 앞 12자 노출. 유산은 제목으로 보여 준다. `SignatureLegacyDisplay.title`
- 투구 판정 4줄, 결과 해설 10줄, 슬라이더 프롬프트, 코치 팁(①②③·— 제거), 중단 다이얼로그를 반말 현재형으로 바꿨다. `PitchActivity.kt`, `PitchDeliveryControl.kt`, `PitchHudProjection.kt`
- 관계 수치("감독 62 · 포수 48"), 사인 확신 퍼센트, 포수 호흡 숫자를 말로 바꿨다("믿는 편", "높음", "합이 맞음").
- 용어집 29개 정의에서 "~입니다" 연쇄를 걷어냈다. `BaseballGlossary.kt`
- 훈련 결과에 코치 한 줄을 붙였다(초점·성장 여부·재능 발현별 14문장). `TrainingPresentation.coachLine`
- 게임 이름 "야구 못하면 또 환생함"을 타이틀 화면에 쓴다. "환생 투수 커리어"는 사라졌다.

### 투구 화면
- "작전" 모달을 해체했다. 포수 사인/다른 사인은 조준 존 위의 세그먼트로, 포수의 사인 근거는 한 줄 인라인(`pitch.rationale`, 탭하면 펼침), 노림·힘 배분은 인라인 펼치기, 상대 분석은 타자 카드 다이얼로그로, 자동 릴리스·진동은 "조작 설정" 작은 다이얼로그(`pitch.settings`)로 옮겼다. 존 그리드와 구종 칩의 이중 렌더를 없앴다.
- 자동 진행 뒤에도 직전 공의 판정과 릴리스 평가가 슬라이더 위에 남는다(`pitch.lastPitch`). 250ms 자동 진행은 유지했다.
- 튜토리얼 코치 팁을 정의만 있던 `PitchCoachStrip`으로 화면에 그린다.
- "이 타석 넘기기"는 저압 타석이면 초구부터 열리고, 풀카운트·2스트라이크에서는 닫힌다. `PitchHudProjection.canFastForward`
- 등판 종료 버튼은 "등판 마치기".

### 첫 60초
- 타이틀: 게임 이름, "한 구씩, 한 생씩.", 두 줄 설명, 시작하기. 조작 설명 카드와 자동 저장 안내를 뺐다(슬라이더 프롬프트가 그 자리에서 알려 준다).
- 선수 만들기: 첫 생은 2페이지(이름+지역 / 손+유형). 이름을 치면 초상화가 바로 바뀐다(`setup.portrait`). 환생 설정 경로는 지난 생의 이름을 미리 채운다.
- 편지 화면에서 바로 "첫 공 던지기"(BeginTutorial + 투구 예약을 한 번에). 별도 "첫 투구" 설명 화면은 복구 상황에서만 나오고 한 줄로 줄였다. `beginTutorial` 액션은 프로젝션에 남아 컨트롤러·테스트 경로는 그대로다.

### 성장·환생
- 훈련 화면의 "연속 훈련 안내" 토글을 없애고 ×3 버튼 설명으로 옮겼다. 회복 권고는 코치 말투.
- 환생 화면: 초상화 전환(에이스/프로 → 1학년)과 "같은 이름, 같은 얼굴. 1학년부터 다시."가 먼저, 이어지는 힘, 다음 생의 도전, 지난 생 라이프카드와 공유 버튼, 그다음에 시작 능력 비교표. `rebirth.identity`
- 주 액션 위치를 통일했다. 단일 주 액션이 있는 일반 화면은 모두 하단 고정 바에 건다. 선택지가 내용인 화면(학교·주간 계획·계약·유산)은 인라인을 유지한다.

## 하지 않은 것
- 튜토리얼을 3~5구로 늘리는 것. `HighSchoolPhase4Kernel.submitTutorialPitch`가 한 구를 전제하고 `activePitch == null`을 요구한다. 커널과 픽스처 변경이 필요해 이번 범위에서 뺐다.
- 프로 결정 결과 문구(`ProWeeklyDecisionRules`)와 주간 뉴스 박스스코어(`ProKernel`)는 game-core라 손대지 않았다.
- 정보 공개 방식(모달·토글·다이얼로그)의 완전한 단일화. 투구 화면의 다이얼로그는 5개에서 3개(타자 카드, 조작 설정, 중단)로 줄였다.

# 2차: 후반부·프로·감정의 정점 (2026-09-07)

# 3차: 열리지 않던 화면과 주변 흐름 (2026-09-07)

## P1
- **기록 탭에서 업적·주간 노트·라이프 카드·돌아올 자리로 갈 수 없던 문제.** 다섯 화면의 도달 조건이 같아 첫 화면(기록과 순위)만 열렸다. 기록 화면 상단에 세그먼트 칩(`records.tab.P-0xx`)을 두어 한 번에 이동한다. 라이프 카드는 기록 탭 소속으로 옮겼다. `Phase8Screens.kt`
- **공유되는 라이프 카드 이미지**를 초상화·이름·지명 여부·학교·4스탯·능력/각성/유산/야구혼·게임 이름의 카드로 다시 그렸다. 텍스트 공유에는 게임 이름과 Play 링크가 붙는다. `NativeLifeCardShareService.render`
- **복귀 알림**은 선수 이름과 커널의 안내 문장을 쓰고, 새 계획이 이전 알람을 취소한다. 화면의 내부 ID(`important_game_completed`)는 사라졌다. 기본 문구는 "다음 경기가 기다린다 / 어디까지 했는지 알려 줄게."
- **2회차 설정 마지막 페이지**의 난이도·야구혼 분야·야구혼 부스트·핸디캡에 효과 한 줄씩. 구종 페이지 요약이 실제 선택을 따라가고, 주 구종이 되돌아갈 때 알린다.
- **오류 문구**는 전부 "~어요"로 통일하고 다음에 할 동작을 붙였다.

## P2
- 알림 설정 카드 두 벌 중 설정 페이지만 남겼다. "복귀 계획 준비"는 "내일 아침에 알려 줘"가 되어 언제 오는지 말한다.
- 주간 노트의 도장·보상에 뜻을 달았고 과제 종류 7개를 우리말로 바꿨다(`played_on_two_days` 같은 ID 노출 제거). 기록 탭 첫 진입은 빈 상태 문구.
- 업적 15개 설명을 반말 현재형으로 통일. 초기화 안내에 백업을 먼저 권한다. 도전 코드 입력 예시와 오류 조건을 실제 형식에 맞췄다.
- 접근성 문구를 일어난 일로("삼진", "홈런", "타자 정보 접기"). 스코어보드 상황 줄과 칩에 말줄임을 넣었다.
