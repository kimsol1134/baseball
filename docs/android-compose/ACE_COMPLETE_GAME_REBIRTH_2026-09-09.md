# 에이스의 완투와 다음 생 개선

## 리뷰 원인과 변경

기존 자동 선발은 18아웃에서 끝났고 체력이 다른 능력보다 높을 때만 최대 3아웃이 추가됐다. 모든 능력이 80이면 보너스가 사라졌다. 직접 투구도 18아웃 이후 계속할 수 없었다.

프로 규칙 13은 직접/자동 공통 교체 기준으로 투구 수, 체력, 실점, 후반 무실점 상황을 판단한다. 다른 능력을 올려도 체력 보너스가 줄어들지 않는다. 구종에 붙은 고정 피로 대신 실제 투구 수와 힘 배분에 따른 프로 피로를 적용한다. 한계에 도달하면 교체하고, 몸 상태가 나빠 한 구도 던지지 않은 주는 등판이나 성적 신뢰를 허위로 적립하지 않는다.

- 7~9회 계속 투구 가능. 타순과 주자 책임은 유지한다.
- 이닝 사이 팀 공격을 반영하며 후반 목표를 완투·완봉 도전으로 바꾼다.
- 마운드 유지 / 불펜에 교체 / 내 투수 자동 진행을 구분한다. 교체한 뒤 불펜의 아웃은 내 기록에 넣지 않는다.
- CG·SHO를 실제 결과로 저장하고 앨범·카드·첫 달성 기억에 표시한다. 9이닝을 책임지고 경기가 결정된 경우에만 완투로 기록한다. 완봉은 자책점 0이 아니라 실제 무실점 승리다. 과거 정보가 없는 기록은 ‘—’로 남긴다.
- 이 게임은 9이닝 정규 경기의 완투를 우선 지원한다. 8이닝 패전 완투, 강우 콜드, 연장전 완투를 공식 기록 전체처럼 재현했다고 주장하지 않는다.
- 능력 평가 ‘세대 최고 수준’을 ‘최상급 능력’으로 바꿔 실제 리그 성적과 구분한다.
- 주간 화면에 팀 순위·승패와 완투/완봉/세이브/효율적인 투구 목표를 표시한다.

## 다음 생

환생에서 선발 / 마무리 / 제구형을 먼저 고른다. 확인하기 전에는 시작되지 않는다. 각각 체력형+포심, 변화구형+슬라이더, 제구형+체인지업으로 실제 능력 배분과 주력 구종이 바뀐다. 이름·얼굴·계승 유산·앨범은 보존하며 학교 선택부터 시작한다. 기존 방식으로 이어가기도 남긴다.

선택한 경로를 저장해 프로에서도 서로 다른 목표를 보여준다. 마무리 경로는 캠프의 실제 보직 지원으로 연결하며 즉시 보직을 보장하지 않는다. 선발 경로는 이전 생의 완투 기록을, 제구형은 100이닝·BB/9 2.00 이하를 목표로 한다.

구단·선수·리그 콘텐츠는 독자 가상 세계관이다. 실제 구단명/로고를 가져오는 대신 경기 운영과 지역 팀, 순위, 시즌 기록으로 야구의 느낌을 살린다.

## 검증

- 코어 173개 통과. 과거 Swift 고교 4 / 프로 10 재현을 유지했다.
- 실제 투구로 98구·2–0·9이닝 완봉승을 달성하고 저장/복원을 확인했다.
- 240등판 통제 표본: 내부 능력 50은 9이닝 2회, 65는 10회, 80은 32회. 능력 80의 무실점 9이닝은 15회다. 실제 구종 프로필까지 올린 별도 표본은 9이닝 32회, 무실점 18회다. 모든 표본이 매번 건강한 상태로 시작하는 통제 검사이므로 실제 시즌 완투 비율로 해석하지 않는다.
- 장기 검증 18커리어×20시즌=360시즌, 고교 18조건×7생애=126생애 통과. 결과는 `artifacts/android-compose/ace-long-horizon/`에 저장했다.
- 3생애 실제 native 파일 저장 검사에서 다른 환생 경로를 차례로 선택하고, 학교 선택 진입·유산·구종·이름·앨범 보존을 확인했다.
- 에뮬레이터 기본 슬라이더 실투구 통과. 후반 결정 화면의 자동 전환 없음, 교체/자동 구분, 환생 선택 후 확인, 앨범·주간 화면을 포함한 UI 10개 통과.

프로 저장 스키마 7. CG·SHO·경기 완투 여부는 nullable이며 구버전 해시를 보존한다. iOS에서 별도로 진행 중인 작업은 이 Android 변경에 포함하지 않는다.

20시즌 실제 native 저장→은퇴→환생 검사 통과. 환생 후에도 앨범 297경기·22페이지가 유지됐다. 로그: `artifacts/android-compose/ace-native-twenty.log`.

## 장기 정책별 결과

| 정책 | 검사 시즌 | 완투 | 완봉 | 20시즌 K/9 |
|---|---:|---:|---:|---:|
| 회복 없이 구위 집중 | 120 | 4 | 2 | 7.51 |
| 균형 성장 | 120 | 13 | 5 | 8.3 |
| 회복 우선 | 120 | 4 | 2 | 8.25 |

회복 없이 훈련만 하는 정책은 피로로 등판을 쉬게 된다. 회복을 선택하면 다시 등판할 수 있다. 건강한 최상급 투수의 통제 표본과 이 정책 표본을 혼동하지 않는다.

에뮬레이터 최종 여정: 고교 완료→마무리 선택→학교 선택→재시작 후 마무리 경로·슬라이더 주력 구종·이름·앨범 보존 확인. `ace-rebirth-e2e-final.log` 통과(92.667초). 후반 선택/환생 선택 UI 2개 추가 재검증 통과. 일반 QA APK 빌드 완료. 새 경로와 관계없는 이전 방식의 능력 비교는 숨겼다. 실기기에는 설치하지 않았으며 스토어 배포도 하지 않았다.
