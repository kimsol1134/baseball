## Preservation boundary

The new implementation is deliberately separated from the oracle:

- source migration work lives in `apps/android` and `apps/android-pitch-unity`;
- Unity `unityLibrary` output lives under ignored `artifacts/android-compose/`;
- current oracle code, save data, package identity, signing material, and release artifacts are not
  used as writable migration targets;
- production application ID and production save writes remain disabled in this pass.
