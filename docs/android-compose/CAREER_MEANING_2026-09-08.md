# 육성·등판·진로 피드백 개선

## 플레이 흐름

1. 드래프트는 `지명 완료 · 입단 계약 전` / `미지명`으로 구분한다. 지명된 현재 선수의 주 행동은 `입단 계약 보기`다. 별도 프로 선수 생성은 새 게임 화면에 두고 이름과 유형을 고른 후 실행한다. 환생 중인 고교 선수를 별도 프로 커리어로 보내는 우회 버튼은 제거했다.
2. 훈련에서 즉시 능력치가 오르지 않아도 성장 진도를 보존한다. 가볍게/보통/강하게는 각각 35/60/80 진도, 피로 70 이상에서는 절반이다. 100 진도마다 기존 성장 계산으로 전달한다. 기존 즉시 성장과 첫 훈련 보장은 유지한다. 재능 한계에서는 돌파 진도, 최고 재능에서는 숙련을 구별한다.
3. 직접 등판을 예약할 때 실제 보직, 투입 상황, 목표를 저장한다. 일반 프로 등판은 선발 1회, 긴 이닝 구원 5회, 셋업 8회, 마무리 9회로 구분한다. 기존 포스트시즌 상황은 유지한다. 투구 화면에 역할·점수·아웃·주자·이번 목표를 보이며 공이 날아가는 동안 다음 결과를 미리 표시하지 않는다.
4. 감독 대화는 전문 훈련 지원 / 회복 / 선발 테스트를 선택하게 한다. 포수 대화는 배합 / 코스 / 결정구 지원을 선택하게 한다. 선택 전 예상 효과는 실제 명령과 같은 시드·계산으로 구한다. 선택 후 실제 변화는 확인할 때까지 유지하며 확인 버튼은 게임 명령을 재실행하지 않는다.

## 보상 규칙

- 훈련 지원은 해당 훈련의 성장 신호에 120을 더한다. 다른 훈련에는 소비하지 않으며 여러 종류의 지원을 유지한다. 같은 종류의 지원은 중첩하지 않는다.
- 선발 테스트는 직접 2이닝을 2실점 이하로 막는 목표다. 성공 시 감독 신뢰 최대 +8과 후속 선발 기회를 얻는다. 이후 중요도가 낮은 시나리오에서는 실제 1회 선발 상황으로 시작한다.
- 일반 등판 목표는 무실점 또는 리드 유지다. 성공 시 감독 신뢰 최대 +2를 한 번 받는다. 신뢰 상한 100에서 실제로 오른 양만 표시한다. 추가 이닝 결과가 이미 달성한 목표를 취소하지 않는다.
- 첫 플레이의 기본 조작은 계속 투구 슬라이더다. 자동 릴리스는 명시적으로 고른 보조 기능이다.

## 저장 호환성

- 고교 육성 메타데이터와 고교·프로 등판 목표를 선택적 필드로 추가했다. 기존 파일에 필드가 없으면 기존 커밋먼트와 예약된 투구를 유지한다.
- 고교 외부 저장 스키마는 11, 프로 저장 스키마는 5다. 고교 v9 / 프로 v3 실파일의 읽기·왕복 및 새 필드의 저장 후 재열기를 검사한다.
- UI 결과 확인 기록은 별도 단일 pending 값으로 보관한다. 커리어가 다른 기록은 표시하지 않는다.
