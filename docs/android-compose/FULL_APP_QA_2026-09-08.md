### 2. P1 — 프로 훈련은 진행한 내용과 성과가 잘 보이지 않는다

**확인값:** `강속구 불펜` 한 번 실행 시 구위 **42 → 42**, 성장 진도 **0 → 1**, 피로 **0 → 15**, 자동 경기 **0 → 1**. 성장 진도는 정상적으로 저장되지만 훈련 결과 receipt와 대화 결과 receipt는 모두 생성되지 않는다.

고교의 `훈련 선택 → 예상 결과 → 훈련하기 → 실제 결과`와 달리, 프로는 모든 계획이 초록색 실행 버튼이다. 훈련처럼 보이는 버튼이 한 주와 경기를 함께 진행한다. 일반 성장 알림은 능력치가 실제로 오른 경우에만 잠시 나타나며 누적 진도를 설명하지 않는다.

원인: `TrainingFeedbackView.kt:25`는 고교만 처리한다. `MobileCorePresentation.kt:62`의 성장 receipt도 프로의 진도만 증가한 경우 새 결과를 만들지 않는다. `ProKernel.kt:312`에서 훈련 계획과 자동 등판을 같이 처리한다.

**개선:** 짧은 계획 선택 버튼 + 선택한 계획의 ‘훈련 효과·예상 등판·피로’ + `이번 주 진행`으로 통일한다. 결과는 ‘성장 진도 / 이번 주 경기 / 몸 상태’ 3항목으로 유지한다. 0주차는 ‘시즌 준비’ 또는 다음 행동 기준 ‘1주차 준비’로 표현한다.

**완료 기준:** 능력치 +0인 주에도 누적 진도가 보이고, 몇 경기가 자동 진행될지 실행 전에 알 수 있다. 프로에서도 선택 확인과 실행이 구별된다.

### 4. P1 — 대화 선택 전에 피로 같은 비용이 빠진다

**확인:** ‘선발 기회에 도전할게요’에는 선발 테스트와 구위 +2만 미리 보인다. 해당 감독 유형의 실제 선택에는 피로 +6도 있다. 선택 후에야 이 비용을 확인하게 된다.

### 5. P2 — 중요 경기 전 화면에 같은 정보가 반복된다

### 7. P2 — 능력 상승과 피로 증가가 같은 색이다

훈련 예상의 ‘제구 +2’와 ‘피로 5 → 12’가 모두 같은 빨간색이다. `StatChangeText.kt:20`은 좋은 변화/나쁜 변화 대신 숫자의 증가/감소로 색을 정한다. 대화 결과는 좋은 변화가 초록색이어서 기준도 서로 다르다.

**개선:** 숫자 방향과 플레이어에게 유리한 방향을 분리한다. 능력 증가·피로 감소는 성장색, 피로 증가·신뢰 감소는 주의색으로 표현하고 +/- 기호를 유지한다. 색상만으로 뜻을 전달하지 않는다.

**개선:** 효과를 타입이 있는 항목으로 전달하고 각각 번역한 뒤 합친다. 초상화 seed는 번역된 이름 대신 고정 인물 ID를 사용한다. 실제 합성 문장과 언어 변경 전후 동일 인물 얼굴을 UI에서 검사한다.

그 다음 애착을 강화할 개선으로는 **선발 테스트 통과·처음 지킨 리드·가장 어려웠던 등판을 한 줄 기억 카드로 남기고, 다음 대화에서 그 실제 기록을 언급하는 기능**을 추천한다. 전체 기록을 긴 글로 다시 보여 주기보다 ‘내 투수가 해낸 일’을 골라 되돌려 주는 방향이다. 이 항목은 결함 판정이 아닌 후속 제안이다.
