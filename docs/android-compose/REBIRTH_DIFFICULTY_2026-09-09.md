# 첫 육성 난이도와 환생 성장 검증

## 구현

- 고교 규칙 7: 첫 불펜 튜토리얼은 기존 계산을 유지하고 공식 직접/자동 경기에 새 투구 확률을 적용했다.
- 고교에서도 제구가 낮으면 볼넷·실투가 나오고, 구위/구종의 중복 보너스가 타자를 지나치게 압도하지 않도록 했다. 실제 가운데로 몰린 공은 타구 품질에 영향을 준다. 홈런을 예약하거나 결과를 강제로 조작하지 않는다.
- 자동 경기의 초반 타자 약화는 -6에서 -1로 줄였다. 환생 횟수만으로 상대 능력이 +2/+4 오르던 보정을 없앴다. 학년/대회 차이는 유지한다.
- 완료하고 기록한 생애의 계보 기여를 합산해 기초 능력과 구종의 제구·무브먼트·헛스윙·약한 타구 유도·구속에 반영한다. 계열을 바꿔도 기여는 사라지지 않는다.
- 완료 생애 1~4회는 생애마다 내부 능력 +3, 이후에는 +1씩 늘어 최대 +16이다. 총 보너스를 새 선수 생성 시 한 번 적용한다. 단순 lifeNumber만 올려서는 보상을 받지 않으며, 완료 생애 수를 초과하는 기여도 반영하지 않는다. 기존 선수의 능력을 소급 변경하지 않는다.
- 새로 어려워진 경기 환경에 맞춰 드래프트 평가를 보정했다. 첫 생애라서 무조건 탈락하거나 환생했다고 자동 지명하는 조건은 없다.
- 선수 프로필에 이전 생과 이번 생의 실제 시작 능력을 비교한다. 성장 유형을 바꿨다면 내려간 능력도 그대로 표시한다. 한국어·영어·일본어로 제공한다.
- 기존 저장→규칙 7 전환에서 자동 경기 합계와 개별 기록이 일치하도록 했다. 과거 규칙 4의 Swift 비교 경로는 유지한다.

## 126생애 실제 진행 결과

3개 시드 × 2개 성장 유형 × 3개 훈련 강도 × 7생애. 학교 선택, 훈련, 대화, 투구, 각성, 드래프트, 유산 선택, 환생을 실제 엔진 명령으로 실행하고 생애마다 저장/복원을 검사했다. 직접 투구는 780~915 릴리스, 740~860 조준 입력을 사용한다. 자동 경기와 직접 경기의 합계 검사를 추가했다.

게임 ID의 숫자 크기를 순서로 보지 않고 실제 기록 추가 순서로 묶었다. 10,000번대 자동 경기도 첫 3·10경기에 포함된다. 직접 투구의 승계 주자와 짧은 이닝 때문에 이 값은 고교 전체의 공식 ERA가 아니라 게임 내 실점 기준 RA/9다.

|---|---:|---:|---:|---:|---:|---:|---:|
| 1 | 5.49 | 6.69 | 7.81 | 1.32 | 4.65 | 5.16 | 4/18 |

같은 입력 정책의 제한된 표본이며 실제 사용자 지명률을 의미하지 않는다. 상대·컨디션·선택이 다른 개별 생애는 직전 생애보다 나쁜 성적도 나올 수 있다. 매 경기나 모든 생애의 성적 상승을 보장하지 않는다.

별도 통제 검사에서는 동일한 초기 선수·상대·경기 난수를 두고 완료 생애 보너스만 바꿨다. 초기 RA/9 6.75 → 7번째 생애 4.81, HR/9 1.01 → 0.66, BB/9 4.85 → 3.68. 후기에도 홈런과 실점은 발생하고 초기에도 무실점 경기가 가능했다.
