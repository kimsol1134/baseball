# Android 출시 개선 상태

최신 PM 1·2·3번 실행 결과는 [출시 기준 및 고정 후보 검증 결과](RELEASE_GATE_RESULTS_2026-09-05.md)를 따른다. 버전 42 QA 후보를 별도 체크아웃에 고정했으며, 최종 production 서명은 업로드 키 설정 대기 상태다.

기준일: 2026-09-05. 목표는 Android 유료앱 1위를 지향하는 출시 품질이며, 순위는 구현 완료 기준이나 보장치가 아니다. 최초 비교 보고서는 `docs/ANDROID_IOS_LAUNCH_COMPARISON_2026-09-05.md`에 보존하고, 이후 구현 결과는 이 문서를 따른다. 시작 전 존재한 Android/iOS 미커밋 변경을 보존했다. 스토어 업로드·웹 배포·외부 메시지 전송은 하지 않았다.

## 구현

차이 재점검 이후 구종 학습→관계 대화→각성·결산→표시 수치→햅틱을 개선하고 파일 복원을 추가했다. 최신 결과와 남은 플랫폼 작업은 [후속 개선 결과](PARITY_IMPROVEMENTS_2026-09-05.md)를 따른다. 아래 구현/검증 이력은 전체 iOS 경험의 동등성 완료를 뜻하지 않는다.

- 빌드: Unity 제거 후 남은 의존성 잠금을 실제 그래프에 맞췄다. 저장 스키마 검사는 7 고정 문자열 대신 실제 7+ 호환 읽기 경계를 검증한다. Swift 프로 fixture를 현재 소스에서 재생성하고 소스 트리 SHA-256과 출력 해시를 함께 검증한다. 대표팀 피로는 오프시즌 투자 단계를 마친 뒤 다음 시즌에 이월되는 것을 확인했다.
- 프로 선택: 등판 간격, 신구종 실전 시험, 2군 재정비, 베테랑 조언의 4종 결정과 3주 효과·후속 결과를 연결했다. 스프링캠프 보직 지원에는 자격·계약 제약·조건부 6주차 평가·시즌 중 중복 방지가 있다.
- 첫 플레이: 첫 생은 3단계, 빈 이름은 언어별 추천 이름, 기본은 직접 슬라이더 투구다. 상단 반복 앱 이름과 `첫 화면/선수 준비` 구분을 없앴다. 이름·지역·유형은 질문으로 표시하고 다음/시작 버튼을 고정했다. 지역은 실제 선택 버튼이다. 첫 편지와 투구 안내에서도 반복 이름·튜토리얼 상태·불필요한 탭을 줄였다. 저장 표시가 행동 버튼을 밀어내던 배치를 제거했다.
- 커리어 화면: 훈련·관계·프로 주간은 현재 선택과 결과를 먼저 보여주고 상세 정보는 펼쳐 본다. 용어를 해당 숫자 옆에서 확인할 수 있다. 리뷰 요청 간격·제품 시점 등 내부 운영 설명과 raw ID를 제품 문구에서 제거했다.
- 환생: 구종·주 구종·야구혼 계승 분야·부스트·난이도를 실제 시작 능력과 연결했다. 사용자 설정을 여는 동안 이전 기록을 보존하고 확인 시에만 새 생을 시작한다. 빠른 환생에서 이전 소모성 부스트를 다시 구매하지 않는다.
- 저장: 배포 저장 어댑터가 고교의 일부 필드만 복원하던 문제를 수정했다. 전체 고교 상태와 원본 core 해시를 함께 저장한다. 프로 URL-safe Base64의 읽기 불일치도 해결했다. 프로 은퇴 기록과 보상을 한 번만 남기고 다음 고교·새 프로에서도 보존한다. 상점 잔액을 자동 능력 상속과 분리했다.
- 경기 수: 중간 투구를 공식 경기로 세지 않는다. 고교와 프로를 오가도 누적 경기 수를 증가분으로 합산한다. 연속 포스트시즌 경기는 각각 끝날 때 한 번만 센다.
- 조작·성능: 정확도 점수로 빠름/늦음을 잘못 표시하던 피드백을 수정했다. API35+ 수동 슬라이더에서 View 프레임률을 최대 120Hz까지 요청하며 화면 종료 시 원래 요청값을 복원한다. 자동 릴리스는 사용자가 켜는 보조 경로다.
- 현지화: iOS 번역과 Android 추가 문구를 5,176개 ko/en/ja 카탈로그로 통합했다. `tools/import-android-localization.mjs --check`로 동기화를 검사한다. Kotlin 정적 문구 목록은 현재 누락 0건이다. 이는 번역 품질의 자동 보증이 아니므로 실제 화면을 별도로 검사한다. 사용자 이름은 번역하지 않으며 숫자·단위, 투구 Canvas, 화면 읽기, 공유 카드, 알림에도 표시 언어를 적용했다. 이닝의 `회`는 반복 횟수와 구분해 번역한다.
- 공유: 드래프트·대표팀·은퇴·기록을 PNG와 글, 설치 링크로 공유한다. 장문은 카드 영역을 넘지 않도록 제한한다. 실제 파일 제공 URI와 읽기 권한을 검사하며 외부 수신자에게 보내지 않는다.
- 도전: iOS와 호환되는 `UInt64 시드-생 번호` 코드/링크 생성·수신·수동 입력을 연결했다. 확인 후 별도 도전에 들어가며 원래 고교/프로·기록·잔액·경기 수를 복원한다. 같은 코드/유형의 초기 조건은 설치와 관계없이 같다. 일반 성취 기록을 도전 시드라고 위장하지 않는다. 웹 도전 페이지에는 Google Play 안내를 추가했으며 아직 배포하지 않았다.

## 검증 근거

- 전체 JVM: 268개, 실패 0개. 고교→프로 20시즌→은퇴→다음 생→새 프로와 파일 재열기 포함. 추가 경기 수 검사는 연속 포스트시즌도 확인한다.
- Native 저장 JVM: 고교 전체 필드와 프로 상태의 생산 형식 저장/재열기 통과. 도전 파서·원래 커리어 복원·동일 시드 검사 통과.
- UI: Galaxy와 API35/16KB 에뮬레이터에서 첫 플레이를 검사했다. 화면·플랫폼 semantics 7개 통과, 글자 100/130/150/200%에서 생성 버튼을 확인했다. 도전 링크 수신→확인→시작→원래 이야기 복원 UI 검사 통과.
- Galaxy A53 (SM-A536N, Android16/API36, 4KB): 최신 수동 슬라이더 120Hz 요청에서 callback 중앙 간격 8.345ms/107회, 60Hz에서 16.683ms/57회. 생성→첫 투구→생산 형식 저장까지 각각 10.63/10.70초(자동 테스트 기준이며 신규 사용자의 실제 소요 시간은 아님). 패널 Hz와 전체 장면의 실제 FPS는 구분한다.
- Galaxy 장시간: 이전 동일 연출 코드의 20분/294회 재생, 34,454 frames, jank 1.04%, P95 13ms/P99 20ms, thermal status 최대 0, native heap 38.07~38.76MB. 테스트 중 게임 기록 불변. QA debug 계측이며 서명 release 수치가 아니다. 진동의 주관적인 촉감은 사용자 확인 대상이다.
- 공유 카드: 한국어·영어·일본어 실제 PNG(1080×1350), 본문·도전 URL·FileProvider 읽기 권한 검사 통과. 영어·일본어 렌더를 직접 확인했다.
- `check-android-compose`, `check-android-phase9`, `check-android-compose-release` 소스 검사, `check-copy`, 관계 대사 대조, locale importer, Gradle lint 통과. 웹 도전 페이지 TypeScript 검사 통과.
- 최신 ko/en/ja 첫 플레이: 지역 변경→수동 슬라이더→결과 확인→학교 선택까지 모두 통과. 영어/API35 에뮬레이터 13.157초, 일본어/Galaxy 17.074초, 한국어/Galaxy 16.702초(스크린샷·화면 읽기 검사 포함). 최신 설정·접근성·도전·공유 UI 9개 통과.
- 배포 저장 경로의 20시즌 완주 검사도 통과했다. 이 검사에서 완료 투구가 resume과 함께 지워지는 차이를 발견했고, C# resume은 비우면서 `meta.nativeTerminalPitch`에 완료/포기 기록을 보존하도록 수정했다. 이후 관련 Native/도전/전체 커리어 검사와 나머지 application/app/platform 회귀 검사를 모두 통과했다. 실행 증거: `artifacts/android-compose/qa-launch/verification-summary.json`.

## 외부 출시 조건

1. 현재 프로세스에 업로드 키·암호·Firebase 설정·Amplitude 키 주입값이 없다. 이 작업본의 새 서명 production AAB는 만들지 않았다. 과거 RC 41을 이번 수정본으로 취급하면 안 된다.
2. Play Console의 실제 최신 versionCode와 테스트/프로덕션 트랙을 확인하고 그보다 높은 버전으로 새 후보를 만든다. 기본값 37을 그대로 올리지 않는다. 서명된 동일 후보에 업데이트 설치·기존 저장 복구·16KB 및 지원 하한 Android 확인이 필요하다.
3. 실제 Play 앱 서명 인증서를 확인하기 전에는 verified App Links를 완료했다고 할 수 없다. 현재 custom scheme과 도전 코드 입력 경로는 구현되어 있다. 웹 Google Play 버튼 변경도 배포가 필요하다.
4. 실계정의 테스트 자격, 국가/언어·가격·스토어 소재·데이터 신고, 동의 후 외부 분석/충돌 수신을 최종 후보로 확인한다. 로컬 테스트만으로 Play 승인 또는 랭킹을 주장하지 않는다.
5. 일본어/영어는 정적 누락·대표 UI 검사 외에 주요 커리어 대사를 읽는 언어별 플레이 검수를 권장한다. 하한 기기와 다른 성능 등급 Galaxy는 이번 A53 검사로 대체하지 않는다.

## 파일과 정리

소스/검증: `apps/android`, `docs/localization/android-copy.json`, `docs/localization/android-legacy-copy.json`, `tools/import-android-localization.mjs`, `tools/inventory-android-localization.py`.
증거는 `artifacts/android-compose/qa-launch/` 한 디렉터리에 보관한다. 일반 development/production 앱의 저장은 지우지 않았다. 설치·초기화는 `.compose.qa`에 한정했다. 임시 `/tmp/baseball-android-*`, 기기 QA 캐시와 장시간 테스트 로그는 검증 완료 후 정리 대상이다. 이번에 새 에뮬레이터나 시뮬레이터를 만들지 않았다.

최종 정리: 사용 중이지 않은 과거 RC 37~39의 생성물 약 67MiB를 제거하고 40·41은 보존했다. 이번 QA 증거는 한 디렉터리에 보관한다. Galaxy QA 앱은 사용자 화면 확인을 위해 한국어 첫 화면에 두며, 테스트 APK와 임시 로그는 제거한다.

## 후속 실기기 피드백 반영

사용자의 연습 시작 실패를 반영해 저장 취소 경계와 명령 묶음의 동시 실행을 수정했다. 기존 기록을 보존한 실기기 진행과 취소 재현 검사를 확인했다. 182개 플레이어 문구 정리 및 3언어 UI 재검증 결과는 [후속 검증 기록](PLAYER_POLISH_2026-09-05.md)을 따른다.

## 훈련 후속 개선

iOS 훈련 화면과 비교해 종류 선택/실행 분리, 3단계 강도, 대상 구종, 실제 비용·성장 전망, 결과 카드와 안전하게 멈추는 ×3 훈련을 추가했다. [훈련 비교·검증 기록](TRAINING_COMPARISON_2026-09-05.md)에 남은 표시 눈금/학습 단계 차이도 명시했다.

## 직접 투구·햅틱 후속 개선

직접 구종/코스 선택을 기본 노출하고 슬라이더를 고정했다. 제스처 취소 시 미투구, 릴리스 시 선택 확정, 앱/시스템 진동 설정 존중과 기기 기본 효과 대체 재생을 검증했다. Galaxy에서 시작·릴리스·타이밍·성공 효과의 모터 재생 완료를 확인했다. [후속 기록](PITCH_CONTROL_HAPTICS_2026-09-05.md)을 따른다. QA 그림/원시 증거는 보관 정책에 따라 최근 3개 묶음만 유지한다.
