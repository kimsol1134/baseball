# 직접 투구와 햅틱 개선

## 직접 선택

기존에는 `내 선택 유지` 설정을 켜거나 이미 Manual 선택 상태여야 구종/코스 선택이 나타났다. 실제 사용자는 포수 추천 1안·2안만 볼 수 있었다.

- 구종과 3×3 코스 선택을 기본 화면에 표시한다. 터치 영역은 최소 48dp로 하고 선택 코스를 문자와 색으로 구분한다.
- 추천은 사용자가 원할 때 고르는 보조 선택이다. 구종/코스 선택은 `내 선택 유지` 스위치와 독립적으로 사용할 수 있다.
- 구종·코스·세부 설정은 스크롤할 수 있고, 직접 누르고 놓는 투구 슬라이더는 아래에 고정한다. 경기 연출은 공을 던진 뒤 보여준다.
- 릴리스 순간의 선택을 캡처하고 제출 상태를 즉시 바꾼다. 비동기 저장이 시작되기 전에 다른 선택으로 바뀌거나 중복 제출되는 틈을 줄인다.
- 슬라이더의 드래그는 조준 오차를 줄이는 동작이며, 목표 코스 자체는 위의 3×3 선택으로 정한다. 실제 명중은 게임의 제구/타이밍 규칙을 따른다.

## 햅틱

실기기에서 앱 진동과 시스템 터치 진동은 켜져 있었고 시스템 강도는 LOW였다. 시스템 전체 설정은 변경하지 않았다.

짧은 일회성 진동 경로를 조사하고 기기용 기본 효과로 바꿨다. 중간 검증에서 `View.performHapticFeedback(8)`은 true를 반환했지만 Galaxy 서비스 로그에는 `ignored_unsupported`로 남았다. 따라서 API 반환값만으로 진동 완료라고 판단하지 않았다.

최종 구현은 Android 29+에서 대체 재생을 지원하는 기본 효과(HEAVY_CLICK/CLICK/TICK/DOUBLE_CLICK)와 TOUCH 용도를 사용한다. 이전 Android에서는 지원되는 View 피드백을 사용한다. 앱 진동 스위치와 시스템 설정을 존중한다. 화면 움직임 줄이기는 진동을 끄지 않는다. 시작·릴리스·타이밍·성공에 각각 피드백을 제공하고, 입력 피드백을 연출의 중복 릴리스 진동이 덮지 않게 했다. 누르는 동안 심장박동 진동과의 충돌도 줄였다.

투구 화면에서 진동을 켜고 끄거나 `진동 확인` 버튼으로 확인할 수 있다. 실제 촉감은 시스템 강도와 기기 특성에 영향을 받는다.

공식 참고: [Android 터치 피드백과 기본 진동 효과](https://developer.android.com/develop/ui/views/haptics/haptic-feedback).

## 취소 처리

이전 코드는 제스처 finally 블록에서, 손을 정상적으로 뗀 것인지와 관계없이 일정 시간 누르고 있었으면 공을 던질 수 있었다. 이제 실제 release가 확인된 경우에만 던지며, 화면 이탈·제스처 취소·추가 터치로 취소되면 제출하지 않는다.

## 검증

- 기본 설정에서 숨겨진 옵션을 켜지 않고 커브와 낮은 왼쪽 코스 선택 가능.
- 실제 저장된 투구 결과의 구종이 선택한 커브임을 확인.
- 400ms 누르기 후 ACTION_CANCEL은 0구, 정상 ACTION_UP은 정확히 1구.
- 위 제스처 검사는 움직임 줄이기를 켠 상태로도 확인.
- Galaxy 진동 서비스에서 HEAVY_CLICK, CLICK, TICK, DOUBLE_CLICK이 TOUCH 용도로 `finished` 상태까지 도달한 것을 확인.
- Galaxy QA 업데이트 전후 기존 저장 파일이 바이트 단위로 같았다. 기기 테스트는 별도 제스처 화면에서 하여 사용자 커리어의 투구를 진행하거나 초기화하지 않았다.
- 앱 빌드/lint/단위 검사, 햅틱 정책 검사, 실제 수동 선택을 처리하는 application 검사 통과.
