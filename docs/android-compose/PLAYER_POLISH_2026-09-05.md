# 실기기 진행 오류와 플레이어 문구 개선

## 진행 오류

실기기에서 `game.command.stale_revision`이 반복됐다. 저장 파일과 메모리의 진행 상태가 달랐다. 저장 완료 직후 호출 Activity가 취소되는 상황을 재현한 테스트는 수정 전에 실패했고 수정 후 통과했다.

- GameStore가 저장을 시작한 뒤에는 파일 기록과 StateFlow 반영을 함께 마친다. 대기 중인 호출의 취소는 여전히 허용한다.
- 하나의 버튼이 보내는 여러 명령 사이에 백그라운드 이벤트가 끼어들지 않도록 같은 잠금 안에서 실행한다. 오래된 선택을 임의로 새 선택으로 바꾸거나 검증을 끄지 않는다.
- 화면 복귀 시 실제 저장과 상태를 대조한다. 오류 카드도 실제 상황에 맞는 안내를 표시한다.
- Galaxy의 기존 QA 저장을 지우지 않고 업데이트했다. 막혔던 연습 시작 버튼이 진행됐으며, 이후 같은 Identity/CareerId로 연습 완료 및 ImportantGame 진행을 확인했다. 사용자가 계속 플레이 중이므로 옛 연습 장면으로 되돌리지 않았다.

## 문구

첫 시작, 선수 생성, 투구, 훈련, 관계 선택, 프로 계약, 주간 계획, 비시즌, 은퇴, 환생, 기록, 업적, 설정, 용어 설명의 표현을 검토했다. 182개 항목을 정리했으며 기존 한국어 165개를 고치고 나머지 안내와 번역을 보완했다.

| 이전 | 변경 |
|---|---|
| 첫 사인 익히기 | 투구 연습하기 |
| 튜토리얼 마치기 | 학교 선택하기 |
| 한 블록을 고르면 몸이 남습니다 | 어떤 능력을 키울지 골라 보세요 |
| 능력 포커스를 정해 다음 시즌 헤드스타트를 얻습니다 | 집중 훈련으로 능력을 키우고 다음 시즌을 준비해요 |
| 이번 생의 동결 기록 | 이번 생의 최종 기록 |
| 사인이 맞을수록 실행이 살아납니다 | 포수와의 호흡이 좋을수록 사인에 맞춰 안정적으로 던질 수 있어요 |

안내는 행동과 효과를 먼저 설명하고, 서사와 도움말의 말투를 구분했다. 영어·일본어도 함께 수정했다. 이전 세이브에 저장된 문장도 표시할 때만 고치며 저장 원문·RNG·사용자 이름은 바꾸지 않는다. 원문과 새 문구는 `docs/localization/android-player-copy.json`에 함께 보관한다.

업적에는 내부 ID 대신 달성 조건을 표시한다. 실제 조건이 무실점인 항목의 삼자범퇴 표기를 고쳤다. 새로 달성하는 경로가 없는 과거 업적은 이미 얻은 기록만 표시한다.

QS·WHIP·FIP·WAR 설명의 의미는 공식 용어 자료와 대조했다: [QS](https://www.mlb.com/glossary/standard-stats/quality-start), [WHIP](https://www.mlb.com/glossary/standard-stats/walks-and-hits-per-inning-pitched), [FIP](https://www.mlb.com/glossary/advanced-stats/fielding-independent-pitching), [WAR](https://www.mlb.com/glossary/advanced-stats/wins-above-replacement). 실존 구단·리그 이름은 게임 문구에 추가하지 않았다.

## 검증

- 저장 취소 재현: 수정 전 실패, 수정 후 통과.
- 취소 시 메모리/파일 일치 및 다음 명령 성공, 여러 명령 사이 배경 이벤트 차단 검사 통과.
- 전체 JVM 회귀 통과 후, 문구·업적 표시 변경에 영향을 받는 검사 재실행 통과.
- 화면/플랫폼 UI 7개, ko/en/ja 새 게임→지역 선택→슬라이더→결과 확인→학교 선택 통과.
- lint, 정적 문구/IP 검사, 관계 대사 대조, 카탈로그 동기화 검사 통과.
- 결과 파일: `artifacts/android-compose/qa-player-polish/verification-summary.json`.

실기기 원본 저장 백업은 동일 선수 보존을 확인한 뒤 임시 데이터로 정리한다. 사용자 기기의 진행 중 게임은 초기화하지 않는다.
