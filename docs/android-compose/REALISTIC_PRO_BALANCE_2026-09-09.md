# 프로 밸런스 개선 및 검증

## 기준

[공식 팀 투수 기록](https://www.koreabaseball.com/Record/Team/Pitcher/Basic1.aspx)에서 정규시즌과 2023·2024·2025년을 각각 선택해 합계를 확인했다. 진행 중인 2026년은 제외했다. 원자료는 `benchmarks/pro-pitching-2023-2025.json`에 보관한다. 실제 명칭은 조사 문서에만 쓰며 게임 콘텐츠는 가상 세계관을 유지한다.

세 시즌의 아웃 수를 합산한 기준: ERA 4.4516, RA/9 4.9633, WHIP 1.4389, K/9 7.4584, BB/9 3.6397, HR/9 0.8328. 시즌별 ERA는 4.14 / 4.91 / 4.31이다. 평균 ERA들의 산술평균으로 대체하지 않았다.

## 구현

1. **실제 기록 정산**: 프로 기록에 nullable ER과 투구 중 주자 책임 원장을 추가했다. 새 기록은 실제 득점 사건으로 계산하고, 정보가 없는 과거 시즌·진행 중 구버전 등판은 ER을 추정하지 않는다. 이닝당 지표는 정수 아웃 수로 계산한다. 사구는 BB에 넣지 않는다.
2. **수비 실책**: 프로 새 규칙에는 1루가 비어 있는 상황에서 평범한 땅볼을 놓치는 실책이 있다. 기존 주자는 정지하고 타자만 1루에 나간다. 실책 출루는 안타가 아니며, 실책이 없었을 때의 아웃 수를 따로 보존한다. 가상의 세 번째 아웃 이후 실점은 비자책이다. 모든 수비 실수·송구 실책을 재현하는 공식 기록원 전체 구현은 아니다. 현재 게임에서 실제 발생시키는 플레이 범위에 맞춘 정산이다.
3. **교체 후 주자**: 승계 주자와 본인이 출루시킨 주자를 구분한다. 자동 등판이 끝났을 때 남긴 주자는 후속 투수로 같은 이닝을 시뮬레이션해 정산한다. 후속 투수의 아웃·피안타·볼넷은 원 투수의 기록에 넣지 않는다.
4. **직접+자동 경기**: 직접 던지지 않은 이닝은 실제 투구 엔진으로 계산한다. 기존 기록에 이닝 비율을 곱해 안타·삼진·실점을 나눠 갖는 방식을 새 프로 규칙에서 제거했다.
5. **투구 확률**: 구위·무브먼트·구종·구속의 중복 헛스윙 보너스를 하나의 완만한 효과로 합쳤다. 제구가 높아도 존을 벗어날 여지를 남겼고, 컨택·파울·타구 품질·홈런 조건을 함께 조정했다. 시즌 성적을 사후에 잘라내는 상한은 없다. 퍼펙트는 좋은 실행이지 자동 삼진이 아니다. 기본 투구 슬라이더와 햅틱을 유지한다.
6. **타선과 보직**: 출루형 상위 타선, 중심 장타자, 하위 타선의 서로 다른 능력 조합을 사용한다. 타순은 한 경기 안에서 반복돼도 같은 선수다. 직접·자동 경기 모두 같은 생성기를 사용하며, 프로 타자 능력을 환생·선수 능력·연차에 맞춰 끌어올리지 않는다. 정상 24주 일정에서 선발 28회, 셋업·마무리 60회를 배정하고 부상·임시 보직 지시에 따라 줄어든다. 화면 예상 등판 수도 같은 규칙이다.
7. **성장과 노화**: 구위 하락과 함께 구종 구속·헛스윙·무브먼트도 나이에 맞춰 변한다. 강한 고교 훈련의 기본 피로는 15→11로 줄였다. 첫 훈련 성장 및 보통·강함의 추가 성장 확률은 유지한다. 환생의 기본 보상은 유지하고 높은 능력이 삼진 확률을 폭증시키지 않도록 했다.
8. **기록과 보상**: 앨범·경기 카드·시즌 카드에 ERA/ER을 표시한다. 오래된 기록은 ‘—’다. 명예의 전당은 현실적인 삼진·이닝·승리·세이브·좋은 ERA 시즌으로 도달할 수 있게 재조정했다. 마무리의 세이브도 보직에 맞는 누적 기여로 인정한다.

## 호환성

- 현재 고교 규칙 6 / 프로 규칙 12 / 프로 저장 스키마 6.
- 과거 Swift 비교 고교 4 / 프로 10은 유지한다. 과거 기준 수치나 체크섬을 현재 결과로 다시 만들지 않는다.
- 기존 저장의 누락 ER·원장은 null로 읽고 기존 커밋 계산을 보존한다.
- 실기기 데이터는 변경하지 않았다. 검증은 별도 에뮬레이터 audit 패키지에서 한다.

## 검증 상태

최종 실행 결과를 아래에 기록한다. 통제된 능력별 표본은 실제 리그 선수 분포를 그대로 복제한 표본이 아니며, 3개년 합계와 경향·크기를 비교하는 회귀 검사용이다. 모든 선수·모든 시즌을 리그 평균 성적으로 맞추지 않는다.

### 에뮬레이터

- Android 15 / API 35, 재사용 emulator-5554의 새 audit 패키지에서 검증했다.
- 새 게임 기본 슬라이더로 실제 한 구 투구: 통과.
- 프로 한 시즌 진행→기록·상세 통계→공유 카드→OS 공유 선택창: 통과. 실제 공유 전송은 하지 않았다.
- 실제 카드: 83⅓이닝, R 36 / ER 34, ERA 3.67, WHIP 1.45. 숫자 줄바꿈·잘림 없이 표시된다.
- 백업 복원·손상된 백업 거부·저장 실패 유도 후 정상 재시도: 통과.
- 앨범 및 주간 계획 UI 8개(큰 글씨, 영어·일본어, 카드/재생 포함): 통과.

### 검증 범위와 한계

- 2023–2025년 **공식 리그 합계**를 확보했다. 각 선수의 선발/불펜별 실측 분포 전체를 수집하거나 실제 리그 일정을 복제한 것은 아니다. 보직 등판 수는 게임의 24주 일정에 맞춘 설계값이다.
- 첫 프로 커리어는 2군에서 시작할 수 있어 첫해 성적을 1군 평균과 바로 비교하지 않는다.
- 고교의 과거 기록에는 자책점 원장이 없으므로 ERA를 만들지 않는다. 프로에서 새로 기록한 성적부터 제공한다.
- 기존 일반 QA 설치·실기기 저장은 변경하지 않았다. Android/iOS 스토어 배포는 하지 않았다.

증거: `artifacts/android-compose/long-horizon/`의 전후 CSV와 요약, `artifacts/android-compose/realistic-qa/`의 실제 화면 및 QA 결과. 코드 테스트: `realistic-final-validation.log`, 실제 제스처: `realistic-slider-smoke.log`, 프로/앨범: `realistic-fan-e2e.log`, UI: `realistic-ui-check.log`.

### 실제 파일 저장 검증

- 고교→프로 20시즌→은퇴→환생을 실제 native 파일 저장소로 실행하고 단계마다 닫기/다시 열기를 검사했다. 1~20시즌이 모두 존재하는지 별도로 확인했다.
- 은퇴 뒤 환생해도 앨범 419경기와 22페이지가 남았다.
- 별도 3생애 저장 검증에서 이전 경기 수 21→41→63이 누적 보존됐다.
- 테스트의 시즌 번호를 전환 전 값으로 재사용하던 부분을 수정했다. 실제 시즌 리뷰 시점의 번호를 사용하고 최종 20개 시즌 연속성 검사를 추가했다. 게임의 은퇴 조건을 테스트에 맞춰 완화하지 않았다.
- 실제 프로 마운드에서 기본 슬라이더 투구→홈 이동→복귀→파일 재열기 후 투구가 한 번만 반영되고 주자 책임 원장이 유지되는 검사도 통과했다.

증거: `realistic-native-final.log`, `realistic-pro-slider.log`, `realistic-ui-final.log`, `long-horizon/native-linked-20-seasons.csv`, `long-horizon/native-three-lives.csv`.
