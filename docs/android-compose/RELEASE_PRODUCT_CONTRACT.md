# Android 출시 제품 기준

결정일: 2026-09-05. 사용자가 승인한 PM 제안 1·2·3번을 실행한다. 모집·관찰·인터뷰 등 플레이테스트는 사용자가 담당한다. 이 문서는 개발·자동 비교·출시 후보 검증의 기준이다.

## 제품의 약속

| 약속 | 출시 후보에서 확인할 동작 | 출시를 막는 실패 |
|---|---|---|
| 내가 던진다 | 기본 슬라이더, 사용 가능한 구종·목표 코스 선택, 타이밍/조준 입력을 판정에 전달, 결과 표시 | 선택 무시, 취소 시 투구, 중복 투구, 저장 중 진행 막힘 |
| 내 선수가 성장한다 | 훈련 종류/강도/대상 선택, 성장·학습의 실제 결과, 전후 표시, 재시작 후 보존 | 표시와 실제 성장 불일치, 학습 해금/보상 누락 또는 중복, 기존 구종 소실 |
| 다음 생이 기대된다 | 지명 이유, 각성/유산의 의미, 은퇴와 보상 정산, 다른 빌드로 환생 | 지명/보상 규칙 불일치, 보상 중복·손실, 이전 기록 유실 |

## 플랫폼 동등성 정책

- **일치 필수:** 같은 규칙 버전·시드·선택·선수 상태에서 투구 판정, 능력 성장, 구종 학습, 각성 효과, 지명, 계약/시즌/은퇴 보상과 환생 적용값. 저장 포맷과 내부 식별 문자열은 비교값에서 제외하되 복원된 게임 의미는 유지한다.
- **정보 수준 일치:** 선택의 효과와 비용, 관계 사건/신뢰도별 맥락, 지명 이유와 다음 생 준비. Android 전용 문구는 허용하지만 실제 효과와 달라서는 안 된다.
- **플랫폼별 구현 허용:** 화면 배치, 뒤로 가기, 파일 선택기, 진동 강도/간격. 동일한 API나 픽셀보다 직접 조작 가능·취소 안전·타이밍 인지가 기준이다.
- **후속 범위:** 온라인 이용자 순위, 계정 기반 자동 동기화, iOS 성격/연대기 연출 전체. 수동 파일 복원은 출시 범위이며 실제 기기 간 복원을 확인한다.
- **기존 기록:** 새 기능을 이유로 기록을 초기화하거나 이미 사용하던 구종을 잠그지 않는다. 이전 버전의 저장 바이트와 해시 호환을 별도로 검사한다.

## 차이 판정과 완료 정의

차이는 `BLOCKER`(출시 차단 버그), `PLATFORM`(명시한 플랫폼 차이), `LATER`(후속 개선), `UNVERIFIED`(근거 없음)로 기록한다. 재현 시드·입력·양쪽 결과·수정/유지 이유를 남긴다. 필수 규칙 차이를 `PLATFORM`이나 `LATER`로 옮겨 검사를 통과시키지 않는다.

완료는 ① 구현 ② 지정 검사 통과 ③ 해당 산출물/소스 해시 기록으로 구분한다. 과거 검증, QA debug 앱, 스토어의 현재 판매 바이너리를 서로 대체하지 않는다. 테스트 기대값은 현재 Swift 실행에서 생성하며 Android 결과로 덮어쓰지 않는다.

## 출시 후보 조건

1. 고교·프로·은퇴·환생 경계의 동일 입력 비교에서 미해결 BLOCKER 없음.
2. 기본 슬라이더 실제 한 구, 중단/복귀, 업데이트 후 기존 기록, 복원 후 이어 하기 통과.
3. 동일 소스에서 만든 서명 production 후보의 버전·인증서·APK/AAB 해시가 확정됨.
4. 해당 후보의 지원 기기/16KB·릴리스 설정 검증이 완료됨. 외부 자격 증명이 없거나 검증하지 못했으면 `UNVERIFIED`로 남기고 출시 가능으로 표기하지 않음.
5. 사용자의 플레이테스트 판단은 별도 항목으로 남김. 자동 검사 통과를 사용자 이해·재미 검증으로 표시하지 않음.

현재 범위에서 온라인 기능·새 콘텐츠·가격·광고·스토어 게시를 추가하지 않는다. 발견한 출시 차단 문제를 먼저 해결한다.
