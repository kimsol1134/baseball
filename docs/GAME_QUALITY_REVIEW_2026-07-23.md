## 1. 종합 판정

> **"상용 수준의 야구 시뮬레이션 커널과 최상급 엔지니어링 규율 위에, 아직 '게임'과 '이야기'가 얹히지 않았다."**
>
> 투구 커널(선택/실행/결과 분리, 결정론, ABS, 드래그 물리 궤적)과 기술 기반(저장 무결성, 접근성, CI 게이트, IP 위생)은 인디 최상위권이다. 그러나 그 위의 결정층은 정답이 공개돼 있고, 통계 분포는 야구가 아니며, 콘텐츠의 72%는 배선이 끊겨 있고, 인물은 얼굴이 없으며, 환생이라는 간판은 받는 쪽 연출이 0이다. **지금 상태로 정식 출시하면 스토어 페이지가 약속한 게임과 실제 게임이 다르다.**

### 구조적 문제 3가지 (개별 버그보다 중요)

**① 약속과 실물의 불일치.** 제목("야구 못하면 또 환생함")은 회귀물 코미디를, 스토어 캡슐(`marketing/steam/assets/store/main-capsule.png`)은 전생 잔상이 겹친 인물 드라마를, 랜딩 카피("누군가 당신의 이름을 부릅니다")는 감정 정점을 약속한다. 실물은 진지한 다큐 톤의 얼굴 없는 스탯 대시보드이고, 드래프트 지명은 뉴스 한 줄, 은퇴는 두 줄이다. 참고로 이 제목은 2026-07-22에 '야구혼'에서 개명된 것(`docs/GAME_NAME_CHANGE.md`)으로, 간판이 먼저 바뀌고 알맹이가 못 따라온 상태다.

**② 좋은 커널, 얕은 게임.** 324조합의 투구 결정 공간이 실제로는 훨씬 좁다. 스카우팅이 최적해를 시작부터 공개하고(`selectionQuality`가 약점구종 +170/강점구종 -190을 코드에 명시), 강도 축은 기대이득이 0이며(구속이 결과 판정에 미사용), 라이벌 적응은 "구종 골고루 섞기" 한 가지로 완봉된다. 유료 본체인 프로 커리어는 `4스탯 평균 ±4 난수` 3줄 산식의 스프레드시트다.

**③ 콘텐츠 기근 + 배선 누락.** 작성된 관계 이벤트 36개 중 26개가 코드상 도달 불가능하고, 손으로 쓴 대사 장면은 9개, 순수 서사 산문은 1,500~2,000단어 수준이다. "여러 삶을 반복하는 로그라이트"인데 2~3회차면 모든 텍스트가 소진되고, 회차가 바뀌어도 프롤로그 문장 하나 변하지 않는다.

## 2. 영역별 상세 평가

### 2.1 게임성 — 4.5/10

**잘한 것**
- 타자 노림수 선(先)확정 + 해시 봉인 구조는 진짜 동시-추측 심리전 설계다 (`PitchKernelEngine.swift:705-771`, 정보 차단 테스트 존재).
- 선택 품질 / 실행 품질 / 결과의 3분리로 "좋은 선택, 나쁜 결과"가 실제로 발생하며, 레버리지가 결과 확률을 몰래 바꾸지 않는 비보정 원칙이 테스트로 강제된다.
- 커리어 각성은 진짜 트레이드오프(예: 폭발하는 포심 = stuff +4 / command -2 / 피로 +1)이고, 훈련 16점을 6개 분야에 배분하는 특화 강제는 유효한 자원 게임이다.
- 업보(karma) 6종은 명시적 리스크/보상으로 숙련자 난이도 커스터마이즈 기능을 한다.

**문제 (근거)**
- **정답 공개**: `BatterScoutingSnapshot`이 핫/콜드존·약점구종을 런 시작에 전부 공개하고, `selectionQuality`(`PitchKernelEngine.swift:1069-1103`)가 그대로 정답표다. 관찰로 타자를 "읽어내는" 플레이가 존재하지 않는다.
- **죽은 강도 축**: `velocity`는 결과 판정(`resolvePitch`)에서 미사용 — 궤적 연출 전용. `maxEffort`는 제구 페널티 +130만 부과해 **전력투구가 순수 손해**다.
- **1비트 적응**: 라이벌 기억은 최근 24구의 최빈 구종/코스만 탐지(점유율 ≥50% 필요, `RivalMemory.swift:84,158,224-249`). 4구종을 섞으면 영구 탐지 불가. 반대로 패턴이 잡히면 절벽 붕괴 — 배치 실측에서 같은 콜 반복 시 **피안타율 .696~.702, R/9 60+** (아래 §3 표). 중간 지대가 없다.
- **실패 없는 드래프트**: `ratingScore = 스탯합/4 + 18` + 각성 확정 +6으로 바닥이 높아, 성장을 방치해야 미지명이 나온다. 스펙의 "1회차 지명률 35~45%"와 배치된다 (`HighSchoolCareer.swift:991-993`).
- **성공 런은 메타를 굶긴다**: `let memories = drafted ? [] : memoryOptions(...)` (`HighSchoolCareer.swift:1008`) — **지명되면 기억 카드 0장**. 로그라이트 계승 루프가 실패 전용이다.
- **거꾸로 된 반복 페널티(데드코드)**: `recentRepeatCount`가 0/1만 반환해 -45 분기 도달 불가, 같은 훈련 반복(+55)이 전환(+20)보다 유리 (`PitcherLab.swift:765,1085-1086`). 안티-스팸 설계가 정반대로 구현됐다.
- **상황을 모르는 타자**: `commitBatterPlan`이 주자·아웃·점수를 무시 — 만루와 무주자의 타자가 동일하게 행동한다. `GameSituation`에는 양 팀 점수 필드조차 없고 leverage 실사용처는 도루 확률 한 곳뿐이다.
- **본체가 스프레드시트**: 프로 주간 시뮬은 `skill = 4스탯/4, variance = ±4` (`ProCareer.swift:171-176`). 수동(고충실 커널)과 자동(3줄 산식)의 통계 분포가 이질적이다. 프로 중요 경기 상대는 "오재민" 한 명이 하드코딩돼 매번 같다 (`ProCareerView.tsx:51`).

### 2.2 야구 현실성 — 5.5/10

**잘한 것**
- 제구(control)/커맨드(command) 분리, 피로의 구속·커맨드 동시 잠식, 2차 드래그+마그누스 궤적(비행시간 470ms대), ABS 자동 판정, 파크 팩터, KBO와 같은 10구단, **군 복무 분기**, FA·노쇠·은퇴·명예의 전당까지 커리어 아크.
- 실존 IP 자동 차단(`tools/check-copy.mjs`)과 지역 기반 가상 학교 76개 작명은 상용 출시 수준의 세계관 위생이다.

**문제 (실측 근거는 §3)**
- **홈런이 사실상 없다**: 4만 타석에서 HR 2개(파워 50 기준 0.02%/PA, 현실 ~2.5%). 홈런 임계(contactQuality ≥790)에 파워 ~58+가 필요한 하드 게이팅. UI는 "실투를 장타로 바꾸는 힘이 위협"이라 경고하지만 엔진은 그 위협을 만들 수 없다.
- **타석 질감 왜곡**: 파울 4.7~5.1%(현실 ~17%), 헛스윙 18~22%(현실 ~11%), 볼넷 2.2~5.5%(현실 ~8.5%), P/PA 3.4~3.6(현실 3.9). 버티는 승부·깊은 카운트가 없다.
- **BABIP 초민감**: 상대 컨택 45→56의 11점 구간에서 BABIP .17→.51, AVG .14→.40. 현실의 레이팅-성적 기울기보다 4배 가파르다 (`(contact-50)*4, (power-50)*7` 계수).
- **EV/LA가 장식**: `exitVelocity = 1050 + contactQuality/2`, `launchAngle = 랜덤 -5°~38°` (`PitchKernelEngine.swift:1034-1036`) — 결과가 먼저 정해지고 수치가 사후에 붙는다. 타구속도 상한 ~96mph로 물리적으로 홈런이 불가능한 값이 표기된다.
- **규칙 누락**: 3루타·HBP·고의사구·번트·보크·폭투·포일·견제·희생플라이 전무. `inPlayOut`은 항상 0득점·주자 불변이라 3루 주자 있는 뜬공이 득점을 못 만든다. `throwingHand`가 있는데 좌우 플래툰은 미구현.
- **고교에 부상이 없다**: 한국 아마야구 최대 이슈인 혹사(투구수·UCL)가 고교 단계에 부재. 프로에만 부상 코드가 있다.
- 소소하지만: 시즌 리뷰의 "ERA"는 실점 기반 RA/9의 오기(`ProCareer.swift:252`), 구종 4개뿐(포크/투심/커터 부재), 스펙 구속표(144~147)와 출시 밸런스(141)의 불일치.

### 2.3 스토리·콘텐츠 — 4.4/10

**잘한 것**
- 손으로 쓴 대사 9장면의 품질은 좋다. "이번 등판은 쉰다. 요즘은 팔이 몸보다 늦게 따라온다"(감독), "솔직히 네 변화구가 어디로 올지 몰라서 겁날 때가 있어"(포수) — 캐릭터 보이스가 산다.
- 아키타입(감독 4·포수 4·라이벌 8) × 응답(듣기/설명/도전) 매트릭스가 실제로 다른 결과를 낸다 (`HighSchoolCareer.swift:1124-1157`).
- 세계관 축이 가장 단단하다: 지역별 가상 고교 76개, 가상 구단 10개, 조사(이/가) 자동 처리, 팬 핸들("@3루측막내") 같은 디테일.

**문제 (근거)**
- **환생의 받는 쪽이 0이다**: `lifeNumber`는 careerID 문자열과 "N번째 선수" 라벨에만 쓰인다. 2회차든 10회차든 프롤로그 뉴스가 동일하고(`HighSchoolCareer.swift:768`), 어떤 인물도 데자뷔를 말하지 않는다. 기억 카드는 팀 자체 리뷰가 이미 P0로 등록했듯 "파워 누적"으로 소비된다.
- **26/36 이벤트가 사장**: 유일한 소비처가 카테고리를 coach/catcher/rival로만 필터(`HighSchoolCareer.swift:1100-1101`) — "첫 팬레터", "집에서 온 전화", "시험 주간" 등 growth/health/life/fan/media/legacy 26종은 작성만 되고 절대 노출되지 않는다.
- **감정 정점의 배신**: 랜딩이 약속한 지명의 순간은 실제로 `"드래프트 지명 · 구단 · 이름"` 한 줄, 은퇴는 `score >= 70 ? "명예의 전당 헌액…" : "은퇴식에서…돌아봤습니다."` 삼항 2줄(`ProCareer.swift:270`)이다. 8~15시간 커리어의 종착점이다.
- **반복 소진**: 대화 9장면·경기 시나리오 12종은 2~3회차에 전부 소진되고, 뉴스 인용문은 완전 고정이라("좋았던 공 하나보다…") 같은 인물이 같은 말을 반복한다.
- **톤 분열**: 제목은 능청스러운 회귀물, 본문은 근엄한 세미다큐. 어느 쪽이든 정해야 한다.

### 2.4 그래픽·연출 — 5.0/10

**잘한 것**
- **GameCast(TRACKLAB)는 실질 차별점이다**: 1,047줄의 SVG 스탯캐스트풍 리플레이 — 야간 구장, 목표 대비 실제 궤적, 단계 공개(투구→판정→결과), 배속/건너뛰기, 모션 감소 대응 (`TrajectoryReplay.tsx`). 스크린샷 기준으로도 게임에서 가장 "게임다운" 화면이다.
- 성장 축하 파티클, 드래프트 단계 공개, 22개 keyframes의 절제된 모션.
- 스토어 키 아트는 프로급이고 환생 콘셉트(전생 잔상)를 정확히 전달한다.

**문제 (근거)**
- **캐릭터 얼굴이 0개**: 관계(감독·포수·라이벌 신뢰)가 핵심 기계인 RPG인데 인물이 전부 텍스트 카드다. 주인공 아바타는 글자 "P"(`App.tsx:1720`). 실제 얼굴 초상이 있었으나 "같은 얼굴 반복" 문제로 폐기됐다(`docs/assets/source/retired/*-portrait.webp`, 커밋 cbe1ee8) — 해법이 얼굴 삭제가 아니라 얼굴 다양화여야 했다.
- **인게임 아트 6장뿐**: 얼굴 없는 역할 신 3장 + 빈 야간 구장 3장. 그마저 배경은 72~97% 불투명 오버레이에 가려 거의 안 보인다(`styles.css:4805-4831`). 원인은 dist 2.5MiB 자산 예산(`tools/check-web-assets.mjs:9-10`) — 데스크톱 게임이 웹 예산에 아트를 굶기고 있다.
- **오디오가 게인 0.07의 합성 비프 8종**(`gameFeedback.ts`, 52줄): 배트 크랙도 미트 팡도 관중도 음악도 없다. 팀 자체 평가도 손맛 0.5/5.

### 2.5 디자인·UX — 7.5/10

**잘한 것**

**문제**

### 2.6 기술 품질 — 8.5/10

### Phase 1 — 게임성 코어 (2~3주)

1. **타자 상황 인식** (최우선): `commitBatterPlan`·`resolvePitch`에 주자/아웃/점수/leverage 입력 — 만루의 타자는 적극적으로, 빈 베이스에선 유인구를 참게. 결과 확률 보정이 아닌 **행동 변화**이므로 비보정 원칙(ADR-005)과 충돌하지 않는다. 장식이던 leverage가 즉시 전략 축이 된다.
2. **통계 분포 재보정**: 파울을 컨택의 35~40%로(→투구의 ~17%), 스윙 컨택 base 560→~720(헛스윙 하향), 볼넷 8~9%, BABIP ~.300, 레이팅 민감도 완화(`(contact-50)*4`·`(power-50)*7` 계수 압축). **홈런 도입**: EV/LA를 인과 변수로 승격(배럴 로직: EV≥155km/h & LA 20~35° → HR), 타구속도 상한 해제. 구속을 헛스윙 확률에 연결해 죽은 강도 축을 살린다.
3. **스카우팅을 답안지에서 가설로**: 약점/콜드존 정보를 신뢰도 낮은 범위로 시작해 관찰(투구 결과)로 정밀해지게. 난이도 "정보 공개" 축과 자연 결합.
4. **드래프트 실패 복원**: ratingScore 바닥(+18)과 각성 확정분(+6)을 낮춰 1회차 지명률을 스펙(35~45%)에 근접시킴 — 실패-계승 루프가 비로소 긴장을 얻는다.
5. **밸런스 불변식 자동화**: CLI 하네스에 assert 추가 — "추천 무지성 수락이 최적이 아님", "지배 전략 점유 <45%", "HR/PA 1~3%", "BABIP .28~.32". CI 게이트化.

### Phase 2 — 감정·표현 (3~4주, DOPAMINE Sprint 1~3와 병행)

1. **받는 쪽 환생**: 프롤로그를 `lifeNumber`로 분기(2회차부터 다른 도입부), 상속 기억의 서사 콜백("손끝이 낯선 그립을 기억한다"), 라이벌·포수의 데자뷔 대사 각 1종. 제목값 회수의 최소 비용 경로.
2. **3대 정점 연출**: 드래프트 호명(이미 단계 공개 구현됨 — 여기에 사운드·풀스크린 키 아트), 1군 데뷔, 은퇴 회고 시퀀스(통산 기록·최고의 경기·함께한 포수·고교 라이벌 소환). 은퇴 2줄을 다단 연출로.
3. **캐릭터 얼굴 복원**: 폐기한 초상 방식 대신 파츠 조합 또는 스타일화 초상 세트로 절차 생성 인물에도 서로 다른 얼굴 부여. 최소 범위: 감독 4·포수 4·라이벌 8 초상 + 주인공("P" 글자 대체). 관계 RPG의 전제 조건.
4. **오디오 실자산화**: 비프 8종 → 배트 크랙/미트 팡/관중 스웰/마일스톤 스팅어. 라이선스 불가 시 고품질 합성이라도 게인·레이어 재설계.
5. **관계 아크**: `relationshipScene`에 신뢰도·챕터·lifeNumber 인자 전달, 같은 인물 3회 등장 시 갈등→시험→회수 미니 아크(DOPAMINE Sprint 3와 동일 방향), 고정 인용문을 관계 단계별 3~4종 풀로.

### Phase 3 — 유료 본체(프로) 재건 (4~6주)

1. 자동/수동 시뮬 통일: 주간 자동 결과를 3줄 산식이 아니라 **같은 커널의 저해상도 실행**(타석 단위 축약)으로 생성 — 직접 던진 경기와 통계 연속성 확보.
2. 프로 시즌 아크: 24주를 6구간으로 압축, 중요 경기를 고정 주차가 아닌 기록 추격·보직 경쟁·라이벌로 발생(DOPAMINE Sprint 4 승계). 하드코딩된 "오재민" 단일 상대를 구단별 라이벌 풀로.
3. **고교 혹사 시스템**: 투구수·연투 기반 부상 리스크(UCL) — 한국 아마야구의 상징적 갈등이자 "무리한 완투 vs 다음 생"이라는 로그라이트 본연의 긴장. 프로 부상 코드를 고교로 확장.
4. 규칙 프리미티브: 희생플라이(3루 주자 득점), 3루타, HBP, 좌우 플래툰(이미 있는 `throwingHand` 활용). 번트·고의사구·폭투는 후순위.

### Phase 4 — 볼륨·리플레이성 (지속)

- 손대사 9→25+ 장면(0-1로 배선한 이벤트에 우선 투입), 중요 경기 시나리오 12→20+.

- **톤 결정**: 제목의 코미디를 본문에 주입할지(회귀물 위트), 다큐 톤을 유지하고 스토어 기대를 재조정할지 명시 결정. 현재는 간판과 본문이 서로 다른 게임을 광고한다.
- 인게임 아트 예산 상향: 데스크톱/Steam 빌드에 고화질 아트 별도 번들(2.5MiB 웹 예산은 웹 티저 전용으로 격리).

### 출시 전략 제언 (RC 관점)

- 기술 게이트는 통과 상태지만, **현재 빌드로 정식 1.0을 내면 데모 30~45분 안에 반복감과 스토어 약속 불일치가 노출된다.** Phase 0(1주)은 출시 전 필수로 판단한다.

## 6. 한계

- 점수는 외부 플레이테스트 표본이 아닌 코드·실측·화면 기반 휴리스틱이다. DOPAMINE 리뷰와 동일하게, 실사용자 데이터 수집 후 같은 기준으로 재평가해야 한다.
- 배치 실측은 중요 이닝 커널 기준이며, 고교 경기 5회·프로 시즌의 체감 난이도는 커리어 보정에 따라 다를 수 있다.
- iOS 축약판은 화면 실행 없이 코드 분석만 반영했다.
