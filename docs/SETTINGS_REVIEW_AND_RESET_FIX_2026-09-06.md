2026-09-06. 사용자의 Galaxy A53 테스트 피드백을 기준으로 실제 화면과 Android 소스를 확인했다. **설정 전체 재배치는 아래 제안이며, 진행 삭제 버그는 이번에 수정·검증했다.**

## 사용자 관점 진단

- 같은 설정의 상태 설명과 실행 버튼을 따로 보여준다. 상태를 읽고 한참 아래의 버튼을 찾아야 한다.
- 모든 토글이 큰 초록 버튼이라 우선순위가 같아 보인다. ‘진동 끄기’라는 행동 이름은 현재 켜져 있다는 사실을 바로 읽기 어렵게 한다.
- 용어집 29개를 설정에 펼쳐 보여 설정 화면이 게임 설명서처럼 길어진다.
- 자동 릴리스가 첫 번째 대형 버튼이다. 기본 재미인 직접 타이밍 조작보다 보조 조작이 강조된다.
- 알림의 실제 제어는 별도 플랫폼 영역에 있고, 상태 요약과 떨어져 있다. ‘기록과 이야기’, ‘도전 코드’처럼 설정의 목적과 다른 기능도 섞여 있다.
- 설정 변경 뒤 커리어로 돌아가는 공통 처리도 보인다. 여러 옵션을 조정하는 중에는 같은 설정 화면을 유지하는 것이 적절하다.

## 권장 첫 화면

| 항목 | 표시와 동작 |
|---|---|
| 효과음 | 현재 상태가 보이는 스위치 |
| 배경 음악 | 현재 상태가 보이는 스위치 |
| 진동 | 현재 상태가 보이는 스위치 |
| 조작과 화면 › | 보조 조작·글자/대비·화면 움직임 |
| 알림 › | 현재 기기 권한 상태와 필요한 변경 동작 |
| 저장과 기록 › | 파일 보관·불러오기·모든 진행 삭제 |
| 도움말 › | 투구 방법·야구 용어·문의 |

첫 화면은 한 화면 안에 들어오는 짧은 목록을 목표로 한다. 설명을 없애기 위해 접근성 기능까지 없애지는 않는다. 필요한 사람은 한 번 눌러 찾을 수 있어야 한다.

큰 초록 버튼은 게임의 주요 행동에 집중시키고, 설정에는 짧은 행과 스위치를 쓴다. 효과음·음악·진동에는 ‘설정을 저장합니다’ 같은 설명을 붙이지 않는다. 보조 조작은 ‘한 번 눌러 던지기’, 모션은 ‘화면 움직임 줄이기’처럼 실제 행동으로 설명한다. 직접 슬라이더 조작은 기본값을 유지한다.

용어집은 도움말 안으로 이동한다. 모든 능력 옆에 도움말 아이콘을 추가하기보다는, 이해가 필요한 장면에서 짧은 효과를 보여주고 상세 설명은 사용자가 요청할 때 연다.

이 방향은 설정을 간결한 목록으로 구성하고, 현재 상태를 보여주며, 긴 설명은 별도 화면으로 옮기는 [Android 공식 설정 지침](https://developer.android.com/design/ui/mobile/guides/patterns/settings)과도 일치한다. 구체적인 항목과 우선순위는 이 게임의 핵심 재미에 맞춘 제안이다.

## 진행 삭제 원인과 수정

실제 native 저장 어댑터가 일반 명령 처리로 ResetProgress를 전달했고, 해당 경로는 reset.native_only 오류로 거부했다. 오류 UI는 긴 설정 화면 최상단에 있어 삭제 버튼 위치에서 보이지 않았다. 확인창도 없었다.

- 삭제 버튼을 누르면 삭제 범위와 되돌릴 수 없음을 알리는 확인창을 연다.
- 취소하면 현재 선수와 기록을 유지한다. 사용자가 최종 확인해야 삭제한다.
- 삭제 중 중복 조작을 막고, 실패하면 확인창 안에 오류를 표시한다.
- 실제 저장 어댑터에 삭제 전용 처리를 추가했다. 삭제 의도를 먼저 저장한 뒤 현재 저장·자동 백업을 정리하고 첫 상태를 기록한다.
- 처리 중 종료되면 다음 불러오기 전에 삭제를 마무리한다. 예전 자동 백업이 살아나지 않도록 했다.
- 알림·분석 큐·리뷰·공유 임시 데이터의 기존 정리 경로도 연결했다. 기기 설치 식별자는 유지한다.
- 완료 후 첫 화면으로 이동한다. 전체 진행 삭제의 기존 규칙에 따라 설정도 기본값으로 돌아가며, 수동 슬라이더가 기본이다.
- 확인창 문구는 한국어·영어·일본어로 추가했다.

## 검증과 실기기 반영

- native 삭제 3개 테스트 통과: 정상 삭제/재로드/중복 요청, 4개 중단 지점 복구, 플랫폼 정리 실패 후 재시작.
- 기존 native 커리어 저장·명령·파일 복원·번역 회귀 검사 통과.
- 앱 단위 검사와 debug/release 컴파일·lint 통과. 문구 매핑 2,643개 전부, 전체 제품 문구와 변경분 공백 검사 통과.
- Galaxy A53의 별도 reset QA 앱에서 확인창 → 취소/기록 유지 → 다시 확인 → 첫 화면을 실제 조작으로 검증했다. 프로세스 종료 후 다시 실행해도 첫 화면이 유지됐다.
- 실기기 삭제 검사는 사용자의 core QA 기록과 분리해 수행했다. 검사용 앱 두 패키지는 종료 후 제거했다.
- 수정한 최신 core QA APK를 사용자 기기에 설치했다. 설치 전후 기존 save.json의 SHA-256이 같음을 확인했다. 사용자 기록을 대신 삭제하지 않았다.
