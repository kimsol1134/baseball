# 모바일 핵심 경험 — 개선 완성 구현

2026-09-05. iOS·Android 공통으로 슬라이더 투구, 한 투수의 성장, 다음 생의 재도전을 중심에 두었다. 기존 초상·야구 이미지·2D 투구 화면을 사용한다.

## 사용자가 체감하는 변화

| 장면 | 변경된 경험 |
|---|---|
| 내 투수·훈련 | 작은 선수 표시 아래에 실제 일정으로 계산한 다음 등판 준비를 표시한다. 능력 상세는 선수 표시를 눌러 확인한다. |
| 훈련 선택 | 첫 강도는 보통이다. 추천은 훈련 종류를 뜻하며, 강도·피로·팔 부담을 따로 확인한다. 이전에 직접 고른 강도와 회복 권고를 유지한다. |
| 성장 | 관계·각성 단계로 넘어가도 첫 성장 결과는 전후 수치를 크게 보여준다. 다음 실제 행동 뒤에는 줄여 보여주며, 별도의 보상 수령을 요구하지 않는다. |
| 각성 | 지금 배울 수 있는 각성이 먼저 나온다. 잠긴 단계·이미 익힌 단계는 전체 성장 트리에서 확인한다. 확정 전 효과와 선택 확인을 유지한다. |
| 환생 | 이번 생과 다음 생을 구분한다. 이번 생 시작 능력과 다음 생의 실제 시작 능력, 계승 효과, 지난 생의 기록에 기반한 다음 도전을 보여준다. 환생 버튼은 화면 아래에 남는다. |
| 상세 정보 | 훈련 설명·구종 학습·연속 훈련 규칙·전체 기록은 펼쳐볼 수 있다. 중요한 피로·부상 경고와 결정에 필요한 비용은 행동 가까이에 둔다. |

## 환생 수치의 신뢰성

- iOS는 다음 생의 시드를 하나 예약하고 미리보기와 실제 환생에서 함께 사용한다. 계승·기억·유산·계보·구종·능력 상한이 실제 시작 경로와 같은 조건으로 적용된다.
- Android는 버튼이 제출할 명령의 시드와 날짜로 미리보기를 계산한다. 명령이 바뀌면 이전 계산값은 숨긴다. 실제 게임 상태와 저장된 난수 진행은 미리보기로 바뀌지 않는다.
- 이전 시작 능력이 없는 iOS 구저장본은 값을 지어내지 않고 기록 없음으로 표시한다.
- 큰 계승량을 포함한 iOS 실제 환생, Android의 파일 저장·프로 은퇴 이후 환생에서 미리보기와 실제 시작값의 일치를 검사했다.

## 완주 검증에서 함께 수정한 문제

- 환생 전 정산이 이미 다음 생인 것처럼 보이던 iOS 회차 표시.
- 일본어 유산 효과와 근거가 영어 또는 문장 조각으로 조합되던 문제.
- 기록이 없는 유산 정의를 일본어로 표시할 때 문구 인자가 빠져 환생 직후 오류가 나던 경로.
- Android의 옛 기억 후보를 대표 유산 후보로 잘못 노출할 수 있던 경로. 정식 후보를 준비한 뒤 선택하도록 수정했다.
- 언어에 따라 완주 테스트가 다른 확인 버튼을 찾던 부분을 고유 식별자로 검증하도록 정리했다.

## 검증 범위

- iOS: 환생·유산 통합 단위 테스트 17개 통과. 다음 등판 카운트다운·성장 표시 관련 3개 통과.
- iOS: 한국어 고교→드래프트→유산→환생→다음 생 편지 완주, 훈련 직후 결과 노출, 관계 선택 접근성 통과.
- iOS: 기본 수동 슬라이더로 한 구 완료, 영어 첫 투구 화면 검사 통과.
- iOS: 일본어 고교→드래프트→유산→환생→두 번째 생의 편지 완주 통과. 환생 미리보기의 한글 대체 문구 미노출도 검사했다.
- Android: 화면 모델·현지화·성장·저장·20시즌 은퇴 후 환생 관련 검사 통과. 앱 단위 검사 9개와 lint 오류 0개.
- Android Galaxy A53: 훈련 선택 후 실제 저장 재로드, 글자 크기 1배·2배, 전체 각성 트리, 환생 미리보기와 확정값 일치 통과.
- Android Galaxy A53: 영어·일본어 신규 플레이에서 기본 슬라이더로 투구 완료. 동작 취소는 0구, 의도한 릴리스는 정확히 1구인 것을 검사했다.
- 전체 제품 문구 검사: 내부 용어 38종·실존 야구 IP 42종 미노출.

검증 APK와 화면·로그를 포함한 QA 폴더는 약 29MB, 최종 화면이 있는 이미지 폴더는 약 3.9MB다.

이번 기록은 로컬 QA 빌드의 실행·저장·화면 검증이다. 실제 사용자 만족도와 반복 플레이 유지율, iOS 실기기/TestFlight 및 App Store 지원 언어 표시는 별도 출시 검증 대상이다. 순위 달성이나 스토어 제출 결과를 의미하지 않는다.
