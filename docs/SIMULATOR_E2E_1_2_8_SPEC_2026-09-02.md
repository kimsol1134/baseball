# 1.2.8 시뮬레이터 E2E 검증 + 글자 깨짐 재현 스펙

작성: PM, 2026-09-02. 구현: grok. 목적: 1.2.8 후보(주간 결정 훅, 보직 지원, 용어 카드, 게이트 정리)를 실제 앱에서 끝까지 돌려 보고, 리뷰 "각종 글자 깨짐"을 재현·수정한다.

## 0. 절대 규칙
1. 커밋·푸시·stash·reset·checkout 금지.
2. 시뮬레이터: 부팅된 **iPhone 17**을 재사용한다. 작은 화면 검증이 필요하면 `xcrun simctl list runtimes`에 있는 런타임으로 **"iPhone SE (3rd generation)" 하나만** 만들고 작업 끝에 반드시 삭제한다. 타임스탬프·재시도용 기기 생성 금지.
3. xcodebuild는 한 번에 하나. `QACaptureUITests`는 상시 실패 이력이 있어 게이트로 쓰지 않는다.
4. 스크린샷·결과 번들은 `apps/ios/releases/qa-1.2.8/`에만 저장하고 200MB를 넘기지 않는다. `.xcresult`는 요약만 남기고 삭제.
5. 코드 수정은 발견한 결함의 수정에 한정한다. 새 기능 추가 금지. 테스트 삭제·약화 금지.
6. 투구 슬라이더는 기본 조작이어야 한다(AGENTS.md). E2E에서 슬라이더로 한 구를 끝까지 던질 수 있는지 확인한다.

## 1. E2E 시나리오 (XCUITest로 작성, `apps/ios/UITests/Release128JourneyUITests.swift`)
기존 `CareerSmokeUITests`의 진입·환생·프로 진입 헬퍼를 재사용한다. 각 단계에서 `XCTAttachment` 스크린샷을 남기고 결과에서 PNG를 추출해 `apps/ios/releases/qa-1.2.8/<scenario>/NN-<step>.png`로 저장한다.

1. **새 커리어 → 프로 진입**: 고교를 자동 진행/스킵 경로로 통과해 프로 계약 제안까지. 좌완/우완 선택이 시작 화면에 있는지 확인.
2. **보직 지원**: 스프링캠프 카드가 보이고 3개 선택지에 수락 전망이 표시된다. "선발" 선택 → 결과 문구 확인.
3. **주간 결정 3주차**: 주 단위 진행으로 3주차에 결정 화면(eyebrow "3주 결정")이 열린다. 선택지 카드에 즉시 효과와 "3주 뒤" 요약이 분리 표시된다. 설명 안 용어를 탭해 용어 시트가 열리는지 확인. 선택 A.
4. **후속 결과**: 3주 더 진행하면 주간 화면에 "결정 결과" 카드가 나타난다. 접힘/펼침 동작 확인.
5. **직접 등판 1구**: 중요 경기 또는 직접 등판 진입 → 슬라이더로 한 구 던지기 → 결과 표시.
6. **시즌 완주**: 자동 진행으로 시즌 종료 → 시즌 정산 → 오프시즌 → 다음 시즌 스프링캠프까지. 결정 수가 7을 넘지 않았는지 기록 화면에서 확인(가능하면).
7. **저장·복귀**: 앱을 백그라운드로 보낸 뒤 재실행해 같은 화면으로 복귀.
8. **언어 스위치**: 시뮬레이터 언어 en, ja로 각각 1·3·4 단계를 재실행해 한국어가 새어 나오는 화면이 없는지 확인(`-AppleLanguages (en)` 런치 인자).

## 2. 글자 깨짐 재현 (리뷰 8/29 "각종 글자 깨짐 문제")
"깨짐"의 후보: (a) 글자 잘림/말줄임, (b) 한국어 단어 중간 줄바꿈(1.2.7에서 수정 주장), (c) 폰트 미적용으로 나오는 사각 글리프, (d) 숫자·단위 겹침.
- 텍스트 밀도가 높은 화면 8곳을 정한다: 시즌 결정, 주간 계획, 훈련 결과, 시즌 정산, 계약 제안, 은퇴 화면, 기록 화면(박스스코어), 설정.
- 각 화면을 다음 조합으로 캡처: iPhone 17 기본 / iPhone 17 + Dynamic Type `UICTContentSizeCategoryAccessibilityL` / (가능하면) iPhone SE 3세대 기본. 런치 인자 `-UIPreferredContentSizeCategoryName`.
- 캡처를 눈으로 검토(Read로 PNG 열기)해 잘림·겹침·중간 줄바꿈·사각 글리프를 찾고, 발견한 것은 원인 파일과 수정 내용을 적고 고친다. 수정 후 같은 조합으로 재캡처해 전후 비교를 보고서에 넣는다.
- `.lineLimit(1)`/`.minimumScaleFactor` 없이 고정 높이에 들어간 Text, 좁은 HStack의 숫자 열 등이 주요 후보다. `DesignSystem.swift`의 공용 카드/버튼부터 본다.

## 3. 게이트
