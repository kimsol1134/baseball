## 미해결

### S-03 가운데 탭 레이블이 화면 최상단에 중복 렌더 — 앱이 그리는 것 확정

4차 수정 기록에 "상단 픽셀 영역에 추가 글자가 그려지지 않는 검사 통과"로 되어 있으나 그대로다.

- **런처를 캡처하면 상단이 깨끗하다** → 시스템 아티팩트가 아니라 앱이 그리는 것
- 설정 탭·기록 탭 모두 재현. 어느 탭을 선택하든 **항상 가운데 항목(기록)의 레이블만** 나온다
- 접근성 트리에는 노드가 없다(그려지기만 하는 잔상)
- 1차 M-10 이후 5개 라운드, 서로 다른 세 세션에서 재현

검사가 이 경로를 놓치고 있다는 뜻이므로 검사 자체를 먼저 의심할 것.

## 신규 — 이번 수정이 만든 것

- **T-01** "아래에 내용이 더 있어요 ↓"가 볼 것이 없을 때도 표시된다. 멈춰 둔 등판 화면에서 2회 스크롤해도 노드 목록이 완전히 동일(새로 드러나는 내용 0). 하단 여백만 있으면 실제 가림 여부와 무관하게 뜨는 것으로 보인다.
- **T-02** 그 안내 바가 스크롤 콘텐츠 위에 얹혀 글자를 자른다. 시즌 결산 화면에서 `시즌 등판 기록`이 가로로 반쯤 잘림. 수정 기록의 "독립된 영역에 표시" 의도와 다르게 겹친다.
- **T-03** 스트라이크 존 격자가 포수 가슴·미트 위에 겹쳐 가운데 열 경계가 안 보인다. 격자선이 옅고 포수도 어두워 대비가 거의 없다. 비행 화면은 조준 화면보다 훨씬 어두워 같은 두 인물이 화면마다 다른 밝기로 그려진다.
- **T-04** 조준 화면 그림 패널 아래 약 360px 여백 잔존. 세이브가 계속 증가(372KB; `meta.album` 138KB/3항목, `pro.coreStateJson` 106KB, `commandReceipts` **1,749개** 53KB, 정리 흔적 없음). 성능 영향은 확인되지 않았으므로 상한만 정해 두면 되는 사안.

## 정정 — 4차 성능 관련

이번 세션 초반에 잰 콜드 스타트 **8.6~11.5초는 잘못된 측정**이다. 측정 당시 맥 부하 평균이 8~43이었고 다른 에이전트 세션이 동시 실행 중이었으며 에뮬레이터가 받은 CPU는 21%였다. 에뮬레이터 재부팅 후 같은 372KB 세이브로 다시 재니 **1,494 / 1,515 / 1,535 / 1,642 ms**로 1~4차(1.1~1.3초)와 같은 수준이다. **콜드 스타트 회귀 없음.** 세이브 크기가 시작 시간에 주는 영향도 이 수치 안에서는 드러나지 않는다.
