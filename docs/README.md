# Project Diamond Soul 개발 문서 패키지 v1.0

이 패키지는 확정된 제품 방향을 기준으로 만든 개발 기준선입니다.

## 핵심 제품 정의

여러 번의 고교 야구 인생에서 얻은 기억으로 프로 드래프트를 돌파하고, 지명된 한 명의 선수로 은퇴까지 살아가는 데이터 중심 야구 로그라이트 RPG.

## 파일 구성

- `Project_Diamond_Soul_Master_Spec_v1.0.docx`: 전체 문서를 합친 검토·공유용 Word 문서.
- `docs/`: 버전 관리와 수정에 적합한 개별 Markdown 원본.
- `assets/`: 문서에 사용한 구조도.
- `schemas/`: 데이터·콘텐츠 스키마 샘플.

## 기준선 핵심

- Windows 우선, iOS 후속.
- Swift 공유 시뮬레이션 코어.
- 투수부터 구현.
- 고교 60~90분 로그라이트, 프로 장기 커리어.
- 현재 세부 스탯 완전 공개, 미래는 범위·신뢰도.
- 야구혼 + 기억 3장 + 각성 3개.
- 영구 직접 능력 상승 최대 8~10%.
- 고교와 드래프트 무료, 프로 계약부터 일회성 구매.
- 광고·가챠·에너지·능력 판매 없음.
